Этот справочник представляет собой всеобъемлющее руководство по всему синтаксису, концепциям, функциям, типам и другим определениям Typst. Используйте справочник, чтобы получить ответы на конкретные вопросы о Typst и расширить своё понимание доступных возможностей.

Если вы совсем не знакомы с Typst, мы рекомендуем начать с [руководства](/docs/typst/tutorial), а затем вернуться к справочнику, чтобы по мере необходимости узнать больше о возможностях Typst.

## Язык [#language]

Справочник начинается с основ языка Typst. Сначала мы даём обзор [синтаксиса Typst.](/docs/typst/reference/syntax) Следующие разделы охватывают ключевые концепции, центральные для языка Typst, такие как [стилизация документов,](/docs/typst/reference/styling) использование [скриптовых возможностей Typst](/docs/typst/reference/scripting) и [рассуждения о содержимом вашего документа.](/docs/typst/reference/context)

## Библиотека [#library]

Вторая часть включает разделы обо всех функциях, типах и других определениях, предоставляемых _стандартной библиотекой_ языка Typst.

Разделы с определениями сгруппированы по темам. Например, если вы хотите изучить все инструменты, которые Typst предоставляет для настройки расположения элементов на странице, вам следует начать с раздела [Макетирование](/docs/typst/reference/layout). Если же вы хотите узнать больше о том, в какие форматы Typst может экспортировать документы, вам стоит просмотреть раздел [Форматы](/docs/typst/reference/format).

## Как читать справочник [#reading-the-reference]

В этом справочнике используется несколько графических соглашений и меток, которые позволяют быстро просматривать его разделы.

`str`Эти плашки указывают, что значение относится к определённому типу. В заголовке главы каждого типа используется соответствующая плашка. Похожие типы имеют общий цвет. Например, все числовые типы имеют одинаковый цвет.ElementНекоторые функции помечены как элементы. Это означает, что их можно использовать с правилами set и show. Некоторые элементы можно [локализовать](/docs/typst/reference/introspection/locate) и использовать с функцией [`query`](/docs/typst/reference/introspection/query). Элементы, как правило, создают видимый вывод в документе. Вы можете использовать элементы, даже если не вызываете функции, поскольку для некоторых элементов существует специальная разметка.ContextualЭти функции могут рассуждать о содержимом вашего документа. Их можно использовать только тогда, когда доступен _контекст_, например, через контекстный блок. Дополнительные сведения см. в разделе [Контекст](/docs/typst/reference/context).RequiredОтображается у параметра функции, если вызов функции без этого параметра привёл бы к ошибке.PositionalОтображается у параметра функции, который указывается без имени параметра и двоеточия. Вместо этого Typst использует порядок параметров, чтобы определить, какой аргумент какой. Параметры, не помеченные как позиционные, являются _именованными_ параметрами.VariadicОтображается у параметров функции, которые можно указать несколько раз.SettableОтображается у параметров функций-элементов, которые можно настроить с помощью правила set.
