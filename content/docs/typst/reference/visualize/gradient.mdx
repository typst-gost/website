<span id="summary" />

*С версии: 0.9.0*

Цветовой градиент.

Typst поддерживает линейные градиенты через [функцию `gradient.linear`](#definitions-linear), радиальные градиенты через [функцию `gradient.radial`](#definitions-radial) и конические градиенты через [функцию `gradient.conic`](#definitions-conic).

Градиент можно использовать для следующих целей:

- В качестве заливки для окрашивания внутренней области фигуры: `rect(fill: gradient.linear(..))`
- В качестве обводки для окрашивания контура фигуры: `rect(stroke: 1pt + gradient.linear(..))`
- В качестве заливки текста: `set text(fill: gradient.linear(..))`
- В качестве цветовой карты, из которой можно [выбирать значения](#definitions-sample): `gradient.linear(..).sample(50%)`

## Точки останова [#stops]

Градиент состоит из последовательности точек останова. Каждая такая точка имеет цвет и смещение. Смещение — это [отношение](/docs/typst/reference/layout/ratio) между `0%` и `100%` или угол между `0deg` и `360deg`. Смещение — это относительная позиция, которая определяет, насколько далеко вдоль градиента расположена точка останова. Цвет точки останова определяет цвет, который градиент должен иметь в этой позиции.

Каждая точка останова передаётся как позиционный аргумент и может принимать одну из двух форм:

- Просто цвет, например `red`, чтобы Typst разместил точку останова автоматически.
- Массив из цвета и его смещения, например `(red, 30%)`, чтобы задать положение точки останова самостоятельно.

При определении градиента можно опустить смещения. В этом случае Typst равномерно распределит все точки останова. В противном случае смещения должны быть указаны для _каждой_ точки останова. Они не должны убывать от одной точки к следующей, первое должно быть `0%`, а последнее — `100%`.

<TypstRender
  code={`
  #rect(
    width: 100%,
    fill: gradient.linear(
      (green, 0%),
      (red, 30%),
      (blue, 100%),
    ),
  )
`}
  image="/typst_docs_assets/images/mvyZmnRKUItkQ6BdrP3BWA.png"
  alt=""
  editable={true}
/>

Если задать двум точкам останова одинаковое смещение, вместо плавного перехода создаётся резкая граница:

<TypstRender
  code={`
  #rect(
    width: 100%,
    fill: gradient.linear(
      (orange, 0%),
      (orange, 50%),
      (blue, 50%),
      (blue, 100%),
    ),
  )
`}
  image="/typst_docs_assets/images/h8fRyYCOpo-OIMgE4S9YMQ.png"
  alt=""
  editable={true}
/>

Typst предоставляет для градиентов метод [`sharp`](#definitions-sharp), который автоматически превращает плавный градиент в градиент с резкими границами. Приведённый выше пример можно эквивалентно записать так:

<TypstRender
  code={`
  #rect(
    width: 100%,
    fill: gradient.linear(orange, blue)
      .sharp(2),
  )
`}
  image="/typst_docs_assets/images/h8fRyYCOpo-OIMgE4S9YMQ.png"
  alt=""
  editable={true}
/>

Typst предопределяет цветовые карты, которые можно использовать в качестве точек останова в [`color.map`](/docs/typst/reference/visualize/color#definitions-map).

## Относительность [#relativeness]

Расположение точек останова `0%` и `100%` зависит от размеров контейнера. Этим контейнером может быть либо фигура, на которую наносится заливка, либо ближайший окружающий контейнер. Это управляется аргументом `relative` конструктора градиента. По умолчанию градиенты относительны к фигуре, на которую они наносятся, за исключением случаев, когда градиент применяется к тексту — тогда он относителен к ближайшему контейнеру-предку.

Typst определяет контейнер-предок следующим образом:

- Для фигур, размещённых на корневом/верхнем уровне документа, ближайшим предком является сама страница.
- Для других фигур предком является самый внутренний [`block`](/docs/typst/reference/layout/block) или [`box`](/docs/typst/reference/layout/box), содержащий фигуру.

## Цветовые пространства и интерполяция [#color-spaces-and-interpolation]

Градиенты можно интерполировать в любом цветовом пространстве. По умолчанию градиенты интерполируются в цветовом пространстве [Oklab](/docs/typst/reference/visualize/color#definitions-oklab), которое является [перцептивно равномерным](https://programmingdesignsystems.com/color/perceptually-uniform-color-spaces/index.html) цветовым пространством. Это означает, что градиент будет восприниматься как плавная последовательность цветов. Это особенно полезно для визуализации данных.

Однако вы можете выбрать интерполяцию градиента в любом поддерживаемом цветовом пространстве, но учтите, что некоторые цветовые пространства не подходят для перцептивной интерполяции между цветами. При выборе пространства интерполяции руководствуйтесь таблицей ниже.

| **Цветовое пространство** | **Перцептивно равномерное?** |
| --- | --- |
| [Oklab](/docs/typst/reference/visualize/color#definitions-oklab) | _Да_ |
| [Oklch](/docs/typst/reference/visualize/color#definitions-oklch) | _Да_ |
| [sRGB](/docs/typst/reference/visualize/color#definitions-rgb) | _Нет_ |
| [linear-RGB](/docs/typst/reference/visualize/color#definitions-linear-rgb) | _Да_ |
| [CMYK](/docs/typst/reference/visualize/color#definitions-cmyk) | _Нет_ |
| [Grayscale](/docs/typst/reference/visualize/color#definitions-luma) | _Да_ |
| [HSL](/docs/typst/reference/visualize/color#definitions-hsl) | _Нет_ |
| [HSV](/docs/typst/reference/visualize/color#definitions-hsv) | _Нет_ |

## Направление [#direction]

Некоторые градиенты чувствительны к направлению. Например, линейный градиент имеет угол, определяющий его направление. Typst использует угол по часовой стрелке, где 0° — слева направо, 90° — сверху вниз, 180° — справа налево, а 270° — снизу вверх.

<TypstRender
  code={`
  #stack(
    dir: ltr,
    spacing: 1fr,
    square(fill: gradient.linear(red, blue, angle: 0deg)),
    square(fill: gradient.linear(red, blue, angle: 90deg)),
    square(fill: gradient.linear(red, blue, angle: 180deg)),
    square(fill: gradient.linear(red, blue, angle: 270deg)),
  )
`}
  image="/typst_docs_assets/images/mHDTlWfH71VyunQ2I2BQBw.png"

## Замечание о размерах файлов [#note-on-file-sizes]

Градиенты могут быть довольно большими, особенно если у них много точек останова. Это связано с тем, что градиенты хранятся в виде списка цветов и смещений, который может занимать много места. При экспорте в SVG градиенты хранятся в виде списка цветов [`color.rgb`](/docs/typst/reference/visualize/color#definitions-rgb), воспроизводящих исходное цветовое пространство с оптимизированным числом дополнительных точек останова между ними. При экспорте в PDF то же самое относится к градиентам в цветовых пространствах [`color.oklab`](/docs/typst/reference/visualize/color#definitions-oklab), [`color.oklch`](/docs/typst/reference/visualize/color#definitions-oklch), [`color.hsv`](/docs/typst/reference/visualize/color#definitions-hsv), [`color.hsl`](/docs/typst/reference/visualize/color#definitions-hsl) и [`color.linear-rgb`](/docs/typst/reference/visualize/color#definitions-linear-rgb). Это избавляет от необходимости кодировать эти цветовые пространства в вашем PDF-файле, но добавляет дополнительные точки останова в градиент, что может увеличить размер файла.

**Тип:** [color](/docs/typst/reference/visualize/color) или [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Обязательный, Позиционный, Вариативный

### `radial` [#definitions-radial]

*С версии: 0.9.0*

Создаёт новый радиальный градиент, в котором цвета расходятся от начала.

Градиент определяется двумя окружностями: фокальной окружностью и конечной окружностью. Фокальная окружность — это окружность с центром `focal-center` и радиусом `focal-radius`, которая определяет точки, в которых градиент начинается и имеет цвет первой точки останова. Конечная окружность — это окружность с центром `center` и радиусом `radius`, которая определяет точки, в которых градиент заканчивается и имеет цвет последней точки останова. Затем градиент интерполируется между этими двумя окружностями.

Используя эти четыре значения, также называемые фокальной точкой для начальной окружности и центром и радиусом для конечной окружности, можно определить градиент с более интересными свойствами, чем у базового радиального градиента.

<TypstRender

    dir: ltr,
    spacing: 1fr,
    circle(fill: gradient.radial(
      ..color.map.viridis,
    )),
    circle(fill: gradient.radial(
      ..color.map.viridis,
      focal-center: (10%, 40%),
      focal-radius: 5%,
    )),
  )
`}

/>

</details>

  space: auto | spot | function,

  radius: ratio,
  focal-center: auto | array,

#### `space` [#definitions-radial-space]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [spot](/docs/typst/reference/visualize/color#definitions-spot) или [function](/docs/typst/reference/foundations/function) · **По умолчанию:** `auto`

Цветовое пространство, в котором интерполируется градиент.

По умолчанию используется перцептивно равномерное цветовое пространство под названием [Oklab](/docs/typst/reference/visualize/color#definitions-oklab).

#### `relative` [#definitions-radial-relative]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [str](/docs/typst/reference/foundations/str) · **По умолчанию:** `auto`

[Относительное размещение](#relativeness) градиента.

Родителем элемента является самый внутренний [`box`](/docs/typst/reference/layout/box) или [`block`](/docs/typst/reference/layout/block), содержащий элемент, или, если такового нет, сама страница.

| **Вариант** | **Описание** |
| --- | --- |
| `"self"` | Относительно самого себя (собственной ограничивающей рамки). |
| `"parent"` | Относительно родителя (ограничивающей рамки родителя). |

#### `center` [#definitions-radial-center]

**Тип:** [array](/docs/typst/reference/foundations/array) · **По умолчанию:** `(50%, 50%)`

Центр конечной окружности градиента.

Значение `(50%, 50%)` означает, что конечная окружность центрирована внутри своего контейнера.

#### `radius` [#definitions-radial-radius]

**Тип:** [ratio](/docs/typst/reference/layout/ratio) · **По умолчанию:** `50%`

Радиус конечной окружности градиента.

По умолчанию установлен в `50%`. Конечный радиус должен быть больше фокального радиуса.

#### `focal-center` [#definitions-radial-focal-center]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [array](/docs/typst/reference/foundations/array) · **По умолчанию:** `auto`

Центр фокальной окружности градиента.

Фокальный центр должен находиться внутри конечной окружности.

Значение `(50%, 50%)` означает, что фокальная окружность центрирована внутри своего контейнера.

По умолчанию устанавливается таким же, как центр последней окружности.

#### `focal-radius` [#definitions-radial-focal-radius]

**Тип:** [ratio](/docs/typst/reference/layout/ratio) · **По умолчанию:** `0%`

Радиус фокальной окружности градиента.

Фокальный центр должен находиться внутри конечной окружности.

По умолчанию установлен в `0%`. Фокальный радиус должен быть меньше конечного радиуса.
