<span id="summary" />

*Since: forever*

Цвет в определённом цветовом пространстве.

Typst поддерживает:

- sRGB через [функцию `rgb`](#definitions-rgb)
- Device CMYK через [функцию `cmyk`](#definitions-cmyk)
- D65 Gray через [функцию `luma`](#definitions-luma)
- Oklab через [функцию `oklab`](#definitions-oklab)
- Oklch через [функцию `oklch`](#definitions-oklch)
- Linear RGB через [функцию `color.linear-rgb`](#definitions-linear-rgb)
- HSL через [функцию `color.hsl`](#definitions-hsl)
- HSV через [функцию `color.hsv`](#definitions-hsv)
- Цветовые пространства, описываемые плашечными красителями, через [тип `color.spot`](#definitions-spot)

Все цветовые пространства, кроме CMYK и плашечных красителей, имеют альфа-каналы.

В документации мы используем термин _process color_ (триадный цвет) для цветов, которые можно смешивать друг с другом (в настоящее время все цвета, кроме плашечных). В этом термине _process_ означает, что оттенок создаётся в процессе печати, а не заранее.

## Предопределённые цвета [#predefined-colors]

Typst определяет следующие встроенные цвета:

| **Цвет** | **Определение** |
| --- | --- |
| `black` | `luma(0)` |
| `gray` | `luma(170)` |
| `silver` | `luma(221)` |
| `white` | `luma(255)` |
| `navy` | `rgb("#001f3f")` |
| `blue` | `rgb("#0074d9")` |
| `aqua` | `rgb("#7fdbff")` |
| `teal` | `rgb("#39cccc")` |
| `eastern` | `rgb("#239dad")` |
| `purple` | `rgb("#b10dc9")` |
| `fuchsia` | `rgb("#f012be")` |
| `maroon` | `rgb("#85144b")` |
| `red` | `rgb("#ff4136")` |
| `orange` | `rgb("#ff851b")` |
| `yellow` | `rgb("#ffdc00")` |
| `olive` | `rgb("#3d9970")` |
| `green` | `rgb("#2ecc40")` |
| `lime` | `rgb("#01ff70")` |

Предопределённые цвета и наиболее важные конструкторы цветов доступны глобально, а также в области видимости типа color, поэтому вы можете писать как `color.red`, так и просто `red`.

### `map` [#definitions-map]

*Since: 0.9.0* · **Тип:** [module](/docs/typst/reference/foundations/module)

Набор предустановленных цветовых карт, которые можно использовать для [градиентов](/docs/typst/reference/visualize/gradient#stops). Это просто массивы цветов.

<details open>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  #circle(fill: gradient.linear(..color.map.crest))
`}
  image="/typst_docs_assets/images/xPjaEuxsNYx5_m83vIu5lw.png"
  alt=""
  editable={true}
/>

</details>

| **Карта** | **Подробности** |
| --- | --- |
| `turbo` | Перцептивно равномерная радужная цветовая карта. Подробнее читайте в [этом сообщении блога](https://ai.googleblog.com/2019/08/turbo-improved-rainbow-colormap-for.html). |
| `cividis` | Цветовая карта от синего через серый к жёлтому. Подробнее см. в [этом сообщении блога](https://bids.github.io/colormap/). |
| `rainbow` | Циклически проходит через весь цветовой спектр. Эту цветовую карту лучше всего использовать, установив цветовое пространство интерполяции в [HSL](#definitions-hsl). Радужный градиент **не подходит** для визуализации данных, поскольку он не является перцептивно равномерным, поэтому различия между значениями становятся неясными для ваших читателей. Его следует использовать только в декоративных целях. |
| `spectral` | Цветовая карта от красного через жёлтый к синему. |
| `viridis` | Цветовая карта от фиолетового через бирюзовый к жёлтому. |
| `inferno` | Цветовая карта от чёрного через красный к жёлтому. |
| `magma` | Цветовая карта от чёрного через фиолетовый к жёлтому. |
| `plasma` | Цветовая карта от фиолетового через розовый к жёлтому. |
| `rocket` | Цветовая карта от чёрного через красный к белому. |
| `mako` | Цветовая карта от чёрного через бирюзовый к белому. |
| `coolwarm` | Цветовая карта от синего через белый к красному с плавными переходами. |
| `vlag` | Цветовая карта от светло-синего через белый к красному. |
| `icefire` | Цветовая карта от светло-бирюзового через чёрный к оранжевому. |
| `flare` | Перцептивно равномерная цветовая карта от оранжевого к фиолетовому. |
| `crest` | Цветовая карта от светло-зелёного к синему. |

Некоторые популярные предустановки не включены, поскольку они недоступны по бесплатной лицензии. Другие, например [Jet](https://jakevdp.github.io/blog/2014/10/16/how-bad-is-your-colormap/), не включены, поскольку они неудобны для людей с нарушениями цветового зрения. Не стесняйтесь использовать или создавать пакет с другими предустановками, которые вам полезны!

### `luma` [#definitions-luma]

*Since: forever*

Создаёт оттенок серого.

Оттенок серого представляется компонентом светлоты и альфа-компонентом.

Значения этих компонентов можно получить для существующего цвета luma с помощью метода [`components`](#definitions-components).

### `oklab` [#definitions-oklab]

*Since: 0.9.0*

Создаёт цвет [Oklab](https://bottosson.github.io/posts/oklab/).

Это цветовое пространство хорошо подходит для следующих случаев использования:

- Манипуляции с цветом, например повышение насыщенности при сохранении воспринимаемого оттенка
- Создание изображений в оттенках серого с равномерной воспринимаемой светлотой
- Создание плавных и равномерных цветовых переходов и градиентов

Линейный цвет Oklab представляется четырьмя компонентами: светлота ($L$), $a$, $b$ и альфа.

Значения этих компонентов можно получить для существующего цвета Oklab с помощью метода [`components`](#definitions-components).

### `linear-rgb` [#definitions-linear-rgb]

*Since: 0.9.0*

Создаёт цвет RGB(A) с линейной светлотой.

Это цветовое пространство похоже на sRGB, но с тем отличием, что компоненты цвета не гамма-корректированы. Это упрощает выполнение цветовых операций, таких как смешивание и интерполяция. Тем не менее для этих целей предпочтительнее использовать [функцию `oklab`](#definitions-oklab).

Линейный цвет RGB(A) представляется четырьмя компонентами: красный, зелёный, синий и альфа.

Значения этих компонентов можно получить для существующего линейного цвета RGB(A) с помощью метода [`components`](#definitions-components).

### `rgb` [#definitions-rgb]

*Since: forever*

Создаёт цвет RGB(A).

Цвет RGB(A) представляется четырьмя компонентами: красный, зелёный, синий и альфа.

### `components` [#definitions-components]

*Since: 0.9.0*

Извлекает компоненты цвета.

Размер и значения этого массива зависят от цветового пространства. Цветовое пространство можно получить с помощью метода [`space`](#definitions-space). Ниже приведена таблица цветовых пространств и их компонентов.

| **Цветовое пространство** | **C0** | **C1** | **C2** | **C3** |
| --- | --- | --- | --- | --- |
| [`luma`](#definitions-luma) | Светлота | Альфа |  |  |
| [`oklab`](#definitions-oklab) | Светлота ($L$) | $a$ | $b$ | Альфа |
| [`oklch`](#definitions-oklch) | Светлота ($L$) | Цветность ($C$) | Оттенок ($h$) | Альфа |
| [`linear-rgb`](#definitions-linear-rgb) | Красный | Зелёный | Синий | Альфа |
| [`rgb`](#definitions-rgb) | Красный | Зелёный | Синий | Альфа |
| [`cmyk`](#definitions-cmyk) | Голубой | Пурпурный | Жёлтый | Ключевой |
| [`hsl`](#definitions-hsl) | Оттенок | Насыщенность | Светлота | Альфа |
| [`hsv`](#definitions-hsv) | Оттенок | Насыщенность | Значение | Альфа |
| [`spot`](#definitions-spot) | Тинт |  |  |  |

Значение и тип каждого отдельного значения см. в документации соответствующего цветового пространства. Длина возвращаемого массива зависит от количества компонентов и от того, включён ли альфа-компонент.

## Типы [#types]

### `spot` [#definitions-spot]

*Since: 0.15.0*

Плашечный краситель, из которого можно создавать плашечные цвета.

Используйте плашечные цвета, чтобы запросить точный пигмент в профессиональной печатной среде. Создав плашечный краситель, вы можете создавать цвета с помощью его [метода `tint`](#definitions-spot-definitions-tint).

#### Конструктор [#constructor]

Создаёт новый плашечный краситель.

```typst
color.spot(
  none | str,
  color,
) -> spot
```

##### `name` [#constructor-name]

**Тип:** [none](/docs/typst/reference/foundations/none) или [str](/docs/typst/reference/foundations/str) · **Модификаторы:** Обязательный, Позиционный

Имя используемого плашечного красителя.

В производстве это имя будет проверено вручную и сопоставлено с красителем, поэтому это значение должно быть однозначным. Лучше всего ссылаться на цвет из реестра, такого как PANTONE, HKS, RAL, Toyo & DIC и т. д.

Значения здесь могут обрабатываться с учётом регистра во время производства: `"PANTONE 2221 C"` и `"PANTONE 2221 c"` могут считаться разными цветами. Убедитесь, что вы используете последовательное соглашение об именовании, либо ссылаясь на реестр, либо согласовав это с вашими экспертами по производственной печати.

Если это значение равно `"all"` и ваша печать будет включать несколько [цветовых форм](https://en.wikipedia.org/wiki/Offset_printing#Plates), использование этого красителя приведёт к тому, что указанный тинт будет применён одинаково ко всем формам. Если вы выберете `none`, при использовании этого цвета краситель не будет применён. Это специальное значение часто используется для обозначения высечек или лаков. Обязательно обсудите это с вашим производственным принтером!

Мы не рекомендуем использовать имена `"Cyan"`, `"Magenta"`, `"Yellow"`, `"Key"`, `"Black"` или их переводы на ваш местный язык. В зависимости от вашего принтера они могут или не могут интерпретироваться как триадные цвета CMYK.

| **Вариант** | **Подробности** |
| --- | --- |
| `"all"` | Использовать все доступные цветовые формы вместо только конкретного красителя. |

##### `fallback` [#constructor-fallback]

**Тип:** [color](/docs/typst/reference/visualize/color) · **Модификаторы:** Обязательный, Позиционный

Как отображать этот цвет, если указанный краситель недоступен.

Многие носители, такие как предварительный просмотр на экране и бытовые принтеры, не будут иметь этого конкретного плашечного красителя. Чтобы отобразить приближение предполагаемой печати, вместо него используется другой доступный цвет.
