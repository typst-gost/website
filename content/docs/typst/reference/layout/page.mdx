<span id="summary" />

*Элемент* · *Доступно с: всегда*

Размещает своё содержимое на одной или нескольких страницах.

Хотя эта функция в первую очередь используется в правилах set для настройки свойств страницы, её также можно применять для явного размещения аргумента на собственном наборе страниц.

Для ширины или высоты страниц можно задать значение `auto`. В этом случае страницы будут увеличиваться, чтобы вместить своё содержимое по соответствующей оси.

В [руководстве по настройке страницы](/docs/typst/guides/page-setup) объясняется, как использовать эту и связанные с ней функции для настройки документа, с множеством примеров.

## Пример [#example]

  #set page("us-letter")

  There you go, US friends!
`}

## Доступность [#accessibility]

Содержимое верхнего колонтитула, нижнего колонтитула, переднего и заднего планов страницы невидимо для вспомогательных технологий (AT), таких как программы чтения с экрана. Вспомогательные технологии читают только основное содержимое страницы. Не размещайте в этих областях важную информацию, которая не встречается в других местах документа.

## Стилизация [#styling]

Обратите внимание, что на элемент [`page`](/docs/typst/reference/layout/page) нельзя нацеливать правила show; запись `show page: ..` не даёт эффекта. Чтобы повторять содержимое на каждой странице, вместо этого можно настроить свойства [`header`](#parameters-header), [`footer`](#parameters-footer), [`background`](#parameters-background) и [`foreground`](#parameters-foreground) с помощью правила set.

## Параметры [#parameters]

```typst
page(
  paper: str,
  width: auto | length,
  height: auto | length,
  flipped: bool,
  margin: auto | relative | dictionary,
  bleed: relative | dictionary,
  binding: auto | alignment,
  columns: int,
  fill: none | auto | color | gradient | tiling,
  numbering: none | str | function,
  supplement: none | auto | content,
  number-align: alignment,
  header: none | auto | content,
  header-ascent: relative,
  footer: none | auto | content,
  footer-descent: relative,
  background: none | content,
  foreground: none | content,
  content,
)
```

Это всего лишь сокращение для задания `width` и `height`, и поэтому его нельзя получить в контекстном выражении.

### `width` [#parameters-width]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [length](/docs/typst/reference/layout/length) · **Модификаторы:** Settable · **По умолчанию:** `595.28pt`

Ширина итоговой страницы после применения всех обрезок.

В профессиональных типографских настройках это значение может быть меньше размера листа, подаваемого в принтер.

Подробнее о том, как задать область обрезки или вылета, см. параметр [`bleed`](#parameters-bleed).

### `height` [#parameters-height]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [length](/docs/typst/reference/layout/length) · **Модификаторы:** Settable · **По умолчанию:** `841.89pt`

Высота итоговой области страницы после применения всех обрезок.

Если задано значение `auto`, разрывы страниц можно вызывать только вручную, вставляя [разрыв страницы](/docs/typst/reference/layout/pagebreak) или добавляя другое непустое правило set для страницы. В большинстве примеров в этой документации для высоты страницы используется `auto`, чтобы она динамически увеличивалась и уменьшалась в соответствии с содержимым.

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `false`

Переворачивается ли страница в альбомную ориентацию.

### `margin` [#parameters-margin]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [relative](/docs/typst/reference/layout/relative) или [dictionary](/docs/typst/reference/foundations/dictionary) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Поля страницы.

- `auto`: Поля автоматически устанавливаются равными 2.5/21 от меньшего размера страницы. Для страницы A4 это даёт поля в 2.5 см.
- Одно значение длины: одинаковое поле со всех сторон.
- Словарь: с помощью словаря поля можно задать по отдельности. Словарь может содержать следующие ключи в порядке приоритета:
  - `top`: верхнее поле.
  - `right`: правое поле.
  - `bottom`: нижнее поле.
  - `left`: левое поле.
  - `inside`: поле с внутренней стороны страницы (там, где находится [переплёт](#parameters-binding)).
  - `outside`: поле с внешней стороны страницы (напротив [переплёта](#parameters-binding)).
  - `x`: горизонтальные поля.
  - `y`: вертикальные поля.
  - `rest`: поля со всех сторон, кроме тех, для которых словарь явно задаёт размер.

Все ключи необязательны; для пропущенных ключей используется ранее заданное значение или значение поля по умолчанию, если оно никогда не задавалось. Кроме того, значения `left` и `right` взаимоисключающи со значениями `inside` и `outside`. Значения должны быть относительными длинами или `auto`.

### `bleed` [#parameters-bleed]

**Тип:** [relative](/docs/typst/reference/layout/relative) или [dictionary](/docs/typst/reference/foundations/dictionary) · **Модификаторы:** Settable · **По умолчанию:** `(:)`

Поле вылета страницы.

Вылет — это область содержимого, выходящая за пределы итогового обрезанного размера страницы. Он гарантирует, что в готовом изделии не появятся неотпечатанные края, даже если при обрезке возникнут небольшие смещения.

Допустимые значения:

- Одно значение длины: одинаковый вылет со всех сторон.
- Словарь: с помощью словаря поля вылета можно задать по отдельности. Словарь может содержать следующие ключи в порядке приоритета:
  - `top`: верхнее поле вылета.
  - `right`: правое поле вылета.
  - `bottom`: нижнее поле вылета.
  - `left`: левое поле вылета.
  - `inside`: поле вылета с внутренней стороны страницы (там, где находится [переплёт](#parameters-binding)).
  - `outside`: поле вылета с внешней стороны страницы (напротив [переплёта](#parameters-binding)).
  - `x`: горизонтальные поля вылета.
  - `y`: вертикальные поля вылета.
  - `rest`: поля вылета со всех сторон, кроме тех, для которых словарь явно задаёт размер.

Все ключи необязательны; для пропущенных ключей используется ранее заданное значение или `0pt`, если оно никогда не задавалось. Кроме того, значения `left` и `right` взаимоисключающи со значениями `inside` и `outside`. Значения должны быть относительными длинами.

При экспорте в PDF, если вылет не равен нулю, для страницы определяется `TrimBox`.

### `binding` [#parameters-binding]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [alignment](/docs/typst/reference/layout/alignment) · **Модификаторы:** Settable · **По умолчанию:** `auto`

С какой стороны будут переплетены страницы.

- `auto`: эквивалентно `left`, если [направление текста](/docs/typst/reference/text/text#parameters-dir) — слева направо, и `right`, если справа налево.
- `left`: переплёт с левой стороны.
- `right`: переплёт с правой стороны.

Это влияет на смысл параметров `inside` и `outside` для полей.

### `columns` [#parameters-columns]

**Тип:** [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Settable · **По умолчанию:** `1`

Сколько столбцов на странице.

Если вам нужно вставить столбцы на страницу или в другой контейнер, вы также можете использовать [функцию `columns`](/docs/typst/reference/layout/columns).

<TypstRender
  code={`
  #set page(columns: 2, height: 4.8cm)
  Climate change is one of the most
  pressing issues of our time, with
  the potential to devastate
  communities, ecosystems, and
  economies around the world. It's
  clear that we need to take urgent
  action to reduce our carbon
  emissions and mitigate the impacts

### `fill` [#parameters-fill]

**Тип:** [none](/docs/typst/reference/foundations/none) или [auto](/docs/typst/reference/foundations/auto) или [color](/docs/typst/reference/visualize/color) или [gradient](/docs/typst/reference/visualize/gradient) или [tiling](/docs/typst/reference/visualize/tiling) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Заливка фона страницы.

Установка нетранспарентного значения указывает принтеру окрашивать страницу целиком. Если вы рассматриваете крупносерийное производство, может оказаться более экологичным и экономически выгодным использовать предварительно окрашенную бумагу и не задавать это свойство.

### `numbering` [#parameters-numbering]

**Тип:** [none](/docs/typst/reference/foundations/none) или [str](/docs/typst/reference/foundations/str) или [function](/docs/typst/reference/foundations/function) · **Модификаторы:** Settable · **По умолчанию:** `none`

Как нумеровать страницы. О настройке номеров страниц см. в руководстве по настройке страницы, раздел [настройка номеров страниц](/docs/typst/guides/page-setup#page-numbers).

Принимает [шаблон нумерации или функцию](/docs/typst/reference/model/numbering), принимающую одно или два числа:

1. Первое число — текущий номер страницы.
2. Второе число — общее количество страниц. В шаблоне нумерации второе число можно опустить. Если передаётся функция, она получит один аргумент в контексте ссылок или перекрёстных ссылок и два аргумента при формировании видимых номеров страниц.

Это логические номера, управляемые счётчиком страниц, и поэтому они могут не совпадать с физическими номерами. В частности, это [текущее](/docs/typst/reference/introspection/counter#definitions-get) и [итоговое](/docs/typst/reference/introspection/counter#definitions-final) значения `counter(page)`. Подробнее см. документацию по [`counter`](/docs/typst/reference/introspection/counter#page-counter).

Если задан явный [`footer`](#parameters-footer) (или [`header`](#parameters-header) для нумерации [с выравниванием по верху](#parameters-number-align)), нумерация игнорируется.

  #lorem(48)
`}

### `footer` [#parameters-footer]

### `background` [#parameters-background]

**Тип:** [none](/docs/typst/reference/foundations/none) или [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Settable · **По умолчанию:** `none`

Содержимое на заднем плане страницы.

Это содержимое размещается за основным содержимым страницы. Его можно использовать для размещения фонового изображения или водяного знака.

Для удобства содержимое заднего плана позиционируется относительно страницы, расширенной её [вылетом](#parameters-bleed). Например, выравнивание `top + left` размещает содержимое в верхнем левом углу области вылета, а не страницы.

Аналогично, [относительные длины](/docs/typst/reference/layout/relative) при использовании в содержимом заднего плана вычисляются относительно размера страницы плюс вылет. Например, на странице шириной `100mm` с дополнительным вылетом `5mm` с каждой стороны ширина `100%` вычисляется как `5mm + 100mm + 5mm`.

  code={`
  #set page(background: rotate(24deg,
    text(18pt, fill: rgb("FFCBC4"))[
      *CONFIDENTIAL*
    ]
  ))

  = Typst's secret plans
  In the year 2023, we plan to take
  over the world (of typesetting).
`}

### `body` [#parameters-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Содержимое страницы (страниц).

Если содержимое не помещается на одну страницу, будет создано несколько страниц. После набора основного содержимого будет создана новая страница со свойствами страницы, действовавшими до вызова функции.
