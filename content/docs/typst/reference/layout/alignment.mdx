<span id="summary" />

*Since: forever*

Где выравнивать что-либо вдоль оси.

Возможные значения:

- Горизонтальные выравнивания: [`start`](#definitions-start), [`end`](#definitions-end), [`left`](#definitions-left), [`center`](#definitions-center) и [`right`](#definitions-right).
- Вертикальные выравнивания: [`top`](#definitions-top), [`horizon`](#definitions-horizon) и [`bottom`](#definitions-bottom).
- [2D-выравнивания](#loc-1), например `center + horizon`.

Эти значения доступны глобально, а также в области видимости типа alignment, поэтому вы можете написать любой из следующих двух вариантов:

<TypstRender
  code={`
  #align(center)[Hi]
  #align(alignment.center)[Hi]
`}
  image="/typst_docs_assets/images/jB_l01kNOnHHM9RqWf9Lqg.png"
  alt=""
  editable={true}
/>

## 2D-выравнивания [#loc-1]

Чтобы выровнять одновременно по обеим осям, сложите два выравнивания с помощью оператора `+`. Например, `top + right` выравнивает содержимое по правому верхнему углу.

<TypstRender
  code={`
  #set page(height: 3cm)
  #align(center + bottom)[Hi]
`}
  image="/typst_docs_assets/images/FbFJ0yqgUHxxCrbEOHsxVw.png"
  alt=""
  editable={true}
/>

## Поля [#fields]

Поля `x` и `y` содержат горизонтальную и вертикальную составляющие выравнивания соответственно (как ещё один `alignment`). Они могут быть `none`.

<TypstRender
  code={`
  #(top + right).x \\
  #left.x \\
  #left.y (none)
`}
  image="/typst_docs_assets/images/3kebbaoygcYRZHgnCD_KxQ.png"
  alt=""
  editable={true}
/>

## Функции [#functions]

### `axis` [#definitions-axis]

*Since: 0.7.0*

Ось, к которой относится это выравнивание.

- `"horizontal"` для `start`, `left`, `center`, `right` и `end`
- `"vertical"` для `top`, `horizon` и `bottom`
- `none` для двумерных выравниваний

<details open>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  #left.axis() \\
  #bottom.axis()
`}
  image="/typst_docs_assets/images/SKgAG0Uup_6qLdpZEMqKQQ.png"
  alt=""
  editable={true}
/>

</details>

```typst
self.axis() -> none | str
```
