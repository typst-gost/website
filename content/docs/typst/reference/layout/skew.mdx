<span id="summary" />

*Элемент* · *Доступно с: 0.12.0*

Наклоняет содержимое.

Наклоняет элемент в горизонтальном и/или вертикальном направлении. Макет будет вести себя так, как если бы элемент не был наклонён, если только вы не укажете `reflow: true`.

## Пример [#example]

<TypstRender
  code={`
  #skew(ax: -12deg)[
    This is some fake italic text.
  ]
`}

  alt=""

## Параметры [#parameters]

```typst
skew(
  ax: angle,
  ay: angle,
  origin: alignment,
  reflow: bool,
  content,
)
```

### `ax` [#parameters-ax]

**Тип:** [angle](/docs/typst/reference/layout/angle) · **Модификаторы:** Settable · **По умолчанию:** `0deg`

Угол горизонтального наклона.

### `origin` [#parameters-origin]

**Тип:** [alignment](/docs/typst/reference/layout/alignment) · **Модификаторы:** Settable · **По умолчанию:** `center + horizon`

Начало преобразования наклона.

Начало остаётся неподвижным во время операции.

### `reflow` [#parameters-reflow]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `false`

Влияет ли преобразование наклона на макет.

Если установлено значение `false`, наклонённое содержимое сохранит ограничивающую рамку исходного содержимого. Если установлено значение `true`, ограничивающая рамка будет учитывать преобразование содержимого и соответствующим образом корректировать макет.

<details>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`

`}
  image="/typst_docs_assets/images/CDjCr0RcMEeqZlt76vc2Ug.png"
  alt=""
  editable={true}
/>

</details>

### `body` [#parameters-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Required, Positional

Содержимое для наклона.
