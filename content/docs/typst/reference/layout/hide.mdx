<span id="summary" />

*Элемент* · *С версии: forever*

Скрывает содержимое, не влияя на макет.

Функция `hide` позволяет скрыть содержимое, при этом макет по-прежнему «видит» его. Это полезно для создания пустого пространства, точно равного размеру некоторого содержимого.

## Сокрытие информации [#redaction]

Эта функция также может быть полезна для сокрытия информации, поскольку её аргументы ни визуально не отображаются, ни доступны вспомогательным технологиям. Тем не менее, могут оставаться _некоторые_ следы скрытого содержимого (например, закладка заголовка в структуре документа PDF).

Обратите внимание, что в зависимости от обстоятельств содержимое может быть восстановлено на основе его размера в макете. Поэтому мы не рекомендуем использовать эту функцию для сокрытия особо чувствительной информации.

## Параметры [#parameters]

```typst
hide(content)
```

### `body` [#parameters-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Содержимое, которое нужно скрыть.
