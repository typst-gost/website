<span id="summary" />

*Since: forever*

Угол, описывающий поворот.

Typst поддерживает следующие угловые единицы:

- Градусы: `180deg`
- Радианы: `3.14rad`

## Пример [#example]

## Функции [#functions]

### `rad` [#definitions-rad]

*Since: 0.7.0*

Преобразует этот угол в радианы.

```typst
self.rad() -> float
```

### `deg` [#definitions-deg]

*Since: 0.7.0*

Преобразует этот угол в градусы.

```typst
self.deg() -> float
```
