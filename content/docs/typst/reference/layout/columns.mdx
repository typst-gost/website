<span id="summary" />

*Элемент* · *Доступно с: всегда*

Разделяет область на несколько столбцов одинакового размера.

Функция `columns` позволяет разделить содержимое любого контейнера на несколько столбцов. По умолчанию столбцы занимают высоту своего контейнера или оставшуюся высоту страницы и заполняются один за другим. Используйте [`colbreak`](/docs/typst/reference/layout/colbreak), чтобы явно завершить столбец и продолжить в следующем. Используйте [параметр `balanced`](#parameters-balanced), чтобы автоматически выровнять высоту столбцов.

## Пример [#example]

<TypstRender
  code={`
  #columns(2, gutter: 8pt)[
    This text is in the
    first column.

    #colbreak()

    This text is in the
    second column.
  ]
`}

## Столбцы на уровне страницы [#page-level]

Если вам нужно вставить столбцы по всему документу, используйте вместо этого [параметр `columns`](/docs/typst/reference/layout/page#parameters-columns) функции `page`. Это создаст столбцы непосредственно на уровне страницы, а не обернёт всё ваше содержимое в контейнер компоновки. В результате такие элементы, как [разрывы страниц](/docs/typst/reference/layout/pagebreak), [сноски](/docs/typst/reference/model/footnote) и [номера строк](/docs/typst/reference/model/par#definitions-line), продолжат работать как ожидается. Для получения дополнительной информации также прочитайте [соответствующий раздел руководства по настройке страницы](/docs/typst/guides/page-setup#columns).

## Выход за пределы столбцов [#breaking-out]

Чтобы временно выйти за пределы столбцов (например, для заголовка статьи), используйте плавающее размещение с родительской областью видимости:

<TypstRender
  code={`
  #set page(columns: 2, height: 150pt)

  #place(
    top + center,
    scope: "parent",
    float: true,
    text(1.4em, weight: "bold")[
      My document
    ],
  )

  #lorem(40)
`}
  image="/typst_docs_assets/images/Z8ZNPK63hYVpB-lOuErsdw.png"
  alt=""
  editable={true}
/>

## Параметры [#parameters]

```typst
columns(
  int,
  gutter: relative,
  balanced: bool,
  separator: none | content,
  content,
)
```

### `count` [#parameters-count]

**Тип:** [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Позиционный, Устанавливаемый · **По умолчанию:** `2`

Количество столбцов.

### `gutter` [#parameters-gutter]

**Тип:** [relative](/docs/typst/reference/layout/relative) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `4% + 0pt`

Размер промежутка между столбцами.

</details>

### `balanced` [#parameters-balanced]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `false`

Следует ли выравнивать высоту столбцов путём досрочного завершения столбцов.

### `separator` [#parameters-separator]

**Тип:** [none](/docs/typst/reference/foundations/none) или [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `none`

Разделитель, размещаемый между каждой парой непустых столбцов.

По умолчанию содержимое центрируется, а [линии](/docs/typst/reference/visualize/line) используют длину `100%` и угол `90deg`, если не указано иное.

    gutter: 2em,
    separator: line(),

### `body` [#parameters-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Содержимое, которое должно быть размещено в столбцах.
