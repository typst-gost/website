<span id="summary" />

*Элемент* · *Доступно: всегда*

Повторяет содержимое до доступного пространства.

Это может быть полезно при реализации пользовательского указателя, справочника или оглавления.

Пространство может быть вставлено между экземплярами параметра body, поэтому обязательно настройте параметр [`justify`](#parameters-justify) соответствующим образом.

Выдаёт ошибку, если доступное пространство не ограничено, так как это создало бы бесконечное содержимое.

## Доступность [#accessibility]

Повторяющееся содержимое автоматически помечается как [артефакт](/docs/typst/reference/format/pdf/artifact) и скрывается от вспомогательных технологий (AT). Не используйте эту функцию для создания содержимого, которое вносит вклад в смысл вашего документа.

## Параметры [#parameters]

```typst
repeat(
  content,
  gap: length,
  justify: bool,
)
```

### `body` [#parameters-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Содержимое для повторения.

### `gap` [#parameters-gap]

**Тип:** [length](/docs/typst/reference/layout/length) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `0pt`

Промежуток между каждым экземпляром body.

### `justify` [#parameters-justify]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `true`

Увеличивать ли промежуток между экземплярами, чтобы полностью заполнить доступное пространство.
