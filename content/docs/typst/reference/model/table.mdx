<span id="summary" />

*Элемент* · *Locatable* · *Since: forever*

Таблица элементов.

Таблицы используются для упорядочивания содержимого в ячейках. Ячейки могут содержать произвольное содержимое, включая несколько абзацев, и задаются в порядке построчного заполнения. Подробное объяснение всех способов использования и настройки таблиц в Typst см. в [руководстве по таблицам](/docs/typst/guides/tables).

Поскольку таблицы — это просто сетки с другими значениями по умолчанию для некоторых свойств ячеек (в частности, `stroke` и `inset`), обратитесь к [документации по сеткам](/docs/typst/reference/layout/grid#track-size) для получения дополнительной информации о том, как задавать размеры дорожек таблицы и указывать свойства внешнего вида ячеек.

Если вы не уверены, стоит ли использовать таблицу или сетку, подумайте, принадлежит ли содержимое, которое вы упорядочиваете, семантически к одному набору связанных точек данных или подобному, или вы просто хотите улучшить презентацию, расположив несвязанное содержимое в сетке. В первом случае таблица — правильный выбор, а во втором более уместна сетка. Кроме того, вспомогательные технологии (AT), такие как программы чтения с экрана, будут объявлять содержимое `table` как табличное, тогда как содержимое сетки будет объявляться так же, как несколько блоков содержимого в потоке документа. Пользователи AT смогут перемещаться по таблицам в двух измерениях по ячейкам.

Обратите внимание, что для переопределения свойств конкретной ячейки или применения правил show к ячейкам таблицы можно использовать элемент [`table.cell`](#definitions-cell). Дополнительную информацию см. в его документации.

Хотя `table` и `grid` имеют большинство общих свойств, правила set и show для одного из них не влияют на другой. Рекомендуется размещать большую часть стилизации в правилах set и show, так как это сохраняет фактическое использование таблицы чистым и легко читаемым. Это также позволяет легко изменять внешний вид всех таблиц в одном месте.

Чтобы добавить таблице подпись и сделать её [доступной для ссылок](/docs/typst/reference/model/ref), поместите её в [figure](/docs/typst/reference/model/figure).

Подобно сеткам, вы можете использовать [`table.cell`](#definitions-cell) для настройки внешнего вида и положения каждой ячейки.

<TypstRender
  code={`
  #set table(
    stroke: none,
    gutter: 0.2em,
    fill: (x, y) =>
  if x == 0 or y == 0 { gray },
    inset: (right: 1.5em),
  )

  #show table.cell: it => {
    if it.x == 0 or it.y == 0 {
      set text(white)
      strong(it)
    } else if it.body == [] {
      // Replace empty cells with 'N/A'
  pad(..it.inset)[_N/A_]
    } else {
      it
    }
  }

  #let a = table.cell(
    fill: green.lighten(60%),
  )[A]
  #let b = table.cell(
    fill: aqua.lighten(60%),
  )[B]

  #table(
    columns: 4,
    [], [Exam 1], [Exam 2], [Exam 3],

    [John], [], a, [],
    [Mary], [], a, a,
    [Robert], b, a, b,
  )
`}

## Доступность [#accessibility]

Таблицы сложны для восприятия пользователями вспомогательных технологий (AT). Чтобы облегчить жизнь пользователям AT, мы настоятельно рекомендуем использовать [`table.header`](#definitions-header) и [`table.footer`](#definitions-footer) для разметки секций заголовка и нижнего колонтитула таблицы. Это позволит AT объявлять метки столбцов для каждой ячейки.

Поскольку навигация по таблице по ячейкам более громоздка, чем визуальное чтение, вам следует рассмотреть возможность сделать основную информацию вашей таблицы доступной также в виде текста. Вы можете сделать это, обернув таблицу в [figure](/docs/typst/reference/model/figure) и используя её подпись для обобщения содержимого таблицы.

## Параметры [#parameters]

```typst
table(
  columns: auto | int | relative | fraction | array,
  rows: auto | int | relative | fraction | array,
  gutter: auto | int | relative | fraction | array,
  column-gutter: auto | int | relative | fraction | array,
  row-gutter: auto | int | relative | fraction | array,
  inset: relative | array | dictionary | function,
  align: auto | array | function | alignment,
  fill: none | color | gradient | tiling | array | function,
  stroke: none | length | color | gradient | stroke | tiling | array | dictionary | function,
  ..content,
)
```

### `columns` [#parameters-columns]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [int](/docs/typst/reference/foundations/int) или [relative](/docs/typst/reference/layout/relative) или [fraction](/docs/typst/reference/layout/fraction) или [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Settable · **По умолчанию:** `()`

Размеры столбцов. Дополнительную информацию о задании размеров дорожек см. в [документации по сеткам](/docs/typst/reference/layout/grid#track-size).

### `rows` [#parameters-rows]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [int](/docs/typst/reference/foundations/int) или [relative](/docs/typst/reference/layout/relative) или [fraction](/docs/typst/reference/layout/fraction) или [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Settable · **По умолчанию:** `()`

Размеры строк. Дополнительную информацию о задании размеров дорожек см. в [документации по сеткам](/docs/typst/reference/layout/grid#track-size).

### `gutter` [#parameters-gutter]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [int](/docs/typst/reference/foundations/int) или [relative](/docs/typst/reference/layout/relative) или [fraction](/docs/typst/reference/layout/fraction) или [array](/docs/typst/reference/foundations/array) · **По умолчанию:** `()`

Промежутки между строками и столбцами. Это сокращение для установки `column-gutter` и `row-gutter` в одно и то же значение. Дополнительную информацию о промежутках см. в [документации по сеткам](/docs/typst/reference/layout/grid#parameters-gutter).

### `column-gutter` [#parameters-column-gutter]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [int](/docs/typst/reference/foundations/int) или [relative](/docs/typst/reference/layout/relative) или [fraction](/docs/typst/reference/layout/fraction) или [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Settable · **По умолчанию:** `()`

Промежутки между столбцами. Имеет приоритет над `gutter`. Дополнительную информацию о промежутках см. в [документации по сеткам](/docs/typst/reference/layout/grid#parameters-gutter).

### `row-gutter` [#parameters-row-gutter]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [int](/docs/typst/reference/foundations/int) или [relative](/docs/typst/reference/layout/relative) или [fraction](/docs/typst/reference/layout/fraction) или [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Settable · **По умолчанию:** `()`

Промежутки между строками. Имеет приоритет над `gutter`. Дополнительную информацию о промежутках см. в [документации по сеткам](/docs/typst/reference/layout/grid#parameters-gutter).

### `inset` [#parameters-inset]

**Тип:** [relative](/docs/typst/reference/layout/relative) или [array](/docs/typst/reference/foundations/array) или [dictionary](/docs/typst/reference/foundations/dictionary) или [function](/docs/typst/reference/foundations/function) · **Модификаторы:** Settable · **По умолчанию:** `0% + 5pt`

Насколько заполнить отступом содержимое ячеек.

Чтобы задать одинаковый inset для всех ячеек, используйте единую длину для всех сторон или словарь длин для отдельных сторон. Дополнительные сведения см. в [документации по box](/docs/typst/reference/layout/box#parameters-inset).

Чтобы задать разный inset для разных ячеек, вы можете:

- использовать единый, одинаковый inset для всех ячеек
- использовать массив inset для каждого столбца
- использовать функцию, которая отображает позицию ячейки по X/Y (обе начинаются с нуля) в её inset

Дополнительные сведения см. в [документации по сеткам](/docs/typst/reference/layout/grid#styling).

### `align` [#parameters-align]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [array](/docs/typst/reference/foundations/array) или [function](/docs/typst/reference/foundations/function) или [alignment](/docs/typst/reference/layout/alignment) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Как выравнивать содержимое ячеек.

Если установлено `auto`, используется внешнее выравнивание.

Вы можете задать выравнивание любым из следующих способов:

- использовать единое выравнивание для всех ячеек

- использовать функцию, которая отображает позицию ячейки по X/Y (обе начинаются с нуля) в её выравнивание

Подробности см. в [руководстве по таблицам](/docs/typst/guides/tables#alignment).

### `fill` [#parameters-fill]

**Тип:** [none](/docs/typst/reference/foundations/none) или [color](/docs/typst/reference/visualize/color) или [gradient](/docs/typst/reference/visualize/gradient) или [tiling](/docs/typst/reference/visualize/tiling) или [array](/docs/typst/reference/foundations/array) или [function](/docs/typst/reference/foundations/function) · **Модификаторы:** Settable · **По умолчанию:** `none`

- функция, которая отображает позицию ячейки в её заливку

### `stroke` [#parameters-stroke]

**Тип:** [none](/docs/typst/reference/foundations/none) или [length](/docs/typst/reference/layout/length) или [color](/docs/typst/reference/visualize/color) или [gradient](/docs/typst/reference/visualize/gradient) или [stroke](/docs/typst/reference/visualize/stroke) или [tiling](/docs/typst/reference/visualize/tiling) или [array](/docs/typst/reference/foundations/array) или [dictionary](/docs/typst/reference/foundations/dictionary) или [function](/docs/typst/reference/foundations/function) · **Модификаторы:** Settable · **По умолчанию:** `stroke()`

Как [обводить](/docs/typst/reference/visualize/stroke) ячейки.

Обводки можно отключить, установив для этого параметра значение `none`.

Если необходимо разместить линии, которые могут пересекать промежутки между ячейками, созданные параметром [`gutter`](#parameters-gutter), или переопределить обводку между несколькими конкретными ячейками, рассмотрите возможность указания одного или нескольких из [`table.hline`](#definitions-hline) и [`table.vline`](#definitions-vline) вместе с ячейками таблицы.

Чтобы задать одинаковую обводку для всех ячеек, используйте единую [обводку](/docs/typst/reference/visualize/stroke) для всех сторон или словарь [обводок](/docs/typst/reference/visualize/stroke) для отдельных сторон. Дополнительные сведения см. в [документации по rectangle](/docs/typst/reference/visualize/rect#parameters-stroke).

Чтобы задать разные обводки для разных ячеек, вы можете:

- использовать единую обводку для всех ячеек
- использовать массив обводок, соответствующих каждому столбцу
- использовать функцию, которая отображает позицию ячейки в её обводку

Дополнительные сведения см. в [руководстве по таблицам](/docs/typst/guides/tables#strokes).

### `children` [#parameters-children]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Required, Positional, Variadic

Содержимое ячеек таблицы, а также любые дополнительные линии таблицы, заданные элементами [`table.hline`](#definitions-hline) и [`table.vline`](#definitions-vline).

## Функции [#functions]

### `cell` [#definitions-cell]

*Элемент* · *Since: 0.11.0*

Ячейка в таблице. Используйте её для ручного позиционирования ячейки или для применения стилизации. Для последнего вы можете либо использовать функцию для переопределения свойств конкретной ячейки, либо использовать её в правилах show для применения определённых стилей к нескольким ячейкам сразу.

Пожалуй, наиболее важный вариант использования `table.cell` — сделать ячейку охватывающей несколько столбцов и/или строк с помощью полей `colspan` и `rowspan`.

**Тип:** [none](/docs/typst/reference/foundations/none) или [length](/docs/typst/reference/layout/length) или [color](/docs/typst/reference/visualize/color) или [gradient](/docs/typst/reference/visualize/gradient) или [stroke](/docs/typst/reference/visualize/stroke) или [tiling](/docs/typst/reference/visualize/tiling) или [dictionary](/docs/typst/reference/foundations/dictionary) · **Модификаторы:** Settable · **По умолчанию:** `(:)`

Переопределение [обводки](#parameters-stroke) для ячейки.

#### `breakable` [#definitions-cell-breakable]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Могут ли строки, охватываемые этой ячейкой, размещаться на разных страницах. Если равно `auto`, ячейка, охватывающая только строки фиксированного размера, является неразрывной, тогда как ячейка, охватывающая хотя бы одну строку размером `auto`, является разрывной.

### `hline` [#definitions-hline]

*Элемент* · *Since: 0.11.0*

Горизонтальная линия в таблице.

Переопределяет любую обводку отдельных ячеек, включая обводку, заданную через поле `stroke` таблицы. Может пересекать промежутки между ячейками, созданные параметром [`column-gutter`](#parameters-column-gutter) таблицы.

Используйте эту функцию вместо поля `stroke` таблицы, если вы хотите вручную разместить горизонтальную линию в определённой позиции в отдельной таблице. Рассмотрите возможность использования [поля `stroke` таблицы](#parameters-stroke) или [поля `stroke` у `table.cell`](#definitions-cell-stroke) вместо этого, если линия, которую вы хотите разместить, является частью дизайна всех ваших таблиц.

#### `y` [#definitions-hline-y]

Строка, над которой размещается горизонтальная линия (с нулевым индексом). Функционирует идентично полю `y` в [`grid.hline`](/docs/typst/reference/layout/grid#definitions-hline-y).

#### `start` [#definitions-hline-start]

**Тип:** [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Settable · **По умолчанию:** `0`

Столбец, с которого начинается горизонтальная линия (с нулевым индексом, включительно).

#### `end` [#definitions-hline-end]

**Тип:** [none](/docs/typst/reference/foundations/none) или [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Settable · **По умолчанию:** `none`

Столбец, перед которым заканчивается горизонтальная линия (с нулевым индексом, исключительно).

#### `stroke` [#definitions-hline-stroke]

**Тип:** [none](/docs/typst/reference/foundations/none) или [length](/docs/typst/reference/layout/length) или [color](/docs/typst/reference/visualize/color) или [gradient](/docs/typst/reference/visualize/gradient) или [stroke](/docs/typst/reference/visualize/stroke) или [tiling](/docs/typst/reference/visualize/tiling) или [dictionary](/docs/typst/reference/foundations/dictionary) · **Модификаторы:** Settable · **По умолчанию:** `stroke()`

Обводка линии.

Указание `none` удаляет любые линии, ранее размещённые в диапазоне этой линии, включая hline или обводку отдельных ячеек под ней.

#### `position` [#definitions-hline-position]

**Тип:** [alignment](/docs/typst/reference/layout/alignment) · **Модификаторы:** Settable · **По умолчанию:** `top`

Позиция, в которой размещается линия, относительно её строки (`y`) — либо `top`, чтобы нарисовать над ней, либо `bottom`, чтобы нарисовать под ней.

Этот параметр актуален только при включённом промежутке между строками (и не должен использоваться в противном случае — предпочтительнее просто увеличить поле `y` на единицу), поскольку тогда позиция под строкой становится отличной от позиции над следующей строкой из-за промежутка между ними.

### `vline` [#definitions-vline]

*Элемент* · *Since: 0.11.0*

Вертикальная линия в таблице. Дополнительную информацию о том, как использовать поля этого элемента, см. в документации по [`grid.vline`](/docs/typst/reference/layout/grid#definitions-vline).

Переопределяет любую обводку отдельных ячеек, включая обводку, заданную через поле `stroke` таблицы. Может пересекать промежутки между ячейками, созданные параметром [`row-gutter`](#parameters-row-gutter) таблицы.

Подобно [`table.hline`](#definitions-hline), используйте эту функцию, если вы хотите вручную разместить вертикальную линию в определённой позиции в отдельной таблице, и используйте [поле `stroke` таблицы](#parameters-stroke) или [поле `stroke` у `table.cell`](#definitions-cell-stroke) вместо этого, если линия, которую вы хотите разместить, является частью дизайна всех ваших таблиц.

#### `x` [#definitions-vline-x]

Столбец, перед которым размещается вертикальная линия (с нулевым индексом). Функционирует идентично полю `x` в [`grid.vline`](/docs/typst/reference/layout/grid#definitions-vline).

#### `start` [#definitions-vline-start]

**Тип:** [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Settable · **По умолчанию:** `0`

Строка, с которой начинается вертикальная линия (с нулевым индексом, включительно).

#### `end` [#definitions-vline-end]

**Тип:** [none](/docs/typst/reference/foundations/none) или [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Settable · **По умолчанию:** `none`

Строка, на которой заканчивается вертикальная линия (с нулевым индексом, исключительно).

#### `stroke` [#definitions-vline-stroke]

**Тип:** [none](/docs/typst/reference/foundations/none) или [length](/docs/typst/reference/layout/length) или [color](/docs/typst/reference/visualize/color) или [gradient](/docs/typst/reference/visualize/gradient) или [stroke](/docs/typst/reference/visualize/stroke) или [tiling](/docs/typst/reference/visualize/tiling) или [dictionary](/docs/typst/reference/foundations/dictionary) · **Модификаторы:** Settable · **По умолчанию:** `stroke()`

Обводка линии.

Указание `none` удаляет любые линии, ранее размещённые в диапазоне этой линии, включая vline или обводку отдельных ячеек под ней.

#### `position` [#definitions-vline-position]

**Тип:** [alignment](/docs/typst/reference/layout/alignment) · **Модификаторы:** Settable · **По умолчанию:** `start`

Позиция, в которой размещается линия, относительно её столбца (`x`) — либо `start`, чтобы нарисовать перед ним, либо `end`, чтобы нарисовать после него.

Значения `left` и `right` также принимаются, но не рекомендуются, так как они приводят к несогласованности вашей таблицы между документами с письмом слева направо и справа налево.

Этот параметр актуален только при включённом промежутке между столбцами (и не должен использоваться в противном случае — предпочтительнее просто увеличить поле `x` на единицу), поскольку тогда позиция после столбца становится отличной от позиции перед следующим столбцом из-за промежутка между ними.

### `header` [#definitions-header]

*Элемент* · *Since: 0.11.0*

Повторяемый заголовок таблицы.

Вам следует обернуть строки заголовка ваших таблиц в эту функцию, даже если вы не планируете разбивать таблицу по страницам, потому что Typst использует эту функцию для прикрепления метаданных доступности к таблицам и обеспечения [универсального доступа](/docs/typst/guides/accessibility#basics) к вашему документу.

Вы можете использовать параметр `repeat`, чтобы управлять тем, будет ли заголовок вашей таблицы повторяться на разных страницах.

В настоящее время эта функция не подходит для создания столбца заголовка или отдельных ячеек заголовка. Используйте обычные ячейки или, если вы экспортируете PDF, вы также можете использовать функцию [`pdf.header-cell`](/docs/typst/reference/format/pdf/header-cell), чтобы пометить ячейку как ячейку заголовка. Аналогично, вы можете использовать [`pdf.data-cell`](/docs/typst/reference/format/pdf/data-cell), чтобы пометить ячейки в этой функции как ячейки данных. Обратите внимание, что эти функции не являются окончательными и поэтому доступны только при включении функции `a11y-extras` (подробности см. в [документации по формату PDF](/docs/typst/reference/format/pdf)).

  ..content,

#### `repeat` [#definitions-header-repeat]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `true`

Должен ли этот заголовок повторяться на разных страницах.

#### `level` [#definitions-header-level]

**Тип:** [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Settable · **По умолчанию:** `1`

Уровень заголовка. Не должен быть нулевым.

Это позволяет повторять несколько заголовков одновременно. Заголовки с разными уровнями могут повторяться вместе, если их уровни возрастают.

Примечательно, что когда заголовок с более низким уровнем начинает повторяться, все заголовки более высокого или равного уровня перестают повторяться (они «заменяются» новым заголовком).

#### `children` [#definitions-header-children]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Required, Positional, Variadic

Ячейки и линии внутри заголовка.

### `footer` [#definitions-footer]

*Элемент* · *Since: 0.11.0*

Повторяемый нижний колонтитул таблицы.

Подобно элементу [`table.header`](#definitions-header), нижний колонтитул может повторяться на каждой странице таблицы. Это полезно для улучшения читаемости путём добавления меток столбцов как в заголовке, так и в нижнем колонтитуле большой таблицы, итогов или другой информации, которая должна быть видна на каждой странице.

После нижнего колонтитула не может быть размещено никаких других ячеек таблицы.

```typst
table.footer(
  repeat: bool,
  ..content,
)
```

#### `repeat` [#definitions-footer-repeat]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `true`

Должен ли этот нижний колонтитул повторяться на разных страницах.

#### `children` [#definitions-footer-children]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Required, Positional, Variadic

Ячейки и линии внутри нижнего колонтитула.
