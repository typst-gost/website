*Элемент* · *Locatable* · *Since: forever*

Список терминов и их описаний.

Отображает последовательность терминов и их описаний по вертикали. Когда описания занимают несколько строк, используется висячий отступ для передачи визуальной иерархии.

  / Ligature: A merged glyph.
  / Kerning: A spacing adjustment
    between two adjacent letters.

## Синтаксис [#syntax]

Эта функция также имеет специальный синтаксис: строка, начинающаяся со слэша, за которым следуют термин, двоеточие и описание, создаёт элемент списка терминов.

## Параметры [#parameters]

```typst
terms(
  tight: bool,
  separator: content,
  indent: length,
  hanging-indent: length,
  spacing: auto | length,
  ..content,
)
```

### `tight` [#parameters-tight]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `true`

Определяет [интервал](#parameters-spacing) по умолчанию для списка терминов. Если значение равно `false`, элементы разделяются с помощью [интервала между абзацами](/docs/typst/reference/model/par#parameters-spacing). Если значение равно `true`, вместо этого используется [интерлиньяж абзаца](/docs/typst/reference/model/par#parameters-leading). Это делает список более компактным, что может выглядеть лучше, если элементы короткие.

В режиме разметки значение этого параметра определяется на основе того, разделены ли элементы пустой строкой. Если элементы следуют непосредственно друг за другом, устанавливается значение `true`; если элементы разделены пустой строкой, устанавливается значение `false`. Плотность, заданную разметкой, нельзя переопределить с помощью правил set.

### `separator` [#parameters-separator]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Settable · **По умолчанию:** `h(amount: 0.6em, weak: true)`

Разделитель между элементом и описанием.

Если вы хотите просто разделить их определённым количеством пространства, используйте `h(2cm, weak: true)` в качестве разделителя и замените `2cm` на желаемое количество пространства.

### `indent` [#parameters-indent]

**Тип:** [length](/docs/typst/reference/layout/length) · **Модификаторы:** Settable · **По умолчанию:** `0pt`

Отступ каждого элемента.

### `hanging-indent` [#parameters-hanging-indent]

**Тип:** [length](/docs/typst/reference/layout/length) · **Модификаторы:** Settable · **По умолчанию:** `2em`

Висячий отступ описания.

Это дополнение к `indent` всего элемента.

### `spacing` [#parameters-spacing]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [length](/docs/typst/reference/layout/length) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Интервал между элементами списка терминов.

Если установлено значение `auto`, используется [`leading`](/docs/typst/reference/model/par#parameters-leading) абзаца для плотных списков терминов и [`spacing`](/docs/typst/reference/model/par#parameters-spacing) абзаца для широких (неплотных) списков терминов.

### `children` [#parameters-children]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Required, Positional, Variadic

Дочерние элементы списка терминов.

При использовании синтаксиса списка терминов соседние элементы автоматически собираются в списки терминов, даже через такие конструкции, как циклы for.
