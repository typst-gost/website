<span id="summary" />

*Элемент* · *Позиционируемый* · *Начиная с: всегда*

Ссылка на работу из библиографии.

Прежде чем начать цитировать, вам нужно добавить [библиографию](/docs/typst/reference/model/bibliography) где-нибудь в вашем документе.

## Пример [#example]

<TypstRender
  code={`
  This was already noted by
  pirates long ago. @arrgh

  Multiple sources say ...
  @arrgh @netwok.

  You can also call \`cite\`
  explicitly. #cite(<arrgh>)

  #bibliography("works.bib")
`}
  image="/typst_docs_assets/images/J9C2F3uO8t-JTBZDrAgTow.png"
  alt=""
  editable={true}
/>

Если имя вашего источника содержит определённые символы, такие как слэши, которые не распознаются синтаксисом `<>`, вы можете явно вызвать `label` вместо этого.

```typst
Computer Modern is an example of a modernist serif typeface.
#cite(label("DBLP:books/lib/Knuth86a")).
```

## Синтаксис [#syntax]

Эта функция косвенно имеет выделенный синтаксис. [Ссылки](/docs/typst/reference/model/ref) можно использовать для цитирования работ из библиографии. Метка при этом соответствует ключу цитирования.

## Параметры [#parameters]

```typst
cite(
  label,
  supplement: none | content,
  form: none | str,
  style: auto | str | path | bytes,
)
```

### `key` [#parameters-key]

**Тип:** [label](/docs/typst/reference/foundations/label) · **Модификаторы:** Обязательный, Позиционный

Ключ цитирования, который идентифицирует запись в библиографии, на которую следует сослаться, в виде метки.

<details>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  // All the same
  @netwok \\
  #cite(<netwok>) \\
  #cite(label("netwok"))
`}
  image="/typst_docs_assets/images/J3TVDAD3M7DQrSNHEoCF-g.png"
  alt=""
  editable={true}
/>

</details>

### `supplement` [#parameters-supplement]

**Тип:** [none](/docs/typst/reference/foundations/none) или [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `none`

Дополнение к цитате, такое как номер страницы или главы.

В синтаксисе ссылок дополнение можно добавить в квадратных скобках:

<details>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  This has been proven. @distress[p.~7]
  #bibliography("works.bib")
`}
  image="/typst_docs_assets/images/c4SKkIwQ2cEnsKXlKYAmbg.png"
  alt=""
  editable={true}
/>

</details>

### `form` [#parameters-form]

**Тип:** [none](/docs/typst/reference/foundations/none) или [str](/docs/typst/reference/foundations/str) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `"normal"`

Вид создаваемой цитаты. Разные формы полезны в разных сценариях: обычная цитата полезна как источник в конце предложения, тогда как «прозаическая» цитата больше подходит для включения в поток текста.

Если установлено значение `none`, цитируемая работа включается в библиографию, но ничего не отображается.

<details>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  #cite(<netwok>, form: "prose")
  show the outsized effects of
  pirate life on the human psyche.
`}
  image="/typst_docs_assets/images/eMjy1Lb8wzYgEx8hCt6wrQ.png"
  alt=""
  editable={true}
/>

</details>

| **Вариант** | **Описание** |
| --- | --- |
| `"normal"` | Отображается стандартным способом для активного стиля. |
| `"prose"` | Создаёт цитату, подходящую для включения в предложение. |
| `"full"` | Имитирует запись в библиографии с полной информацией о цитируемой работе. |
| `"author"` | Показывает только автора (авторов) цитируемой работы. |
| `"year"` | Показывает только год цитируемой работы. |

### `style` [#parameters-style]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [str](/docs/typst/reference/foundations/str) или [path](/docs/typst/reference/foundations/path) или [bytes](/docs/typst/reference/foundations/bytes) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `auto`

Стиль цитирования.

Это может быть:

- `auto` для автоматического использования [стиля библиографии](/docs/typst/reference/model/bibliography#parameters-style) для цитат.
- Строка с именем одного из встроенных стилей (см. ниже). Некоторые из перечисленных ниже стилей встречаются дважды: один раз с полным именем и один раз с коротким псевдонимом.
- Строка пути или [`path`](/docs/typst/reference/foundations/path) к [файлу CSL](https://citationstyles.org/).
- Необработанные байты, из которых следует декодировать стиль CSL.
