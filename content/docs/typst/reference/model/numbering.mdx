<span id="summary" />

*Since: forever*

Применяет нумерацию к последовательности чисел.

Нумерация определяет, как последовательность чисел должна отображаться в виде содержимого. Она задаётся либо строкой-шаблоном, либо произвольной функцией.

Шаблон нумерации состоит из счётных символов, на место которых подставляется фактическое число, их префиксов и одного суффикса. Префиксы и суффикс отображаются как есть.

## Пример [#example]

<TypstRender
  code={`
  #numbering("1.1)", 1, 2, 3) \\
  #numbering("1.a.i", 1, 2) \\
  #numbering("I – 1", 12, 2) \\
  #numbering(
    (..nums) => nums
      .pos()
      .map(str)
      .join(".") + ")",
    1, 2, 3,
  )
`}

## Шаблоны нумерации и функции нумерации [#patterns-and-functions]

В Typst есть несколько мест, где можно указать шаблон или функцию нумерации. Например, при определении того, как нумеровать [заголовки](/docs/typst/reference/model/heading) или [иллюстрации](/docs/typst/reference/model/figure). Каждый раз ожидаемый формат совпадает с описанным ниже для параметра [`numbering`](#parameters-numbering).

Следующий пример показывает, что функция нумерации — это обычная [функция](/docs/typst/reference/foundations/function), которая принимает числа и возвращает [`content`](/docs/typst/reference/foundations/content).

## Параметры [#parameters]

```typst
numbering(
  str | function,
  ..int,
) -> any
```

### `numbering` [#parameters-numbering]

**Тип:** [str](/docs/typst/reference/foundations/str) или [function](/docs/typst/reference/foundations/function) · **Модификаторы:** Required, Positional

Определяет, как работает нумерация.

**Счётные символы** — это `1`, `a`, `A`, `i`, `I`, `α`, `Α`, `一`, `壹`, `あ`, `い`, `ア`, `イ`, `א`, `가`, `ㄱ`, `*`, `١`, `۱`, `१`, `১`, `ক`, `①` и `⓵`. Они заменяются числом из последовательности с сохранением исходного регистра.

Символ `*` означает, что для счёта следует использовать символы в порядке `*`, `†`, `‡`, `§`, `¶`, `‖`. Если элементов больше шести, число представляется с помощью повторяющихся символов.

**Суффиксы** — это все символы после последнего счётного символа. Они отображаются как есть в конце любого отрисованного числа.

**Префиксы** — это все символы, которые не являются ни счётными символами, ни суффиксами. Они отображаются как есть перед отрисованным эквивалентом их счётного символа.

Этот параметр также может быть произвольной функцией, которая получает каждое число в качестве отдельного аргумента. При передаче функции функция `numbering` просто пересылает аргументы этой функции. Хотя само по себе это не особенно полезно, это означает, что вы можете передавать функции `numbering` произвольные нумерации, не заботясь о том, определены ли они как шаблон или как функция.

### `numbers` [#parameters-numbers]

**Тип:** [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Required, Positional, Variadic

Числа, к которым применяется нумерация. Должны быть неотрицательными.

В общем случае числа считаются с единицы. Число ноль означает, что первый элемент ещё не появился.

Если `numbering` является шаблоном и задано больше чисел, чем счётных символов, последний счётный символ вместе с его префиксом повторяется.
