<span id="summary" />

*Элемент* · *Locatable* · *Since: forever*

Список библиографии / литературы.

Вы можете создать новую библиографию, вызвав эту функцию с путём к файлу библиографии в одном из двух форматов:

- Файл Hayagriva `.yaml`/`.yml`. Hayagriva — это новый формат файлов библиографии, разработанный для использования с Typst. Посетите его [документацию](https://github.com/typst/hayagriva/blob/main/docs/file-format.md), чтобы узнать больше.
- Файл BibLaTeX `.bib`.

Как только вы добавите библиографию где-либо в документе, вы сможете начать цитировать источники с помощью синтаксиса ссылок (`@key`) или явных вызовов функции [citation](/docs/typst/reference/model/cite) (`#cite(<key>)`). В библиографии будут отображаться только записи для работ, на которые были ссылки в документе.

## Пример [#example]

<TypstRender
  code={`
  This was already noted by
  pirates long ago. @arrgh

  Multiple sources say ...
  @arrgh @netwok.

  #bibliography("works.bib")
`}
  image="/typst_docs_assets/images/mAf1zTP8P-WIIQfOhSmlNA.png"
  alt=""

## Стили [#styles]

Typst предлагает широкий выбор встроенных [стилей цитирования и библиографии](#parameters-style). Помимо них, вы можете добавлять и использовать собственные файлы [CSL](https://citationstyles.org/) (Citation Style Language). Не знаете, какой стиль использовать? Вот несколько хороших вариантов по умолчанию в зависимости от дисциплины, в которой вы работаете:

| **Области** | **Типичные стили** |
| --- | --- |
| Инженерия, IT | `"ieee"` |
| Психология, науки о жизни | `"apa"` |
| Социальные науки | `"chicago-author-date"` |
| Гуманитарные науки | `"mla"`, `"chicago-notes"`, `"harvard-cite-them-right"` |
| Экономика | `"harvard-cite-them-right"` |
| Физика | `"american-physics-society"` |

## Несколько библиографий [#multiple-bibliographies]

Когда документ Typst содержит несколько библиографий, каждая ссылка привязывается к одной из них. По умолчанию Typst автоматически выбирает подходящую библиографию (как правило, ближайшую следующую, которая содержит ключ цитируемого источника). Это покрывает распространённые случаи, такие как библиографии по главам или тематические библиографии. Для более тонкого контроля ссылки можно явно адресовать библиографии через селектор [`target`](#parameters-target).

## Оформление [#styling]

Некоторые стили библиографии оформляют записи с висячим отступом. По умолчанию такие стили применяют отступ `1.5em` через встроенное правило show-set для [`par.hanging-indent`](/docs/typst/reference/model/par#parameters-hanging-indent). Чтобы переопределить это значение по умолчанию, вы можете написать собственное правило show-set<sup>[1](#loc-2)</sup>, нацеленное на библиографию:

<TypstRender
  code={`
  #show bibliography: set par(
    hanging-indent: 3em
  )

  The Net Wok is ... @netwok
  #bibliography(
    "works.bib",
    style: "apa",
  )
`}
  image="/typst_docs_assets/images/zAO8eWmdGBM2Yl1JutUytg.png"
  alt=""
  editable={true}
/>

1. <sup>[1](#loc-1)</sup> Простое правило `set par(hanging-indent: ..)` не окажет влияния на библиографию, поскольку правила show-set (включая встроенные) имеют приоритет над обычными правилами set.

## Параметры [#parameters]

```typst
bibliography(
  str | path | bytes | array,
  title: none | auto | content,
  full: bool,
  style: str | path | bytes,
  target: auto | label | selector | location | function,
  group: none | auto | str,
)
```

### `sources` [#parameters-sources]

**Тип:** [str](/docs/typst/reference/foundations/str) или [path](/docs/typst/reference/foundations/path) или [bytes](/docs/typst/reference/foundations/bytes) или [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Обязательный, Позиционный

Один или несколько путей к файлам Hayagriva `.yaml` и/или BibLaTeX `.bib` либо их необработанные байты.

Это может быть:

- Строка пути или [`path`](/docs/typst/reference/foundations/path) для загрузки файла библиографии.
- Необработанные байты, из которых должна быть декодирована библиография.
- Массив, каждый элемент которого является одним из вышеперечисленного.

### `title` [#parameters-title]

**Тип:** [none](/docs/typst/reference/foundations/none) или [auto](/docs/typst/reference/foundations/auto) или [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Заголовок библиографии.

- Если задано `auto`, будет использоваться подходящий заголовок для [языка текста](/docs/typst/reference/text/text#parameters-lang). Это значение по умолчанию.
- Если задано `none`, у библиографии не будет заголовка.
- Пользовательский заголовок можно задать, передав содержимое.

Заголовок библиографии по умолчанию не будет нумероваться, но вы можете принудительно включить нумерацию с помощью правила show-set: `show bibliography: set heading(numbering: "1.")`

### `full` [#parameters-full]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `false`

Включать ли все работы из заданных файлов библиографии, даже те, на которые не было ссылок в документе.

Чтобы выборочно добавить отдельные цитируемые работы без их отображения, вы также можете использовать функцию `cite` с параметром [`form`](/docs/typst/reference/model/cite#parameters-form), установленным в `none`.

### `style` [#parameters-style]

**Тип:** [str](/docs/typst/reference/foundations/str) или [path](/docs/typst/reference/foundations/path) или [bytes](/docs/typst/reference/foundations/bytes) · **Модификаторы:** Settable · **По умолчанию:** `"ieee"`

Стиль библиографии.

Это может быть:

- Строка с именем одного из встроенных стилей (см. ниже). Некоторые из перечисленных ниже стилей встречаются дважды: один раз под полным именем и один раз под коротким псевдонимом.
- Строка пути или [`path`](/docs/typst/reference/foundations/path) к [файлу CSL](https://citationstyles.org/).
- Необработанные байты, из которых должен быть декодирован стиль CSL.

### `target` [#parameters-target]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [label](/docs/typst/reference/foundations/label) или [selector](/docs/typst/reference/foundations/selector) или [location](/docs/typst/reference/introspection/location) или [function](/docs/typst/reference/foundations/function) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Определяет, какие ссылки включать в библиографию.

Typst автоматически привязывает каждую ссылку в документе к библиографии. Конкретно, ссылка привязывается (в порядке приоритета) к

1. первой библиографии, которая включает её в свой селектор `target`; или, если такой библиографии нет,
2. ближайшей _следующей_ библиографии с `target: auto`, которая содержит её ключ; или, если такой библиографии не следует,
3. ближайшей _предшествующей_ библиографии с `target: auto`, которая содержит её ключ.

<details>
<summary>Показать пример: локальная библиография</summary>

<TypstRender
  code={`
  #let info(body) = block(
    stroke: (left: 1.5pt + blue),
    fill: aqua.lighten(50%),
    inset: 1em,
    context {
      body
      show divider: set block(spacing: 1.2em)
      divider()
      bibliography(
        "works.bib",
        title: none,
        target: selector(cite).within(here()),
        style: "mla",
      )
    }
  )

  = On the matter of dumplings
  In recent years, we can observe an uptick in
  dumpling consumption across the board. @netwok
  #info[
    Dumplings are particularly enjoyed
    among pirates. @arrgh
  ]

  #bibliography("works.bib")
`}

### `group` [#parameters-group]

**Тип:** [none](/docs/typst/reference/foundations/none) или [auto](/docs/typst/reference/foundations/auto) или [str](/docs/typst/reference/foundations/str) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Концептуально объединяет эту библиографию с другими библиографиями для целей нумерации. Библиографии в одной группе будут присваивать последовательные номера ссылок.

Это может быть:

- `none`: библиография будет нумероваться изолированно.
- `auto`: библиография будет нумероваться последовательно со всеми другими библиографиями в группе `auto`.
- [Строка](/docs/typst/reference/foundations/str): библиография будет нумероваться последовательно со всеми другими библиографиями с тем же значением `group`.

Группа `auto` работает так же, как любая строковая группа, но является канонической группой по умолчанию.
