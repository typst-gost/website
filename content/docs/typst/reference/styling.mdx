title: "Стилизация"

---


Typst включает гибкую систему стилизации, которая автоматически применяет выбранное вами оформление к документу. С помощью _правил set_ вы можете настраивать базовые свойства элементов. Так вы создаёте большинство распространённых стилей. Однако для всего, что вы хотите сделать, может не найтись встроенного свойства. По этой причине Typst дополнительно поддерживает _правила show_, которые могут полностью переопределять внешний вид элементов.

## Правила set [#set-rules]

С помощью правил set вы можете настраивать внешний вид элементов. Они записываются как [вызов функции](/docs/typst/reference/foundations/function) к [функции элемента](/docs/typst/reference/foundations/function#element-functions), перед которым стоит ключевое слово `set` (или `#set` в разметке). В правило set можно передавать только необязательные параметры этой функции. Обратитесь к документации каждой функции, чтобы узнать, какие параметры являются необязательными. В примере ниже мы используем два правила set, чтобы изменить [семейство шрифтов](/docs/typst/reference/text/text#parameters-font) и [нумерацию заголовков](/docs/typst/reference/model/heading#parameters-numbering).

<TypstRender
  code={`
  #set heading(numbering: "I.")
  #set text(
    font: "New Computer Modern"
  )

  = Introduction
  With set rules, you can style
  your document.
`}
  image="/typst_docs_assets/images/uHAoXFmXr4t5ywkbENtEsg.png"
  alt=""
  editable={true}
/>

Правило set верхнего уровня действует до конца файла. Если оно вложено в блок кода или контента, то действует только до конца этого блока. С помощью блока вы можете ограничить действие правила определённым фрагментом документа. Ниже мы используем блок контента, чтобы ограничить стилизацию списка одним конкретным списком.

<TypstRender
  code={`
  This list is affected: #[
    #set list(marker: [--])
    - Dash
  ]

  This one is not:
  - Bullet
`}
  image="/typst_docs_assets/images/8UuYWhw8zqQyee-04SGbJg.png"
  alt=""
  editable={true}
/>

Иногда вам нужно применить правило set условно. Для этого можно использовать правило _set-if_.

<TypstRender
  code={`
  #let task(body, critical: false) = {
    set text(red) if critical
    [- #body]
  }

  #task(critical: true)[Food today?]
  #task(critical: false)[Work deadline]
`}
  image="/typst_docs_assets/images/mDvHiOOIEBa95sHwwva1Sw.png"
  alt=""
  editable={true}
/>

## Правила show [#show-rules]

С помощью правил show вы можете глубоко настраивать внешний вид элементов определённого типа. Самая базовая форма правила show — это _правило show-set_. Такое правило записывается как ключевое слово `show`, за которым следует [селектор](/docs/typst/reference/foundations/selector), двоеточие и затем правило set. Самая базовая форма селектора — это [функция элемента](/docs/typst/reference/foundations/function#element-functions). Это позволяет правилу set применяться только к выбранному элементу. В примере ниже заголовки становятся тёмно-синими, а весь остальной текст остаётся чёрным.

<TypstRender
  code={`
  #show heading: set text(navy)

  = This is navy-blue
  But this stays black.
`}
  image="/typst_docs_assets/images/DjA-UrsA7UBPRUF9F2hIFg.png"
  alt=""
  editable={true}
/>

С помощью правил show-set вы можете комбинировать свойства из разных функций, чтобы добиваться множества различных эффектов. Но они всё ещё ограничивают вас тем, что предопределено в Typst. Для максимальной гибкости вы можете вместо этого написать _трансформационное_ правило show, которое определяет, как форматировать элемент с нуля. Чтобы написать такое правило show, замените правило set после двоеточия произвольной [функцией](/docs/typst/reference/foundations/function). Эта функция получает рассматриваемый элемент и может возвращать произвольный контент. Функция часто определяется прямо на месте как `it => ..` с использованием [синтаксиса безымянной функции](/docs/typst/reference/foundations/function#unnamed). Параметр функции по соглашению обычно называется `it`.

Доступные [поля](/docs/typst/reference/scripting#fields) у элемента, передаваемого в функцию, соответствуют параметрам соответствующей функции элемента. Ниже мы определяем правило show, которое форматирует заголовки для фэнтезийной энциклопедии.

Само правило show добавляет символы тильды вокруг заголовка (их нужно экранировать обратной косой чертой, иначе они обозначали бы неразрывный пробел), выделяет заголовок курсивом, а затем отображает счётчик заголовков после заголовка.

Для этого примера мы также хотели выравнивание по центру и другой шрифт. Хотя мы могли бы добавить эти правила set в существующее правило show, вместо этого мы добавили их как отдельные правила show-set. Это хорошая практика, потому что теперь эти правила всё ещё могут быть переопределены последующими правилами show-set в документе, сохраняя стилизацию компонуемой. Напротив, правила set внутри трансформационного правила show больше нельзя было бы переопределить.

<TypstRender
  code={`
  #set heading(numbering: "(I)")
  #show heading: set align(center)
  #show heading: set text(font: "Inria Serif")
  #show heading: it => block[
    \\~
  #emph(it.body)
    #counter(heading).display()
    \\~
  ]

  = Dragon
  With a base health of 15, the dragon is the most
  powerful creature.

  = Manticore
  While less powerful than the dragon, the manticore
  gets extra style points.
`}
  image="/typst_docs_assets/images/HKGCC7pen5OG0ZrH1tO3KQ.png"
  alt=""
  editable={true}
/>

Как и правила set, правила show действуют до конца текущего блока или файла.

Вместо функции правая часть правила show также может принимать строковый литерал или блок контента, который должен быть напрямую подставлен вместо элемента. А помимо функции, левая часть правила show также может принимать ряд других _селекторов_, которые определяют, к чему применять преобразование:

- **Всё:** `show: rest => ..`<br />Преобразовать всё после правила show. Это полезно для применения более сложной вёрстки ко всему документу без оборачивания всего в гигантский вызов функции.
- **Текст:** `show "Text": ..`<br />Стилизовать, преобразовать или заменить текст.
- **Регулярное выражение:** `show regex("\w+"): ..`<br />Выбирать и преобразовывать текст с помощью регулярного выражения для ещё большей гибкости. Подробности см. в документации [типа `regex`](/docs/typst/reference/foundations/regex).
- **Функция с полями:** `show heading.where(level: 1): ..`<br />Преобразовывать только элементы с указанными полями. Например, вы можете захотеть изменить стиль только заголовков уровня 1.
- **Метка:** `show <intro>: ..`<br />Выбирать и преобразовывать элементы с указанной меткой. Подробности см. в документации [типа `label`](/docs/typst/reference/foundations/label).

<TypstRender
  code={`
  #show "Project": smallcaps
  #show "badly": "great"

  We started Project in 2019
  and are still working on it.
  Project is progressing badly.
`}
  image="/typst_docs_assets/images/YJMTWWtK2O0ZdnJw7UXgkw.png"
  alt=""
  editable={true}
/>
