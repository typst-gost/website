<span id="summary" />

*Добавлено в версии: 0.1.0*

Считывает структурированные данные из файла YAML.

Файл должен содержать корректный объект или массив YAML. Значения YAML будут преобразованы в соответствующие значения Typst, как указано в [таблице ниже](#conversion).

Функция возвращает словарь, массив или, в зависимости от файла YAML, другой тип данных YAML.

Файлы YAML в примере содержат объекты, в которых ключами являются авторы, а значением каждого из них — последовательность собственных вложенных отображений с ключами «title» и «published».

## Пример [#example]

<TypstRender
  code={`
  #let bookshelf(contents) = {
    for (author, works) in contents {
      author
      for work in works [
        - #work.title (#work.published)
      ]
    }
  }

  #bookshelf(
    yaml("scifi-authors.yaml")
  )
`}

## Детали преобразования [#conversion]

| **Значение YAML** | **Преобразуется в Typst** |
| --- | --- |
| null-значения (`null`, `~` или пустое ``) | `none` |
| boolean | [`bool`](/docs/typst/reference/foundations/bool) |
| number | [`float`](/docs/typst/reference/foundations/float) или [`int`](/docs/typst/reference/foundations/int) |
| string | [`str`](/docs/typst/reference/foundations/str) |
| sequence | [`array`](/docs/typst/reference/foundations/array) |
| mapping | [`dictionary`](/docs/typst/reference/foundations/dictionary) |

| **Значение Typst** | **Преобразуется в YAML** |
| --- | --- |
| типы, которые можно преобразовать из YAML | соответствующее значение YAML |
| [`bytes`](/docs/typst/reference/foundations/bytes) | строка через [`repr`](/docs/typst/reference/foundations/repr) |
| [`symbol`](/docs/typst/reference/foundations/symbol) | строка |
| [`content`](/docs/typst/reference/foundations/content) | отображение, описывающее содержимое |
| другие типы ([`length`](/docs/typst/reference/layout/length) и т. д.) | строка через [`repr`](/docs/typst/reference/foundations/repr) |

### Примечания [#notes]

- В большинстве случаев числа YAML будут преобразованы в числа с плавающей точкой или целые числа в зависимости от того, являются ли они целыми. Однако учтите, что целые числа больше $2^{63} - 1$ или меньше $- 2^{63}$ будут преобразованы в числа с плавающей точкой, что может привести к приблизительному значению.
- Пользовательские теги YAML игнорируются, хотя загруженное значение всё равно будет присутствовать.
- Байты не кодируются как последовательности YAML по соображениям производительности и читаемости. Для двоичных данных рассмотрите возможность использования [`cbor.encode`](/docs/typst/reference/data-loading/cbor#definitions-encode).
- Функция `repr` [предназначена только для отладки](/docs/typst/reference/foundations/repr#debugging-only), и её вывод не гарантируется стабильным между версиями Typst.

## Параметры [#parameters]

```typst
yaml(str | path | bytes) -> any
```

### `source` [#parameters-source]

**Тип:** [str](/docs/typst/reference/foundations/str) или [path](/docs/typst/reference/foundations/path) или [bytes](/docs/typst/reference/foundations/bytes) · **Модификаторы:** Обязательный, Позиционный

Путь к файлу YAML или необработанные байты YAML.

## Функции [#functions]

*Добавлено в версии: 0.8.0*

Кодирует структурированные данные в строку YAML.

```typst
yaml.encode(any) -> str
```

#### `value` [#definitions-encode-value]

**Тип:** `any` · **Модификаторы:** Обязательный, Позиционный

Значение для кодирования.
