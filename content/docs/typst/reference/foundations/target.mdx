<span id="summary" />

*Контекстная* · *Доступна с версии: 0.13.0*

Возвращает текущую цель экспорта.

Эта функция возвращает

- `"paged"` при экспорте в [PDF](/docs/typst/reference/format/pdf), [PNG](/docs/typst/reference/format/png) и [SVG](/docs/typst/reference/format/svg), а также внутри [HTML-фрейма](/docs/typst/reference/format/html/frame)
- `"html"` при экспорте в [HTML](/docs/typst/reference/format/html)
- `"bundle"` при экспорте в [Bundle](/docs/typst/reference/format/bundle)

## Когда использовать [#when-to-use-it]

Эта функция позволяет правильно форматировать документ для постраничного, HTML- и многофайлового экспорта. Её следует использовать прежде всего в шаблонах и правилах show, а не напрямую в содержимом. Благодаря этому содержимое документа может быть полностью независимым от цели экспорта, а контент можно совместно использовать между разными целями экспорта.

## Изменяющиеся цели [#varying-targets]

Эта функция является [контекстной](/docs/typst/reference/context), поскольку цель может меняться в рамках одной компиляции: при экспорте в HTML цель будет `"paged"` внутри [`html.frame`](/docs/typst/reference/format/html/frame).
