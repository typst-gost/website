Модуль, содержащий все глобально доступные элементы.

## Использование «затенённых» определений [#using-shadowed-definitions]

Модуль `std` полезен всякий раз, когда вы переопределили имя из глобальной области видимости (это называется _затенением_). Например, вы могли использовать имя `text` для параметра. Чтобы по-прежнему обращаться к элементу `text`, напишите `std.text`.

<TypstRender
  code={`
  #let par = [My special paragraph.]
  #let special(text) = {
    set std.text(style: "italic")
    set std.par.line(numbering: "1")
    text
  }

  #special(par)

  #lorem(10)
`}

## Условный доступ [#conditional-access]

Вы также можете использовать это в сочетании с [конструктором словаря](/docs/typst/reference/foundations/dictionary#constructor) для условного доступа к глобальным определениям. Это может, например, пригодиться, чтобы использовать новую или экспериментальную функциональность, когда она доступна, при этом возвращаясь к альтернативной реализации, если используется более старая версия Typst. В частности, это позволяет создавать [полифилы](https://en.wikipedia.org/wiki/Polyfill_(programming)).

Это может быть так же просто, как создать псевдоним, чтобы предотвратить предупреждения, например, условно использовать `pattern` в Typst версии 0.12, но использовать [`tiling`](/docs/typst/reference/visualize/tiling) в более новых версиях. Поскольку параметры, принимаемые функцией `tiling`, совпадают с параметрами более старой функции `pattern`, использование функции `tiling`, когда она доступна, и возврат к `pattern` в противном случае унифицирует использование во всех версиях. Обратите внимание, что при создании полифила также может быть очень полезен [`sys.version`](/docs/typst/reference/foundations/sys#constants-version).

```typst
#let tiling = if "tiling" in std { tiling } else { pattern }

...
```
