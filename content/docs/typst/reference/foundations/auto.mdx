---
title: "Auto"
description: "Документация для типа `auto`."
---

<span id="summary" />

Значение, указывающее на разумное значение по умолчанию.

Тип auto имеет ровно одно значение: `auto`.

Параметры, поддерживающие значение `auto`, имеют некоторое разумное значение по умолчанию или контекстное поведение. Хороший пример — параметр [направления текста](/docs/typst/reference/text/text#parameters-dir). Установка его в `auto` позволяет Typst автоматически определять направление по [языку текста](/docs/typst/reference/text/text#parameters-lang).
