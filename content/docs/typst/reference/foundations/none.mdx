<span id="summary" />

Значение, указывающее на отсутствие какого-либо другого значения.

Тип none имеет ровно одно значение: `none`.

При вставке в документ оно не отображается. Это также значение, которое получается в результате пустых блоков кода. Его можно [объединять](/docs/typst/reference/scripting#blocks) с любым значением, в результате чего получается другое значение.
