<span id="summary" />

*Since: forever*

Метка для элемента.

Вставка метки в содержимое прикрепляет её к ближайшему предшествующему элементу, не являющемуся пробелом. Предшествующий элемент должен находиться в той же области видимости, что и метка, а значит, конструкция `Hello #[<label>]`, например, не сработает.

Элемент с меткой можно [сослаться](/docs/typst/reference/model/ref), [запросить](/docs/typst/reference/introspection/query) и [стилизовать](/docs/typst/reference/styling) через его метку.

После создания вы можете получить имя метки с помощью [`str`](/docs/typst/reference/foundations/str#constructor).

## Пример [#example]

## Синтаксис [#syntax]

У этой функции также есть специальный синтаксис: вы можете создать метку, заключив её имя в угловые скобки. Это работает как в разметке, так и в коде. Имя метки может содержать буквы, цифры, `_`, `-`, `:`, и `.`. Метка не может быть пустой.

Обратите внимание, что при использовании специального синтаксиса для этой функции есть синтаксическое различие. В приведённом ниже коде `<a>` завершает заголовок и, таким образом, прикрепляется к самому заголовку, тогда как `#label("b")` является частью заголовка и, следовательно, прикрепляется к тексту заголовка.

```typst
// Equivalent to `#heading[Introduction] <a>`.
= Introduction <a>
// Equivalent to `#heading[Conclusion #label("b")]`.
= Conclusion #label("b")
```

В настоящее время метки можно прикреплять только к элементам в режиме разметки, но не в режиме кода. В будущем это может измениться.

## Конструктор [#constructor]

Создаёт метку из строки.

```typst
label(str) -> label
```

### `name` [#constructor-name]

**Тип:** [str](/docs/typst/reference/foundations/str) · **Модификаторы:** Обязательный, Позиционный

Имя метки.

В отличие от [специального синтаксиса](#syntax), этот конструктор принимает любую непустую строку, включая имена со специальными символами.
