<span id="summary" />

Базовые типы и функции.

Здесь вы найдёте документацию по основным типам данных, таким как [целые числа](/docs/typst/reference/foundations/int) и [строки](/docs/typst/reference/foundations/str), а также сведения о ключевых вычислительных функциях.

## Определения [#definitions]

- [`arguments`](/docs/typst/reference/foundations/arguments)Захваченные аргументы функции.
- [`array`](/docs/typst/reference/foundations/array)Последовательность значений.
- [`assert`](/docs/typst/reference/foundations/assert)Гарантирует выполнение условия.
- [`auto`](/docs/typst/reference/foundations/auto)Значение, указывающее на разумное поведение по умолчанию.
- [`bool`](/docs/typst/reference/foundations/bool)Тип с двумя состояниями.
- [`bytes`](/docs/typst/reference/foundations/bytes)Последовательность байтов.
- [`calc`](/docs/typst/reference/foundations/calc)Модуль для вычислений и обработки числовых значений.
- [`content`](/docs/typst/reference/foundations/content)Фрагмент содержимого документа.
- [`datetime`](/docs/typst/reference/foundations/datetime)Представляет дату, время или их комбинацию.
- [`decimal`](/docs/typst/reference/foundations/decimal)Тип десятичного числа с фиксированной точкой.
- [`dictionary`](/docs/typst/reference/foundations/dictionary)Отображение строковых ключей в значения.
- [`duration`](/docs/typst/reference/foundations/duration)Представляет положительный или отрицательный промежуток времени.
- [`eval`](/docs/typst/reference/foundations/eval)Вычисляет строку как код Typst.
- [`float`](/docs/typst/reference/foundations/float)Число с плавающей точкой.
- [`function`](/docs/typst/reference/foundations/function)Отображение значений аргументов в возвращаемое значение.
- [`int`](/docs/typst/reference/foundations/int)Целое число: положительное целое, отрицательное целое или ноль.
- [`label`](/docs/typst/reference/foundations/label)Метка для элемента.
- [`module`](/docs/typst/reference/foundations/module)Набор переменных и функций, обычно связанных с одной темой.
- [`none`](/docs/typst/reference/foundations/none)Значение, указывающее на отсутствие какого-либо другого значения.
- [`panic`](/docs/typst/reference/foundations/panic)Завершается с ошибкой.
- [`path`](/docs/typst/reference/foundations/path)Путь в файловой системе.
- [`plugin`](/docs/typst/reference/foundations/plugin)Загружает модуль WebAssembly.
- [`regex`](/docs/typst/reference/foundations/regex)Регулярное выражение.
- [`repr`](/docs/typst/reference/foundations/repr)Возвращает строковое представление значения.
- [`selector`](/docs/typst/reference/foundations/selector)Фильтр для выбора элементов в документе.
- [`std`](/docs/typst/reference/foundations/std)Модуль, содержащий все глобально доступные элементы.
- [`str`](/docs/typst/reference/foundations/str)Последовательность кодовых точек Unicode.
- [`symbol`](/docs/typst/reference/foundations/symbol)Символ Unicode.
- [`sys`](/docs/typst/reference/foundations/sys)Модуль для взаимодействия с системой.
- [`target`](/docs/typst/reference/foundations/target)Возвращает текущую цель экспорта.
- [`type`](/docs/typst/reference/foundations/type)Описывает вид значения.
- [`version`](/docs/typst/reference/foundations/version)Версия с произвольным числом компонентов.
