title: "Panic"
description: "Документация для функции `panic`."
---

<span id="summary" />

*Since: forever*

Завершается с ошибкой.

Аргументы отображаются пользователю (не рендерятся в документе) в виде строк, при необходимости преобразуясь с помощью `repr`.

## Пример [#example]

Приведённый ниже код вызывает ошибку `panicked with: this is wrong`.

```typst
#panic("this is wrong")
```

## Параметры [#parameters]

```typst
panic(..any)
```

### `values` [#parameters-values]

**Тип:** `any` · **Модификаторы:** обязательный, позиционный, вариативный

Значения, с которыми происходит паника и которые отображаются пользователю.
