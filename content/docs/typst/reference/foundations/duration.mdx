<span id="summary" />

*Добавлено в версии: 0.8.0*

Представляет положительный или отрицательный промежуток времени.

## Конструктор [#constructor]

Создаёт новую длительность.

Вы можете задать [длительность](/docs/typst/reference/foundations/duration) в неделях, днях, часах, минутах и секундах. Также длительность можно получить, вычтя одну [дату и время](/docs/typst/reference/foundations/datetime) из другой.

```typst
duration(
  seconds: int,
  minutes: int,
  hours: int,
  days: int,
  weeks: int,
) -> duration
```

### `seconds` [#constructor-seconds]

**Тип:** [int](/docs/typst/reference/foundations/int) · **По умолчанию:** `0`

Количество секунд.

### `minutes` [#constructor-minutes]

**Тип:** [int](/docs/typst/reference/foundations/int) · **По умолчанию:** `0`

Количество минут.

### `hours` [#constructor-hours]

**Тип:** [int](/docs/typst/reference/foundations/int) · **По умолчанию:** `0`

## Функции [#functions]

### `seconds` [#definitions-seconds]

*Добавлено в версии: 0.8.0*

Длительность, выраженная в секундах.

Эта функция возвращает общую длительность, представленную в секундах, в виде числа с плавающей точкой, а не компонент секунд длительности.

```typst
self.seconds() -> float
```
