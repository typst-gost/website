### `inputs` [#constants-inputs]

*С версии: 0.11.0* · **Тип:** [dictionary](/docs/typst/reference/foundations/dictionary)

Делает внешние входные данные доступными для проекта.

Входные данные, указанные в командной строке как `--input key=value`, становятся доступны через `sys.inputs.key` как `"value"`. Чтобы включить в значение пробелы, его можно заключить в одинарные или двойные кавычки.

Значение всегда имеет тип [string](/docs/typst/reference/foundations/str). Более сложные данные можно разобрать вручную с помощью таких функций, как [`json`](/docs/typst/reference/data-loading/json).
