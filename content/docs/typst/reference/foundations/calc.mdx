Модуль для вычислений и обработки числовых значений.

Эти определения являются частью модуля `calc` и не импортируются по умолчанию.

## Константы [#constants]

### `inf` [#constants-inf]

*Since: forever* · **Тип:** [float](/docs/typst/reference/foundations/float)

Бесконечность ($+ \infty$) как значение.

Это то же значение, что и [`float.inf`](/docs/typst/reference/foundations/float#definitions-inf). Подробности см. в соответствующей документации.

*Since: forever* · **Тип:** [float](/docs/typst/reference/foundations/float)

Константа Архимеда ($\pi$).

Это отношение длины окружности к её диаметру.

### `atan2` [#functions-atan2]

*Since: 0.3.0*

Вычисляет четырёхквадрантный арктангенс координаты.

Четырёхквадрантный арктангенс $(x, y)$ определяется как аргумент комплексного числа $x + i y$.

Возвращает [`angle`](/docs/typst/reference/layout/angle) между `-180deg` и `180deg`.

Обратите внимание, что эта функция принимает $(x, y)$, а не $(y, x)$.

<TypstRender

  #calc.atan2(-2, -3)
`}

  alt=""
  editable={true}
/>

</details>

```typst
calc.atan2(
  int | float,
  int | float,
) -> angle
```

### `round` [#functions-round]

*Since: forever*

Округляет число до ближайшего целого.

Полуцелые числа округляются от нуля.

При необходимости можно указать количество десятичных знаков. Если оно отрицательное, его абсолютное значение указывает количество значащих целых разрядов, которые нужно удалить перед десятичной точкой.

Обратите внимание, что эта функция возвращает тот же тип, что и операнд. То есть применение `round` к [`float`](/docs/typst/reference/foundations/float) вернёт `float`, а к [`decimal`](/docs/typst/reference/foundations/decimal) — другой `decimal`. Вы можете явно преобразовать результат этой функции в целое число с помощью [`int`](/docs/typst/reference/foundations/int), но учтите, что такое преобразование выдаст ошибку, если `float` или `decimal` окажется больше максимального 64-битного знакового целого или меньше минимального целого.

Кроме того, эта функция может выдать ошибку при попытке округления за пределы максимального или минимального целого или `decimal`. Если число является `float`, такая попытка приведёт к возврату [`calc.inf`](#constants-inf) или `-calc.inf` для максимума и минимума соответственно.

<details open>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`

  #assert(calc.round(3) == 3)
  #assert(calc.round(3.14) == 3)
  #assert(calc.round(3.5) == 4.0)
  #assert(calc.round(3333.45, digits: -2) == 3300.0)
  #assert(calc.round(-48953.45, digits: -3) == -49000.0)
  #assert(calc.round(3333, digits: -2) == 3300)
  #assert(calc.round(-48953, digits: -3) == -49000)
  #assert(calc.round(decimal("-6.5")) == decimal("-7"))
  #assert(calc.round(decimal("7.123456789"), digits: 6) == decimal("7.123457"))
  #assert(calc.round(decimal("3333.45"), digits: -2) == decimal("3300"))
  #assert(calc.round(decimal("-48953.45"), digits: -3) == decimal("-49000"))
`}

### `rem-euclid` [#functions-rem-euclid]

*Since: 0.10.0*

Вычисляет наименьший неотрицательный остаток от деления (неотрицательный остаток по модулю).

Предупреждение: из-за ошибки округления с плавающей точкой остаток может оказаться равным абсолютному значению делителя, если делимое значительно меньше делителя по модулю и делимое отрицательное. Это относится только к входным данным с плавающей точкой.

### `norm` [#functions-norm]

*Since: 0.13.0*

Вычисляет $p$-норму последовательности значений.

$p$-норма $x_{1}, \dots, x_{n}$ определяется следующим образом:

$$
\begin{cases} (\sum_{i = 1}^{n} | x_{i} |^{p})^{1 / p} \quad & \text{if} \, 0 < p < + \infty \\ \max_{i = 1}^{n} | x_{i} | \quad & \text{if} \, p = + \infty \end{cases}
$$

#### `p` [#functions-norm-p]

**Тип:** [float](/docs/typst/reference/foundations/float) · **По умолчанию:** `2.0`

Значение $p$. Должно быть больше нуля.

Значение по умолчанию `2.0` соответствует евклидовой норме:

$$

$$
