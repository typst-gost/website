<span id="summary" />

*Since: forever*

Последовательность значений.

Вы можете создать массив, заключив разделённую запятыми последовательность значений в круглые скобки. Значения не обязаны иметь один и тот же тип.

Вы можете получать доступ к элементам массива и изменять их с помощью метода `.at()`. Индексы начинаются с нуля, а отрицательные индексы отсчитываются от конца массива. Вы можете перебирать массив с помощью [цикла for](/docs/typst/reference/scripting#loops). Массивы можно складывать с помощью оператора `+`, [объединять](/docs/typst/reference/scripting#blocks) и умножать на целые числа.

**Примечание:** Массив длины один требует завершающей запятой, как в `(1,)`. Это нужно, чтобы отличить его от простого выражения в скобках, например `(1 + 2) * 3`. Пустой массив записывается как `()`.

## Пример [#example]

<TypstRender
  code={`
  #let values = (1, 7, 4, -3, 2)

  #values.at(0) \\
  #(values.at(0) = 3)
  #values.at(-1) \\
  #values.find(calc.even) \\
  #values.filter(calc.odd) \\
  #values.map(calc.abs) \\
  #values.rev() \\
  #(1, (2, 3)).flatten() \\
  #(("A", "B", "C")
      .join(", ", last: " and "))
`}

## Конструктор [#constructor]

Преобразует значение в массив.

Обратите внимание, что эта функция предназначена только для преобразования коллекционноподобного значения в массив, а не для создания массива из отдельных элементов. Вместо этого используйте синтаксис массива `(1, 2, 3)` (или `(1,)` для массива из одного элемента).

<details open>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  #let hi = "Hello 😃"
  #array(bytes(hi))
`}
  image="/typst_docs_assets/images/PX34Wmtusca4jA-34zMaXw.png"
  alt=""
  editable={true}
/>

</details>

```typst
array(bytes | array | version)
```

### `value` [#constructor-value]

**Тип:** [bytes](/docs/typst/reference/foundations/bytes) или [array](/docs/typst/reference/foundations/array) или [version](/docs/typst/reference/foundations/version) · **Модификаторы:** Обязательный, Позиционный

Значение, которое следует преобразовать в массив.

## Функции [#functions]

### `len` [#definitions-len]

*Since: forever*

Количество значений в массиве.

```typst
self.len() -> int
```

### `first` [#definitions-first]

*Since: forever*

Возвращает первый элемент массива. Может использоваться в левой части присваивания. Возвращает значение по умолчанию, если массив пуст, или завершается с ошибкой, если значение по умолчанию не указано.

```typst

```

#### `default` [#definitions-first-default]

Значение по умолчанию, возвращаемое, если массив пуст.

### `last` [#definitions-last]

*Since: forever*

Извлекает подмассив из массива. Завершается с ошибкой, если начальный или конечный индекс выходит за границы.

```typst
self.slice(
  int,
  none | int,
  count: int,
) -> array
```

#### `start` [#definitions-slice-start]

**Тип:** [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Обязательный, Позиционный

Начальный индекс (включительно). Если отрицательный, отсчитывается от конца.

#### `end` [#definitions-slice-end]

**Тип:** [none](/docs/typst/reference/foundations/none) или [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Позиционный · **По умолчанию:** `none`

Конечный индекс (не включая его). Если не указан, извлекается весь подмассив до конца массива. Если отрицательный, отсчитывается от конца.

#### `count` [#definitions-slice-count]

**Тип:** [int](/docs/typst/reference/foundations/int)

Количество элементов для извлечения. Это эквивалентно передаче `start + count` в качестве позиции `end`. Взаимоисключающе с `end`.

### `zip` [#definitions-zip]

*Since: 0.3.0*

Объединяет массив с другими массивами попарно.

Возвращает массив массивов, где `i`-й внутренний массив содержит все `i`-е элементы из каждого исходного массива.

Если объединяемые массивы имеют разную длину, они объединяются до последнего элемента самого короткого массива, а все оставшиеся элементы игнорируются.

Эта функция вариативная, то есть вы можете объединить несколько массивов сразу: `(1, 2).zip(("A", "B"), (10, 20))` даёт `((1, "A", 10), (2, "B", 20))`.

```typst
self.zip(
  exact: bool,
  ..array,
)
```

#### `exact` [#definitions-zip-exact]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **По умолчанию:** `false`

Должны ли все массивы иметь одинаковую длину. Например, `(1, 2).zip((1, 2, 3), exact: true)` вызывает ошибку.

#### `others` [#definitions-zip-others]

**Тип:** [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Обязательный, Позиционный, Вариативный

Массивы, с которыми нужно объединить.

### `sorted` [#definitions-sorted]

*Since: forever*

Возвращает отсортированную версию этого массива, при необходимости по заданной ключевой функции. Используемый алгоритм сортировки является стабильным.

Возвращает ошибку, если пару значений, выбранных для сравнения, невозможно сравнить, или если ключевая функция или функция сравнения (если задана) выдают ошибку.

Чтобы сортировать сразу по нескольким критериям, например в случае равенства по некоторым критериям, ключевая функция может возвращать массив. Результаты упорядочиваются лексикографически.

<details open>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  #let array = (
    (a: 2, b: 4),
    (a: 1, b: 5),
    (a: 2, b: 3),
  )
  #array.sorted(key: it => (it.a, it.b))
`}
  image="/typst_docs_assets/images/_1wkN8_pDnCHVCZrzW-fhg.png"
  alt=""
  editable={true}
/>

</details>

```typst
self.sorted(
  key: function,
  by: function,
) -> array
```

#### `key` [#definitions-sorted-key]

**Тип:** [function](/docs/typst/reference/foundations/function)

Если задана, применяет эту функцию к каждому элементу массива для определения ключей сортировки.

#### `by` [#definitions-sorted-by]

**Тип:** [function](/docs/typst/reference/foundations/function)

Если задана, использует эту функцию для сравнения каждых двух элементов массива.

Функция получает два элемента массива для сравнения и должна возвращать логическое значение, указывающее их порядок: `true` означает, что элементы упорядочены, а `false` означает, что их следует поменять местами. Чтобы сохранить стабильность сортировки, если два элемента равны, функция должна возвращать `true`.

Если эта функция не упорядочивает элементы должным образом (например, возвращая `false` как для `(x, y)`, так и для `(y, x)`, или для `(x, x)`), результирующий массив будет в неопределённом порядке.

При использовании вместе с `key` в `by` будут передаваться ключи вместо элементов.

    "decreasing",
    "length",
  ).sorted(
    key: s => s.len(),
    by: (l, r) => l >= r,
  )
`}

### `reduce` [#definitions-reduce]

*Since: 0.12.0*

Сводит элементы к одному, многократно применяя операцию свёртки.

Если массив пуст, возвращает `none`, иначе возвращает результат свёртки.

Функция свёртки — это замыкание с двумя аргументами: «аккумулятором» и элементом.

Для массивов с хотя бы одним элементом это то же самое, что [`array.fold`](#definitions-fold) с первым элементом массива в качестве начального значения аккумулятора, в который свёртывается каждый последующий элемент.

<details open>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  #let array = (2, 1, 4, 3)
  #array.reduce((acc, x) => calc.max(acc, x))
`}
  image="/typst_docs_assets/images/L5nGrxmiyb0LqWF4IjiBAg.png"
  alt=""
  editable={true}
/>

</details>

