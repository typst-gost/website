Альтернативные шрифты в формулах.

Эти функции отличаются от функции [`text`](/docs/typst/reference/text/text), поскольку математические шрифты содержат несколько вариантов каждой буквы.

## Функции [#functions]

### `serif` [#functions-serif]

*Появилось: всегда*

Шрифт с засечками (романский) в математике.

Это уже используется по умолчанию.

```typst
math.serif(content)
```

#### `body` [#functions-serif-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Содержимое, к которому применяется стиль.

### `scr` [#functions-scr]

*Появилось: 0.14.0*

Рукописный (рондо) шрифт в математике.

<details open>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  $scr(L)$ is not the set of linear
  maps $cal(L)$.
`}
  image="/typst_docs_assets/images/BtsQYogdmPfwz9kqtTraLA.png"
  alt=""
  editable={true}
/>

</details>

Существует два способа, которыми шрифты могут поддерживать различие между `cal` и `scr`. Первый — использование вариационных последовательностей Unicode. Это работает в Typst из коробки, однако в настоящее время это поддерживает лишь несколько математических шрифтов.

Другой способ — использование [возможностей шрифта](/docs/typst/reference/text/text#parameters-features). Например, стиль рондо может быть доступен в шрифте через функцию _[стилистического набора](/docs/typst/reference/text/text#parameters-stylistic-set) 1_ (`ss01`). Чтобы использовать его в Typst, вы можете определить свою собственную версию `scr`, как в примере ниже.

<details>
<summary>Посмотреть пример: воссоздание с использованием стилистического набора 1</summary>

<TypstRender
  code={`
  #let scr(it) = text(
    stylistic-set: 1,
    $cal(it)$,
  )

  We establish $cal(P) != scr(P)$.
`}
  image="/typst_docs_assets/images/WABhpb5zYKvVFHEyv4l37w.png"
  alt=""
  editable={true}
/>

</details>

```typst
math.scr(content)
```

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Содержимое, к которому применяется стиль.
