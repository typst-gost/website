Сопоставление разделителей.

Функция `lr` позволяет сопоставить два разделителя и масштабировать их вместе с содержимым, которое они охватывают. Хотя это также происходит автоматически для разделителей, которые сопоставляются синтаксически, `lr` позволяет сопоставить два произвольных разделителя и точно управлять их размером. Помимо функции `lr`, Typst предоставляет ещё несколько функций, которые создают пары разделителей для абсолютных значений, значений с округлением вверх и вниз, а также норм.

Чтобы разделитель не сопоставлялся Typst и, следовательно, не масштабировался автоматически, экранируйте его обратной косой чертой. Чтобы вместо этого полностью отключить автоматическое масштабирование, используйте `set math.lr(size: 1em)`.

## Пример [#example]

  #set math.lr(size: 1em)

## Функции [#functions]

### `lr` [#functions-lr]

*Элемент* · *Доступно с: всегда*

Масштабирует разделители.

Хотя сопоставленные разделители масштабируются по умолчанию, эту функцию можно использовать для масштабирования несопоставленных разделителей и для более точного управления масштабированием разделителей.

```typst
math.lr(
  size: relative,
  content,
)
```

#### `size` [#functions-lr-size]

**Тип:** [relative](/docs/typst/reference/layout/relative) · **Модификаторы:** Settable · **По умолчанию:** `100% + 0pt`

Размер скобок относительно высоты охватываемого содержимого.

#### `body` [#functions-lr-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Required, Positional

Содержимое с разделителями, включая сами разделители.

### `mid` [#functions-mid]

*Элемент* · *Доступно с: 0.10.0*

Масштабирует разделители по вертикали до ближайшей окружающей группы `lr()`.
