<span id="summary" />

*Элемент* · *Доступно с: всегда*

Принудительное использование определённого математического класса.

Это полезно, чтобы обращаться с некоторыми символами так, как если бы они принадлежали к другому классу, например, чтобы символ вёл себя как отношение. Класс символа определяет способ его вёрстки, включая отступы вокруг него и то, как по умолчанию к нему присоединяются скрипты. Обратите внимание, что последнее всегда можно переопределить с помощью [`limits`](/docs/typst/reference/math/attach#functions-limits) и [`scripts`](/docs/typst/reference/math/attach#functions-scripts).

## Параметры [#parameters]

```typst
math.class(
  str,
  content,
)
```

### `class` [#parameters-class]

**Тип:** [str](/docs/typst/reference/foundations/str) · **Модификаторы:** обязательный, позиционный

Класс, который нужно применить к содержимому.

<details>
<summary>Показать варианты</summary>

| **Вариант** | **Описание** |
| --- | --- |
| `"normal"` | Класс по умолчанию для неспециальных элементов. |
| `"punctuation"` | Пунктуация, например запятая. |
| `"opening"` | Открывающий разделитель, например `(`. |
| `"closing"` | Закрывающий разделитель, например `)`. |
| `"fence"` | Разделитель, одинаковый с обеих сторон, например `\|`. |
| `"large"` | Большой оператор, например `sum`. <br /> Если тело состоит из одного глифа, этот класс вертикально центрирует его на математической оси (где расположена дробная черта) и растягивает его по вертикали в стиле [`display`](/docs/typst/reference/math/sizes#functions-display). |
| `"relation"` | Отношение, например `=` или `prec`. |
| `"unary"` | Унарный оператор, например `not`. |
| `"binary"` | Бинарный оператор, например `times`. |
| `"vary"` | Оператор, который может быть как унарным, так и бинарным, например `+`. |
| `"diacritic"` | Диакритический знак. |

</details>

### `body` [#parameters-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** обязательный, позиционный

Содержимое, к которому применяется класс.
