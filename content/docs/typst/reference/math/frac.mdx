Математическая дробь.

## Пример [#example]

  code={`
  $ 1/2 < (x+1)/2 $
  $ ((x+1)) / 2 = frac(a, b) $
`}

## Синтаксис [#syntax]

Эта функция также имеет специальный синтаксис: используйте косую черту, чтобы превратить соседние выражения в дробь. Несколько атомов можно объединить в одно выражение с помощью круглых группирующих скобок. Такие скобки удаляются из вывода, но вы можете вложить несколько, чтобы принудительно их сохранить.

## Параметры [#parameters]

```typst
math.frac(
  content,
  content,
  style: str,
)
```

### `num` [#parameters-num]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Числитель дроби.

### `denom` [#parameters-denom]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Знаменатель дроби.

### `style` [#parameters-style]

**Тип:** [str](/docs/typst/reference/foundations/str) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `"vertical"`

Как должна быть свёрстана дробь.

| **Вариант** | **Описание** |
| --- | --- |
| `"vertical"` | Числитель и знаменатель расположены друг над другом с чертой. |
| `"skewed"` | Числитель и знаменатель разделены косой чертой. |
| `"horizontal"` | Числитель и знаменатель расположены в строке, а скобки не поглощаются. |
