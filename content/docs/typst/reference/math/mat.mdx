<span id="summary" />

*Элемент* · *С версии: forever*

Матрица.

Элементы строки должны быть разделены запятыми, а сами строки — точками с запятой. Синтаксис с точкой с запятой объединяет предшествующие аргументы, разделённые запятыми, в массив. Вы также можете использовать этот специальный синтаксис вызовов математических функций для определения пользовательских функций, принимающих двумерные данные.

Содержимое ячеек можно выровнять с помощью параметра [`align`](#parameters-align), а содержимое ячеек, находящихся в одной строке, можно выровнять с помощью символа `&`.

## Параметры [#parameters]

```typst
math.mat(
  delim: none | str | symbol | array,
  align: alignment,
  augment: none | int | dictionary,
  gap: relative,
  row-gap: relative,
  column-gap: relative,
  ..array,
) -> content
```

### `delim` [#parameters-delim]

**Тип:** [none](/docs/typst/reference/foundations/none) или [str](/docs/typst/reference/foundations/str) или [symbol](/docs/typst/reference/foundations/symbol) или [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Settable · **По умолчанию:** `("(", ")")`

Разделитель, который следует использовать.

Может быть одиночным символом, задающим левый разделитель, и тогда правый разделитель выводится автоматически. В противном случае может быть массивом, содержащим левый и правый разделители.

### `augment` [#parameters-augment]

**Тип:** [none](/docs/typst/reference/foundations/none) или [int](/docs/typst/reference/foundations/int) или [dictionary](/docs/typst/reference/foundations/dictionary) · **Модификаторы:** Settable · **По умолчанию:** `none`

Рисует линии расширения в матрице.

- `none`: линии не рисуются.
- Одно число: вертикальная линия расширения рисуется после указанного номера столбца. Отрицательные числа отсчитываются с конца.
- Словарь: с помощью словаря можно нарисовать несколько линий расширения как по горизонтали, так и по вертикали. Кроме того, можно задать стиль линий. Словарь может содержать следующие ключи:
  - `hline`: смещения, на которых следует рисовать горизонтальные линии. Например, при смещении `2` горизонтальная линия будет нарисована после второй строки матрицы. Принимает либо целое число для одной линии, либо массив целых чисел для нескольких линий. Как и для одного числа, отрицательные числа отсчитываются с конца.
  - `vline`: смещения, на которых следует рисовать вертикальные линии. Например, при смещении `2` вертикальная линия будет нарисована после второго столбца матрицы. Принимает либо целое число для одной линии, либо массив целых чисел для нескольких линий. Как и для одного числа, отрицательные числа отсчитываются с конца.
  - `stroke`: как [обводить](/docs/typst/reference/visualize/stroke) линию. Если задано значение `auto`, используется толщина 0.05 em и квадратные окончания линий.

### `gap` [#parameters-gap]

**Тип:** [relative](/docs/typst/reference/layout/relative) · **По умолчанию:** `0% + 0pt`
