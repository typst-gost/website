## Синтаксис [#syntax]

Эта функция имеет специальный синтаксис: используйте апострофы вместо штрихов. Они автоматически прикрепляются к предыдущему элементу, перенося надстрочные знаки на следующий уровень.

## Параметры [#parameters]

```typst
math.primes(int) -> content
```

### `count` [#parameters-count]

**Тип:** [int](/docs/typst/reference/foundations/int) · **Модификаторы:** Обязательный, Позиционный

Количество сгруппированных штрихов.
