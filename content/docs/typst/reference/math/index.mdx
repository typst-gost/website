<span id="summary" />

Typst имеет специальный [синтаксис](/docs/typst/reference/syntax#math) и библиотечные функции для вёрстки математических формул. Математические формулы могут отображаться в строке с текстом или в виде отдельных блоков. Они будут свёрстаны в собственный блок, если начинаются и заканчиваются хотя бы одним пробелом (например, `$ x^2 $`).

## Переменные [#variables]

В математическом режиме одиночные буквы всегда отображаются как есть. Однако несколько букв интерпретируются как переменные и функции. Чтобы отобразить несколько букв дословно, можно заключить их в кавычки, а для доступа к однобуквенным переменным можно использовать [синтаксис с решёткой](/docs/typst/reference/scripting#expressions).

<TypstRender
  code={`
  $ A = pi r^2 $
  $ "area" = pi dot "radius"^2 $
  $ cal(A) :=
      { x in RR | x "is natural" } $
  #let x = 5
  $ #x < 17 $
`}
  image="/typst_docs_assets/images/qTo0VeVbviA1NZMHK6oegA.png"
  alt=""
  editable={true}
/>

## Символы [#symbols]

Математический режим предоставляет широкий выбор [символов](/docs/typst/reference/symbols/sym), таких как `pi`, `dot` или `RR`. Многие математические символы доступны в различных вариантах. Вы можете выбирать между разными вариантами, применяя [модификаторы](/docs/typst/reference/foundations/symbol) к символу. Кроме того, Typst распознаёт ряд сокращённых последовательностей, таких как `=>`, которые аппроксимируют символ. Если такое сокращение существует, оно указывается в документации символа.

<TypstRender
  code={`
  $ x < y => x gt.eq.not y $
`}
  image="/typst_docs_assets/images/LS7YXPMVafLlG88kqsZYuQ.png"
  alt=""
  editable={true}
/>

## Разрывы строк [#line-breaks]

Формулы также могут содержать разрывы строк. Каждая строка может содержать одну или несколько _точек выравнивания_ (`&`), по которым затем выполняется выравнивание.

<TypstRender
  code={`
  $ sum_(k=0)^n k
      &= 1 + ... + n \\
  &= (n(n+1)) / 2 $
`}
  image="/typst_docs_assets/images/rWxFH5z3hcY4JWJM5kWFHQ.png"
  alt=""
  editable={true}
/>

## Вызовы функций [#function-calls]

Математический режим поддерживает специальные вызовы функций без префикса в виде решётки. В этих «математических вызовах» список аргументов работает несколько иначе, чем в коде:

- Внутри них Typst по-прежнему находится в «математическом режиме». Таким образом, вы можете писать математику непосредственно в них, но для передачи выражений кода необходимо использовать синтаксис с решёткой (за исключением строк, которые доступны в математическом синтаксисе).
- Они поддерживают позиционные и именованные аргументы, а также раскрытие аргументов, но не поддерживают завершающие блоки содержимого.
- Они предоставляют дополнительный синтаксис для двумерных списков аргументов. Точка с запятой (`;`) объединяет предшествующие аргументы, разделённые запятыми, в аргумент-массив.

<TypstRender
  code={`
  $ frac(a^2, 2) $
  $ vec(1, 2, delim: "[") $
  $ mat(1, 2; 3, 4) $
  $ mat(..#range(1, 5).chunks(2)) $
  $ lim_x =
      op("lim", limits: #true)_x $
`}
  image="/typst_docs_assets/images/KDhJSbmMyAhzmENAKIjqfA.png"
  alt=""
  editable={true}
/>

Чтобы написать дословную запятую или точку с запятой в математическом вызове, экранируйте её обратной косой чертой. Двоеточие, с другой стороны, распознаётся особым образом только в том случае, если непосредственно предшествует идентификатору, поэтому чтобы отобразить его дословно в таких случаях, можно просто вставить перед ним пробел.

Вызовы функций, перед которыми стоит решётка, являются обычными вызовами функций кода и не подчиняются этим правилам.

## Выравнивание [#alignment]

Когда уравнения содержат несколько _точек выравнивания_ (`&`), это создаёт блоки чередующихся столбцов с выравниванием по правому и левому краю. В примере ниже выражение `(3x + y) / 7` выровнено по правому краю, а `= 9` — по левому. Слово «given» также выровнено по левому краю, поскольку `&&` создаёт две точки выравнивания подряд, дважды чередуя выравнивание. `& &` и `&&` ведут себя совершенно одинаково. Между тем, «multiply by 7» выровнено по правому краю, поскольку перед ним стоит только один `&`. Каждая точка выравнивания просто чередует выравнивание по правому/левому краю.

<TypstRender
  code={`
  $ (3x + y) / 7 &= 9 && "given" \\
    3x + y &= 63 & "multiply by 7" \\
    3x &= 63 - y && "subtract y" \\
    x &= 21 - y/3 & "divide by 3" $
`}
  image="/typst_docs_assets/images/ho8rfs3SdQep9MBATsY3nA.png"
  alt=""
  editable={true}
/>

## Математические шрифты [#math-fonts]

Вы можете задать математический шрифт с помощью [правила show-set](/docs/typst/reference/styling#show-rules), как показано ниже. Обратите внимание, что для вёрстки математики подходят только специальные математические шрифты OpenType.

<TypstRender
  code={`
  #show math.equation: set text(font: "Pennstander Math")
  $ sum_(i in NN) 1 + i $
`}
  image="/typst_docs_assets/images/WfYLY4LqVmN22FxWumjSFA.png"
  alt=""
  editable={true}

## Модуль math [#math-module]

Все математические функции являются частью [модуля](/docs/typst/reference/scripting#modules) `math`, который по умолчанию доступен в уравнениях. Вне уравнений к ним можно получить доступ с помощью префикса `math.`.

## Доступность [#accessibility]

Чтобы сделать математику доступной, необходимо предоставить альтернативные описания уравнений на естественном языке с помощью [`параметра alt` у `math.equation`](/docs/typst/reference/math/equation#parameters-alt). Для получения дополнительной информации см. [раздел «Текстовые представления» руководства по доступности](/docs/typst/guides/accessibility#textual-representations).

<TypstRender
  code={`
  #math.equation(
    alt: "d S equals delta q divided by T",
    block: true,
    $ dif S = (delta q) / T $,
  )
`}
  image="/typst_docs_assets/images/5e2lFMYaUQHR7GGe-BRd6w.png"
  alt=""
  editable={true}
/>

В будущем Typst будет автоматически делать уравнения без альтернативных описаний доступными при экспорте в HTML и PDF 2.0.

- [`mat`](/docs/typst/reference/math/mat)Матрица.

- [roots](/docs/typst/reference/math/roots)Квадратные и неквадратные корни.

- [underover](/docs/typst/reference/math/underover)Разделители над или под частями уравнения.
- [variants](/docs/typst/reference/math/variants)Альтернативные начертания шрифта внутри формул.
