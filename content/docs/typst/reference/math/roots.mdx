## Функции [#functions]

### `root` [#functions-root]

*Элемент* · *С версии: всегда*

Корень общего вида.

<details open>
<summary>Посмотреть пример</summary>

<TypstRender
  code={`
  $ root(3, x) $
`}
  image="/typst_docs_assets/images/QVZT4LcpjrJc1VwZbrHnDw.png"
  alt=""
  editable={true}
/>

</details>

```typst
math.root(
  none | content,
  content,
)
```

#### `index` [#functions-root-index]

**Тип:** [none](/docs/typst/reference/foundations/none) или [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Позиционный, Устанавливаемый · **По умолчанию:** `none`

Какой корень из подкоренного выражения нужно извлечь.

#### `radicand` [#functions-root-radicand]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Выражение, из которого извлекается корень.
