<span id="summary" />

*Элемент* · *Доступно с: 0.12.0*

Растягивает глиф.

Эту функцию также можно использовать для автоматического растягивания основания присоединённого элемента, чтобы оно соответствовало верхнему и нижнему присоединениям.

Обратите внимание, что растягивать можно только некоторые глифы, и то, какие именно, может зависеть от используемого математического шрифта. Однако в этом отношении большинство математических шрифтов ведут себя одинаково.

## Параметры [#parameters]

```typst
math.stretch(
  content,
  size: relative,
)
```

### `body` [#parameters-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Глиф, который нужно растянуть.

### `size` [#parameters-size]

**Тип:** [relative](/docs/typst/reference/layout/relative) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `100% + 0pt`

Размер, до которого нужно растянуть, относительно максимального размера глифа и его присоединений.

Обратите внимание, что итоговый глиф может не иметь точно желаемого размера. Растянутый глиф может быть либо предопределённым глифом, либо глифом, собранным из составных частей, предоставляемых шрифтом. Возможные размеры могут не покрывать весь диапазон. В примере ниже, когда параметр `size` увеличивается с `101%` до `200%`, выбранный глиф остаётся тем же, поэтому фактический размер не меняется.
