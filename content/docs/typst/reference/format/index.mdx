<span id="summary" />

Документы Typst можно экспортировать в различные форматы. В этом разделе описаны доступные форматы экспорта, а также перечислены настройки и возможности, специфичные для каждого формата.

Каждый формат экспорта имеет связанный элемент, через который его можно настроить. Эти элементы определены в глобальном модуле `format`. Основные форматы `pdf` и `html` дополнительно доступны напрямую в глобальной области видимости.

## Настройка параметров экспорта [#export-settings]

Есть два способа задать параметры экспорта:

- Во время экспорта — через аргументы командной строки или панель «Export & Preview» в веб-приложении
- В документе — через [правило set](/docs/typst/reference/styling#set-rules) для элемента формата

Ниже приведён пример, показывающий, как изменить стандарт [PDF](/docs/typst/reference/format/pdf#parameters-standard) по умолчанию для документа. Если не указано иное (например, через аргумент командной строки), документ с этим правилом set будет экспортирован как PDF/UA-1.

```typst
// The document will now default to PDF/UA-1.
#set pdf(standard: "ua-1")
```

Аналогично можно написать правило set, которое по умолчанию делает отрендеренный PNG немного чётче. Здесь нужно написать [`format.png`](/docs/typst/reference/format/png) вместо просто `png`, поскольку элемент формата PNG не доступен глобально (так как это несколько более узкий формат экспорта, чем PDF).

```typst
// This makes PNGs a bit higher-res.
#set format.png(ppi: 300)
```
