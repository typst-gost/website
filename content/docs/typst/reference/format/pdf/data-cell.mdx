*С версии: 0.14.0* · *Флаг функции: требует функции `a11y-extras`*

Явно определяет эту ячейку как ячейку данных.

Каждая ячейка в таблице является либо ячейкой заголовка, либо ячейкой данных. По умолчанию все ячейки в [`table.header`](/docs/typst/reference/model/table#definitions-header) являются ячейками заголовка, а все остальные ячейки — ячейками данных.

Если ваш заголовок содержит ячейку, которая не является ячейкой заголовка, вы можете использовать эту функцию, чтобы пометить её как ячейку данных.

API этой функции является временным. Поэтому в настоящее время вызов этой функции требует включения флага функции `a11y-extras`. В будущем выпуске Typst эта функциональность может быть вынесена из модуля `pdf`, чтобы таблицы в других целях экспорта могли содержать ту же информацию.

## Параметры [#parameters]

```typst
pdf.data-cell(content)
```

### `cell` [#parameters-cell]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Обязательный, Позиционный

Ячейка таблицы.

Это может быть контент или вызов [`table.cell`](/docs/typst/reference/model/table#definitions-cell).
