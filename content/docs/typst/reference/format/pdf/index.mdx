<span id="summary" />

*Элемент* · *Доступно с: 0.13.0*

Формат экспорта PDF в Typst.

Файлы PDF ориентированы на точное визуальное описание документов, но также обладают средствами для аннотирования их структуры. Этот гибридный подход делает их удобными для обмена документами: они отображаются одинаково на любом устройстве, но также поддерживают извлечение содержимого и структуры документа (по крайней мере, в определённой степени). В отличие от файлов PNG, PDF не привязаны к конкретному разрешению. Поэтому вы можете просматривать их в любом размере без потери качества.

## Экспорт в PDF [#exporting-as-pdf]

### Командная строка [#command-line]

PDF — это формат экспорта по умолчанию в Typst. Запуск подкоманды `compile` или `watch` без указания формата создаст PDF. При экспорте в PDF доступны следующие параметры конфигурации:

- Каким [стандартам PDF](#parameters-standard) должен соответствовать Typst, указывается с помощью `--pdf-standard`, за которым следует один или несколько стандартов, разделённых запятыми. Допустимые стандарты: `1.4`, `1.5`, `1.6`, `1.7`, `2.0`, `a-1b`, `a-1a`, `a-2b`, `a-2u`, `a-2a`, `a-3b`, `a-3u`, `a-3a`, `a-4`, `a-4f`, `a-4e` и `ua-1`. По умолчанию Typst создаёт файлы, соответствующие PDF-1.7.
- Вы можете полностью отключить тегирование PDF с помощью `--pdf-tagged=false`. По умолчанию Typst всегда создаёт _Tagged PDF_ для обеспечения базового уровня доступности. С помощью этого флага вы можете отключить теги. Это сделает ваш файл недоступным и предотвратит соответствие уровням доступности PDF/A и всем частям PDF/UA.
- Какие страницы экспортировать, указывается с помощью `--pages`, за которым следует список чисел, разделённых запятыми, или диапазонов чисел, разделённых дефисами. Диапазоны могут быть полуоткрытыми. Пример: `2,3,7-9,11-`.

### Веб-приложение [#loc-1]

Нажмите кнопку быстрого скачивания в правом верхнем углу, чтобы экспортировать PDF с настройками по умолчанию. Для дальнейшей настройки нажмите «File» \> «Export as» \> «PDF» или нажмите стрелку вниз рядом с кнопкой быстрого скачивания и выберите «Export as PDF». При экспорте в PDF доступны следующие параметры конфигурации:

- Каким стандартам PDF должен соответствовать Typst. По умолчанию Typst создаёт файлы, соответствующие PDF-1.7. Вы можете свободно выбрать версию PDF от 1.4 до 2.0. Допустимые дополнительные стандарты: `A-1b`, `A-1a`, `A-2b`, `A-2u`, `A-2a`, `A-3b`. `A-3u`, `A-3a`, `A-4`, `A-4f`, `A-4e` и `UA-1`.
- Какие страницы экспортировать. Допустимые варианты: «All pages», «Current page» и «Custom ranges». Пользовательские диапазоны — это список чисел, разделённых запятыми, или диапазонов чисел, разделённых дефисами. Диапазоны могут быть полуоткрытыми. Пример: `2,3,7-9,11-`.

## Функциональность, специфичная для PDF [#pdf-specific-functionality]

Typst предоставляет функциональность, специфичную для PDF, в глобальном элементе `pdf`. Ниже приведены определения и параметры, которые он содержит.

Этот элемент содержит некоторые функции без финального API. Они предназначены для повышения доступности документов со сложными таблицами. К ним относятся @[`table-summary`], [`header-cell`](/docs/typst/reference/format/pdf/header-cell) и [`data-cell`](/docs/typst/reference/format/pdf/data-cell). Все эти функции будут удалены в будущем выпуске Typst — либо путём интеграции в функции таблиц, либо путём полного удаления. Вы можете включить эти функции, передав `--features
a11y-extras` или установив переменную окружения `TYPST_FEATURES` в значение `a11y-extras`. В веб-приложении эти функции на данный момент недоступны.

## Параметры [#parameters]

```typst
pdf(
  pages: none | int | array | dictionary,
  standard: str | array,
  tagged: auto | bool,
  pretty: bool,
) -> content
```

### `pages` [#parameters-pages]

**Тип:** [none](/docs/typst/reference/foundations/none) или [int](/docs/typst/reference/foundations/int) или [array](/docs/typst/reference/foundations/array) или [dictionary](/docs/typst/reference/foundations/dictionary) · **Модификаторы:** Settable · **По умолчанию:** `none`

Указывает, какие диапазоны страниц должны быть включены в PDF. Это может быть:

- `none` для экспорта всех страниц.
- Один диапазон страниц.
- Массив диапазонов страниц.

Диапазон страниц — это одно из:

- Число, указывающее ровно одну страницу (нумерация страниц начинается с единицы).
- Словарь с ключами `from` (указывает начало диапазона страниц) и/или `to` (указывает конец диапазона страниц). Должен присутствовать хотя бы один из ключей, и оба числа — начальное и конечное — включаются в диапазон. Таким образом, диапазон `(from: 1, to: 3)` — это список страниц `(1, 2, 3)`.

Указание одной страницы или диапазона страниц:

```typst
#set pdf(pages: 3)
#set pdf(pages: (from: 3))
#set pdf(pages: (to: 5))
#set pdf(pages: (from: 3, to: 5))
```

Указание нескольких страниц, диапазонов страниц или их комбинации:

```typst
#set pdf(pages: (5, 7, 9))
#set pdf(pages: ((to: 3), 5, (from: 7, to: 8), (from: 10)))
```

### `standard` [#parameters-standard]

**Тип:** [str](/docs/typst/reference/foundations/str) или [array](/docs/typst/reference/foundations/array) · **Модификаторы:** Settable · **По умолчанию:** `("1.7",)`

Список стандартов PDF, которым Typst будет обеспечивать соответствие. Это может быть один стандарт или массив стандартов.

Международная организация по стандартизации (ISO) опубликовала базовый стандарт PDF и различные стандарты, расширяющие его, чтобы сделать PDF более подходящими для конкретных случаев использования. По умолчанию Typst экспортирует файлы PDF 1.7. Adobe Acrobat 8 и более поздние версии, а также все другие распространённые программы просмотра PDF совместимы с этой версией PDF.

Некоторые функции Typst могут быть недоступны в зависимости от выбранного стандарта PDF. Вы можете комбинировать совместимые стандарты PDF/A и PDF/UA. Примечательно, что PDF/UA-1 и PDF/A-4 взаимно несовместимы, поскольку первый требует PDF 1.7 или более ранней версии, а второй требует PDF 2.0.

#### Версии PDF [#pdf-versions]

Typst поддерживает пять различных версий PDF: 1.4, 1.5, 1.6, 1.7 (по умолчанию) и 2.0. Вы можете выбрать любую из этих версий для экспорта вашего документа. Однако в зависимости от используемых вами функций может потребоваться минимальная версия. Аналогично, стандарты, на которые вы ориентируетесь, могут ограничивать выбор версий (подробнее см. ниже).

Вот список того, как каждая новая версия улучшает PDF 1.4 для документов Typst:

- **PDF 1.5** (2003): Улучшенное управление цветом, извлечение текста, доступность таблиц, перекомпоновка и шрифты эмодзи
- **PDF 1.6** (2004): Более гибкие ссылки
- **PDF 1.7** (2006): Позволяет использовать [вложения](/docs/typst/reference/format/pdf/attach), улучшенная перекомпоновка
- **PDF 2.0** (2017): Улучшенная семантика как метаданных, так и тегов для доступности

Программное обеспечение, используемое для чтения вашего файла, должно поддерживать вашу версию PDF. При обычных обстоятельствах это не создаёт проблем, но может стать источником ошибок при работе со старым оборудованием. Для общего обмена мы рекомендуем сохранять настройку по умолчанию PDF 1.7 или выбирать PDF 2.0.

При использовании файлов PDF в качестве [изображений](/docs/typst/reference/visualize/image) в вашем документе версия экспортируемого PDF должна быть равна или превышать версии файлов изображений.

#### PDF/UA [#pdf-ua]

Typst поддерживает создание файлов, соответствующих PDF/UA. Файлы PDF/UA предназначены для _[универсального доступа](/docs/typst/guides/accessibility#basics)._ Когда вы выбираете этот стандарт PDF, Typst выполняет дополнительные проверки при экспорте вашего документа. Эти проверки гарантируют, что вы следуете лучшим практикам доступности. Например, они проверяют, что все ваши изображения снабжены альтернативными описаниями.

Обратите внимание, что в PDF/UA есть некоторые правила, которые критически важны для доступности, но не могут быть проверены автоматически. Поэтому при экспорте документа PDF/UA-1 убедитесь, что вы выполнили следующее:

- Если ваш документ написан на языке, отличном от английского, обязательно [установите язык текста](/docs/typst/reference/text/text#parameters-lang) перед любым содержимым.
- Обязательно используйте семантические элементы Typst (такие как [заголовки](/docs/typst/reference/model/heading), [рисунки](/docs/typst/reference/model/figure) и [списки](/docs/typst/reference/model/list)) там, где это уместно, вместо определения пользовательских конструкций. Это позволяет Typst знать (и экспортировать) роль, которую конструкция играет в документе. Подробнее см. в [руководстве по доступности](/docs/typst/guides/accessibility).
- Не используйте исключительно контраст, цвет, форматирование или макет для передачи идеи. Используйте текст или альтернативные описания вместо этих элементов или в дополнение к ним.
- Оборачивайте все декоративные элементы, не имеющие семантического значения, в [`pdf.artifact`](/docs/typst/reference/format/pdf/artifact).
- Не используйте изображения текста. Вместо этого вставляйте текст непосредственно в вашу разметку.

В настоящее время Typst поддерживает только первую часть (PDF/UA-1), которая основана на PDF 1.7 (2006). При экспорте в PDF/UA-1 учитывайте, что вам потребуется вручную предоставить [альтернативные описания математики](/docs/typst/reference/math#accessibility) на естественном языке.

Новые функции доступности были добавлены в PDF 2.0 (2017). При экспорте в PDF 2.0 Typst использует некоторые из этих функций. Однако PDF 2.0 и PDF/UA-1 взаимно несовместимы. Для доступных документов в настоящее время мы рекомендуем экспортировать в PDF/UA-1, а не в PDF 2.0, ради дополнительных проверок и большей совместимости. Вторая часть PDF/UA предназначена для PDF 2.0, но пока не поддерживается Typst.

#### PDF/A [#pdf-a]

Typst опционально поддерживает создание файлов, соответствующих PDF/A. Файлы PDF/A ориентированы на максимальную совместимость с текущими и будущими инструментами работы с PDF. Они не полагаются на сложные в реализации или проприетарные функции и содержат исчерпывающие метаданные. Это делает их подходящими для долгосрочного архивирования.

Стандарт PDF/A имеет несколько версий (_частей_ в терминологии ISO), и большинство частей имеют несколько профилей, указывающих уровень соответствия файла. Вы можете ориентироваться на одну часть и уровень соответствия за раз. В настоящее время Typst поддерживает следующие профили вывода PDF/A:

- **PDF/A-1b:** _Базовый_ уровень соответствия ISO 19005-1. Эта версия PDF/A основана на PDF 1.4 (2001) и приводит к самодостаточным, архивируемым файлам PDF. В отличие от более поздних частей стандарта PDF/A, прозрачность в файлах PDF/A-1 не допускается.
- **PDF/A-1a:** Это _доступный_ уровень соответствия, который строится на базовом уровне PDF/A-1b. Чтобы соответствовать этому уровню, ваш файл должен быть доступным файлом _Tagged PDF_. Обратите внимание, что доступность улучшается в более поздних частях, поскольку не все функции доступности PDF доступны для файлов PDF 1.4. Кроме того, весь текст в файле должен состоять из известных кодовых точек Unicode.
- **PDF/A-2b:** _Базовый_ уровень соответствия ISO 19005-2. Эта версия PDF/A основана на PDF 1.7 (2006) и приводит к самодостаточным, архивируемым файлам PDF.
- **PDF/A-2u:** Это _Unicode-отображаемый_ уровень соответствия, который строится на базовом уровне A-2b. Он также добавляет правила, согласно которым весь текст в документе должен состоять из известных кодовых точек Unicode. Если возможно, всегда предпочитайте этот стандарт вместо PDF/A-2b.
- **PDF/A-2a:** Это _доступный_ уровень соответствия, который строится на Unicode-отображаемом уровне A-2u. Этот уровень соответствия также добавляет два требования: ваш файл должен быть доступным файлом _Tagged PDF_. Typst автоматически добавляет теги, чтобы помочь вам достичь этого уровня соответствия. Также обращайте внимание на разделы о доступности по всей документации и на [руководство по доступности](/docs/typst/guides/accessibility) при ориентации на этот уровень соответствия. Наконец, PDF/A-2a запрещает использовать кодовые точки из [области частного использования Unicode](https://en.wikipedia.org/wiki/Private_Use_Areas). Если вы хотите создать доступный файл, также рассмотрите дополнительную ориентацию на PDF/UA-1, что включает больше автоматических проверок доступности.
- **PDF/A-3b:** _Базовый_ уровень соответствия ISO 19005-3. Эта версия PDF/A основана на PDF 1.7 (2006) и приводит к архивируемым файлам PDF, которые могут содержать произвольные другие связанные файлы в качестве [вложений](/docs/typst/reference/format/pdf/attach). Единственное отличие от PDF/A-2b — это возможность прикреплять файлы, не соответствующие PDF/A.
- **PDF/A-3u:** Это _Unicode-отображаемый_ уровень соответствия, который строится на базовом уровне A-3b. Как и PDF/A-2b, он требует, чтобы весь текст состоял из известных кодовых точек Unicode. Эти правила не применяются к вложениям. Если возможно, всегда предпочитайте этот стандарт вместо PDF/A-3b.
- **PDF/A-3a:** Это _доступный_ уровень соответствия, который строится на Unicode-отображаемом уровне A-3u. Как и PDF/A-2a, он требует, чтобы файлы были доступными _Tagged PDF_ и не использовали символы из области частного использования Unicode. Как и прежде, эти правила не применяются к вложениям.
- **PDF/A-4:** Базовый уровень соответствия ISO 19005-4. Эта версия PDF/A основана на PDF 2.0 (2017) и приводит к самодостаточным, архивируемым файлам PDF. PDF/A-4 не имеет частей, относящихся к доступности. Вместо этого эта тема более подробно раскрыта в специальном стандарте PDF/UA. Файлы PDF/A-4 могут соответствовать PDF/UA-2 (в настоящее время не поддерживается в Typst).
- **PDF/A-4f:** Уровень соответствия _встроенных файлов_, который строится на базовом уровне A-4. Файлы, соответствующие этому уровню, могут содержать произвольные другие связанные файлы в качестве [вложений](/docs/typst/reference/format/pdf/attach), так же как файлы, соответствующие части 3 ISO 19005. Единственное отличие от PDF/A-4 — это возможность прикреплять файлы, не соответствующие PDF/A.
- **PDF/A-4e:** _Инженерный_ уровень соответствия, который строится на уровне встроенных файлов A-4f. Файлы, соответствующие этому уровню, могут содержать 3D-объекты. Typst не поддерживает 3D-содержимое, поэтому с точки зрения Typst это функционально эквивалентно PDF/A-4f.

Если вы хотите ориентироваться на PDF/A, но не уверены, какую конкретную настройку использовать, есть несколько полезных правил. Во-первых, вы должны определить вашу **часть** — это «номер версии» стандарта. Задайте себе следующие вопросы:

1. **Должно ли программное обеспечение или оборудование, выпущенное до 2006 года, иметь возможность читать мой файл?** Если да, выберите часть первую (PDF/A-1).
2. **Если нет, нужны ли моему файлу [вложения](/docs/typst/reference/format/pdf/attach)?** Если да, вы должны выбрать часть третью (PDF/A-3) или уровень встроенных файлов части четвёртой (PDF/A-4f).
3. **Нужно ли вашему файлу использовать функции, появившиеся в PDF 2.0?** В настоящее время использование функций PDF 2.0 в Typst ограничено незначительными улучшениями доступности, например, для [элемента title](/docs/typst/reference/model/title). Если вы можете обойтись без этих улучшений, максимизируйте совместимость, выбрав часть вторую (когда вам не нужны вложения) или часть третью (когда вложения нужны). Если вы полагаетесь на функции PDF 2.0, используйте часть четвёртую.

Теперь вам нужно только выбрать **уровень соответствия** (строчная буква в конце).

- **Если вы выбрали часть первую, вторую или третью,** вам обычно следует выбрать доступный уровень соответствия вашей части, обозначаемый строчной буквой `a` в конце. Если ваш документ по своей природе недоступен, например, портфолио художника, которое невозможно свести к альтернативным описаниям, выберите уровень соответствия `u`. Только если это приводит к ошибке компиляции, например, из-за использования кодовых точек из области частного использования Unicode, используйте базовый уровень `b`.
- **Если вы выбрали часть четвёртую,** вам следует выбрать базовый уровень соответствия (PDF/A-4), за исключением случаев, когда требуется встраивать файлы.

При выборе между экспортом PDF/A и обычного PDF помните, что файлы PDF/A содержат дополнительные метаданные, и что некоторые программы просмотра будут препятствовать изменению файла PDF/A пользователем.

### `tagged` [#parameters-tagged]

**Тип:** [auto](/docs/typst/reference/foundations/auto) или [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `auto`

Создавать ли тегированный документ PDF.

Тегирование включено по умолчанию для обеспечения базового уровня доступности. Его можно отключить вручную, например, чтобы уменьшить размер документа, и оно будет автоматически отключено при экспорте определённого диапазона страниц.

### `pretty` [#parameters-pretty]

**Тип:** [bool](/docs/typst/reference/foundations/bool) · **Модификаторы:** Settable · **По умолчанию:** `false`

Выполнять ли красивое форматирование создаваемого документа PDF.

Это форматирует вывод более удобным для чтения, но менее компактным способом.
