*Элемент* · *Добавлено: 0.13.0* · *Функциональный переключательТребуется функцияhtml*

HTML-элемент, который может содержать содержимое Typst.

Экспорт Typst в HTML автоматически генерирует подходящие теги для большинства элементов. Однако иногда желательно сохранить больший контроль. Например, при использовании Typst для генерации вашего блога вы можете использовать эту функцию, чтобы обернуть каждую статью в тег `<article>`.

Typst знает, что является допустимым HTML. Тег и его атрибуты должны образовывать синтаксически корректный HTML. Некоторые теги, такие как `meta`, не принимают содержимое. Следовательно, вы не должны предоставлять для них тело. В будущем мы можем добавить дополнительные проверки, поэтому убедитесь, что вы генерируете корректный HTML при использовании этой функции.

Обычно Typst генерирует теги `html`, `head` и `body` за вас. Если же вы создаёте их с помощью этой функции, Typst опустит свои собственные теги.

```typst
#html.elem("div", attrs: (style: "background: aqua"))[
  A div with _Typst content_ inside!
]
```

## Параметры [#parameters]

```typst
html.elem(
  str,
  attrs: dictionary,
  none | content,
)
```

### `tag` [#parameters-tag]

**Тип:** [str](/docs/typst/reference/foundations/str) · **Модификаторы:** Обязательный, Позиционный

Тег элемента.

### `attrs` [#parameters-attrs]

**Тип:** [dictionary](/docs/typst/reference/foundations/dictionary) · **Модификаторы:** Устанавливаемый · **По умолчанию:** `(:)`

HTML-атрибуты элемента.

### `body` [#parameters-body]

**Тип:** [none](/docs/typst/reference/foundations/none) или [content](/docs/typst/reference/foundations/content) · **Модификаторы:** Позиционный, Устанавливаемый · **По умолчанию:** `none`

Содержимое HTML-элемента.

Тело может быть произвольным содержимым Typst.
