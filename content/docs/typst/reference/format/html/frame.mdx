<span id="summary" />

*Элемент* · *Доступно с: 0.13.0* · *Флаг функции: требует функцию `html`*

Элемент, который размещает своё содержимое как встроенный SVG.

Иногда преобразование содержимого Typst в HTML нежелательно. Это может быть в случае с графиками и другим содержимым, которое полагается на позиционирование и стилизацию для передачи своего сообщения.

Эта функция позволяет использовать механизм вёрстки Typst, который также применяется при экспорте в PDF, SVG и PNG, чтобы отрисовать часть вашего документа в точности так, как она выглядела бы при экспорте в одном из этих форматов. Она встраивает содержимое как встроенный SVG.

## Параметры [#parameters]

```typst
html.frame(content)
```

### `body` [#parameters-body]

**Тип:** [content](/docs/typst/reference/foundations/content) · **Модификаторы:** обязательный, позиционный

Содержимое, которое должно быть размещено.
