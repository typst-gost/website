Типизированный слой поверх необработанных HTML-элементов.

Модуль `html` предоставляет типизированный слой поверх необработанной функции [`html.elem`](/docs/typst/reference/format/html/elem), который позволяет удобно создавать HTML-элементы. Атрибуты HTML представлены как параметры функций, принимающие типы Typst и автоматически преобразующие их в соответствующий HTML.

Некоторые параметры являются общими для всех типизированных HTML-функций. Для удобства чтения они перечислены внизу в разделе [Глобальные атрибуты](#global-attributes), а не явно у каждого элемента.

## Пример [#example]

```typst
#html.video(
  controls: true,
  width: 1280,
  height: 720,
  src: "sunrise.mp4",
)[
  Your browser does not support the video tag.
]
```

## Глобальные атрибуты [#global-attributes]

Эти параметры являются общими для всех типизированных HTML-функций. Для удобства чтения они перечислены здесь один раз, а не явно у каждого элемента.

### `accesskey` [#global-attributes-accesskey]

**Тип:** [str](/docs/typst/reference/foundations/str) или [array](/docs/typst/reference/foundations/array)

Сочетание клавиш для активации или фокусировки элемента. Ожидается строка из одного кодового символа или массив таких строк.

### `aria-activedescendant` [#global-attributes-aria-activedescendant]

**Тип:** [str](/docs/typst/reference/foundations/str)

Определяет текущий активный элемент, когда фокус DOM находится на составном виджете, текстовом поле, группе или приложении.

### `aria-atomic` [#global-attributes-aria-atomic]

**Тип:** [bool](/docs/typst/reference/foundations/bool)

Указывает, будут ли вспомогательные технологии представлять всю изменённую область или только её части на основе уведомлений об изменениях, определённых атрибутом aria-relevant.

### `aria-autocomplete` [#global-attributes-aria-autocomplete]

**Тип:** [none](/docs/typst/reference/foundations/none) или [str](/docs/typst/reference/foundations/str)

Указывает, может ли ввод текста вызывать отображение одного или нескольких предсказаний предполагаемого значения пользователя для поля ввода, и определяет, как будут представлены предсказания, если они сделаны.

| **Вариант** | **Описание** |
| --- | --- |
| `"inline"` | Когда пользователь вводит данные, текст, предлагающий один из способов завершения введённых данных, может динамически вставляться после курсора. |
| `"list"` | Когда пользователь вводит данные, может отображаться элемент, содержащий набор значений, которые могут завершить введённые данные. |
| `"both"` | Когда пользователь вводит данные, может отображаться элемент, содержащий набор значений, которые могут завершить введённые данные. Если он отображается, одно значение из набора выбирается автоматически, и текст, необходимый для завершения автоматически выбранного значения, появляется после курсора в поле ввода. |

### `aria-busy` [#global-attributes-aria-busy]

**Тип:** [bool](/docs/typst/reference/foundations/bool)

Указывает, что элемент изменяется и что вспомогательные технологии МОГУТ захотеть подождать, пока изменения не будут завершены, прежде чем представлять их пользователю.

### `aria-checked` [#global-attributes-aria-checked]

**Тип:** [bool](/docs/typst/reference/foundations/bool) или [str](/docs/typst/reference/foundations/str)

Указывает текущее состояние «отмечено» флажков, переключателей и других виджетов. См. связанные aria-pressed и aria-selected.

| **Вариант** | **Описание** |
