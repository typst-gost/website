Формат экспорта PNG в Typst.

Вместо создания PDF Typst также может напрямую отрисовывать страницы в растровую графику PNG. PNG — это изображения со сжатием без потерь, которые могут содержать одну страницу за раз. При экспорте многостраничного документа Typst создаст несколько PNG-файлов. PNG — хороший выбор, если вы хотите использовать результат работы Typst в программе для редактирования изображений или если вы не можете использовать другие форматы экспорта Typst.

В отличие от других форматов экспорта Typst, PNG привязаны к определённому разрешению. При экспорте в PNG вы можете настроить разрешение в пикселях на дюйм (PPI). Если носитель, на котором вы просматриваете PNG, имеет более высокое разрешение, чем экспортированный PNG, вы заметите потерю качества. Typst вычисляет разрешение ваших PNG-файлов на основе физических размеров каждой страницы и значения PPI. Если вам нужны рекомендации по выбору значения PPI, учтите следующее:

- Значение 300 или 600 типично для настольной печати.
- Профессиональная печать детализированной графики может достигать 1200 PPI.
- Если ваш документ просматривается только на расстоянии, например плакат, вы можете выбрать значение меньше 300.
- Если ваш документ просматривается на экранах, типичное значение PPI для смартфона составляет 400–500.

Поскольку PNG содержат только пиксельную растровую сетку, текст внутри них нельзя извлечь автоматически (без OCR), например, с помощью копирования/вставки или программы экранного доступа. Если вам нужна доступность текста, экспортируйте вместо этого файл PDF или HTML.

PNG могут иметь прозрачный фон. По умолчанию Typst выводит PNG с непрозрачным белым фоном. Вы можете сделать фон прозрачным с помощью `#set page(fill: none)`. Подробнее на [странице справки функции `page`](/docs/typst/reference/layout/page#parameters-fill).

## Экспорт в PNG [#exporting-as-png]

### Командная строка [#command-line]

Передайте `--format png` в подкоманду `compile` или `watch` либо укажите имя выходного файла, оканчивающееся на `.png`.

Если ваш документ содержит более одной страницы, Typst создаст несколько файлов изображений. Имя выходного файла тогда должно быть строкой-шаблоном, содержащей хотя бы один из следующих элементов:

- `{p}`, который будет заменён номером страницы
- `{0p}`, который будет заменён номером страницы с ведущими нулями (чтобы все номера имели одинаковую длину)
- `{t}`, который будет заменён общим числом страниц

При экспорте в PNG доступны следующие параметры конфигурации:

- Разрешение для отрисовки, задаваемое с помощью `--ppi`, за которым следует число пикселей на дюйм. По умолчанию — `144`.
- Какие страницы экспортировать, задаваемые с помощью `--pages`, за которым следует список номеров, разделённых запятыми, или диапазонов номеров, разделённых дефисами. Диапазоны могут быть полуоткрытыми. Пример: `2,3,7-9,11-`.

### Веб-приложение [#web-app]

Нажмите «File» \> «Export as» \> «PNG» или нажмите стрелку вниз рядом с кнопкой быстрого скачивания и выберите «Export as PNG». При экспорте в PNG доступны следующие параметры конфигурации:

- Разрешение, с которым должны отрисовываться страницы, в виде числа пикселей на дюйм. По умолчанию — `144`.
- Какие страницы экспортировать. Допустимые варианты: «All pages», «Current page» и «Custom ranges». Пользовательские диапазоны — это список номеров, разделённых запятыми, или диапазонов номеров, разделённых дефисами. Диапазоны могут быть полуоткрытыми. Пример: `2,3,7-9,11-`.

## Параметры [#parameters]

```typst
format.png(ppi: float) -> content
```

### `ppi` [#parameters-ppi]

**Тип:** [float](/docs/typst/reference/foundations/float) · **Модификаторы:** Settable · **По умолчанию:** `144.0`

Значение PPI (пикселей на дюйм), используемое для экспорта в PNG.
