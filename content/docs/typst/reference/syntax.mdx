Typst — это язык разметки. Это означает, что вы можете использовать простой синтаксис для решения типичных задач вёрстки. Лёгкий синтаксис разметки дополняется правилами set и show, которые позволяют легко и автоматически стилизовать документ. Всё это опирается на тесно интегрированный язык сценариев со встроенными и пользовательскими функциями.

## Режимы [#modes]

В Typst есть три синтаксических режима: разметка, математика и код. Режим разметки используется в документе Typst по умолчанию, режим математики позволяет писать математические формулы, а режим кода даёт доступ к возможностям языка сценариев Typst.

Вы можете переключиться в определённый режим в любой момент, обратившись к следующей таблице:

| **Новый режим** | **Синтаксис** | **Пример** |
| --- | --- | --- |
| Код | Поставьте перед кодом `#` | `Number: #(1 + 2)` |
| Математика | Окружите уравнение символами `$..$` | `$-x$ is the opposite of $x$` |
| Разметка | Окружите разметку символами `[..]` | `let name = [*Typst!*]` |

После того как вы вошли в режим кода с помощью `#`, дополнительные решётки не нужны, если только вы не переключились обратно в режим разметки или математики.

## Режим математики [#math]

Режим математики — это специальный режим разметки, используемый для набора математических формул. В него входят, окружая уравнение символами `$`. Это работает как в разметке, так и в коде. Уравнение будет набрано отдельным блоком, если оно начинается и заканчивается хотя бы одним пробелом (например, `$ x^2 $`). Встроенную математику можно получить, опустив пробелы (например, `$x^2$`). Ниже приведён обзор синтаксиса, специфичного для режима математики:

| **Название** | **Пример** | **См.** |
| --- | --- | --- |
| Встроенная математика | `$x^2$` | [Математика](/docs/typst/reference/math) |
| Блочная математика | `$ x^2 $` | [Математика](/docs/typst/reference/math) |
| Нижний индекс | `$x_1$` | [`attach`](/docs/typst/reference/math/attach) |
| Верхний индекс | `$x^2$` | [`attach`](/docs/typst/reference/math/attach) |
| Дробь | `$1 + (a+b)/5$` | [`frac`](/docs/typst/reference/math/frac) |
| Разрыв строки | `$x \ y$` | [`linebreak`](/docs/typst/reference/text/linebreak) |
| Точка выравнивания | `$x &= 2 \ &= 3$` | [Математика](/docs/typst/reference/math) |
| Доступ к переменной | `$#x$, $pi$` | [Математика](/docs/typst/reference/math) |

| Сокращение для символа | `$->$`, `$!=$` | [Символы](/docs/typst/reference/symbols#shorthands) |

## Комментарии [#comments]

Комментарии игнорируются Typst и не попадают в вывод. Это полезно для исключения старых версий или добавления примечаний. Чтобы закомментировать одну строку, начните её с `//`:

<TypstRender
  code={`
  // our data barely supports
  // this claim

  We show with $p < 0.05$
  that the difference is
  significant.
`}

## Экранирующие последовательности [#escapes]

Экранирующие последовательности используются для вставки специальных символов, которые трудно набрать или которые имеют особое значение в Typst. Чтобы экранировать символ, поставьте перед ним обратную косую черту. Чтобы вставить любую кодовую точку Unicode, можно записать шестнадцатеричную экранирующую последовательность: `\u{1f600}`. Такие же экранирующие последовательности работают и в [строках](/docs/typst/reference/foundations/str).

  code={`
  I got an ice cream for
  \\$1.50! \\u{1f600}
`}

## Идентификаторы [#identifiers]

Имена переменных, функций и т. д. (_идентификаторы_) могут содержать буквы, цифры, дефисы (`-`) и подчёркивания (`_`). Они должны начинаться с буквы или подчёркивания.

Более точно, синтаксис идентификаторов в Typst основан на [Unicode Standard Annex #31](https://www.unicode.org/reports/tr31/) с двумя расширениями: разрешено использовать `_` в качестве начального символа и разрешено использовать как `_`, так и `-` в качестве последующих символов.

Для многословных идентификаторов рекомендуемое соглашение о регистре — [Kebab case](https://en.wikipedia.org/wiki/Letter_case#Kebab_case). В Kebab case слова пишутся строчными буквами и разделяются дефисами (как в `top-edge`). Это особенно важно при разработке модулей и пакетов для использования другими, поскольку обеспечивает предсказуемость.

<TypstRender
  code={`
  #let kebab-case = [Using hyphen]
  #let _schön = "😊"
  #let 始料不及 = "😱"
  #let π = calc.pi

  #kebab-case
  #if -π < 0 { _schön } else { 始料不及 }
  // -π means -1 * π,
  // so it's not a valid identifier
`}
  image="/typst_docs_assets/images/PZdVoQkwIUj6f5FbGua9uQ.png"
  alt=""
  editable={true}
/>
