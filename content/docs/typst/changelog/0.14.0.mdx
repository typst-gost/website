## Основные изменения [#highlights]

- Typst теперь по умолчанию создаёт [_доступные_ PDF-файлы](/docs/typst/guides/accessibility), с опциональной поддержкой более строгих проверок и соответствия PDF/UA-1
- Typst теперь поддерживает все [стандарты PDF/A](/docs/typst/reference/format/pdf#pdf-a)
- PDF-файлы теперь можно использовать как [изображения](/docs/typst/reference/visualize/image#parameters-format) (спасибо [@LaurenzV](https://github.com/LaurenzV))
- Добавлена поддержка [выключки на уровне символов](/docs/typst/reference/model/par#parameters-justification-limits) (может значительно улучшить внешний вид выключенного текста)
- Добавлена поддержка множества новых встроенных элементов при экспорте в HTML
- Добавлен типизированный HTML API (например, [`html.div`](/docs/typst/reference/format/html/typed#functions-div)) с индивидуально типизированными атрибутами
- Добавлена поддержка нескольких [заголовков](/docs/typst/reference/model/table#definitions-header) и подзаголовков в таблицах
- Добавлен элемент [`title`](/docs/typst/reference/model/title) для отображения названия документа
- Добавлено свойство [`frac.style`](/docs/typst/reference/math/frac#parameters-style) для создания скошенных и строчных дробей

## Экспорт в PDF [#pdf-export]

Экспорт в PDF был полностью переписан с использованием новой библиотеки [`krilla`](https://github.com/LaurenzV/krilla), что исправило различные ошибки и позволило внести множество улучшений. Известные исправления перечислены ниже, но, вероятно, будут и другие изменения в поведении вывода. Если вы обнаружите какие-либо регрессии, пожалуйста, [сообщите о них на GitHub](https://github.com/typst/typst/issues). _(Спасибо [@LaurenzV](https://github.com/LaurenzV) за создание krilla!)_ [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/typst/pull/5420)

- Typst теперь по умолчанию создаёт _доступные_ PDF-файлы. Такие документы подходят для использования в широком спектре обстоятельств. Это касается не только людей с постоянной или временной инвалидностью, но и тех, кто использует другие устройства или имеет иные предпочтения.
  - PDF-файлы Typst теперь по умолчанию _размечены тегами_. _Теги_ — это богатые метаданные, которые программы просмотра PDF могут использовать, чтобы сделать документ доступным не только визуально (например, через программу экранного доступа).
  - Кроме того, Typst теперь может создавать документы, соответствующие стандарту PDF/UA-1. (PDF/UA-2 пока не поддерживается, но это запланировано.)
  - Существует всё больше действующего и готовящегося законодательства, требующего доступности документов, например, Европейский акт о доступности и Закон об американцах с инвалидностью.
  - Для получения более подробной информации обо всём этом прочитайте новое [руководство по доступности](/docs/typst/guides/accessibility).
- Typst теперь поддерживает все стандарты PDF/A: PDF/A-1b, PDF/A-1a, PDF/A-2b, PDF/A-2u, PDF/A-2a, PDF/A-3b, PDF/A-3u, PDF/A-3a, PDF/A-4, PDF/A-4f и PDF/A-4e. См. [расширенную документацию по PDF/A](/docs/typst/reference/format/pdf#pdf-a) для получения рекомендаций о том, как выбрать подходящий стандарт. [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/typst/pull/5420) [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/typst/pull/7038)
- Typst теперь поддерживает версии PDF 1.4, 1.5, 1.6 и 2.0 в дополнение к PDF 1.7. Подробности см. в [соответствующем разделе документации по PDF](/docs/typst/reference/format/pdf#pdf-versions). [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/typst/pull/5420)
- Добавлена функция [`pdf.artifact`](/docs/typst/reference/format/pdf/artifact) для пометки содержимого как не имеющего семантического значения [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/typst/pull/6619)
- Добавлены экспериментальные функции [`pdf.header-cell`](/docs/typst/reference/format/pdf/header-cell), [`pdf.data-cell`](/docs/typst/reference/format/pdf/data-cell) и [`pdf.table-summary`](/docs/typst/reference/format/pdf/table-summary) для повышения доступности документов со сложными таблицами. Эти функции защищены возможностью `a11y-extras`. Они не имеют окончательного интерфейса и будут удалены в будущем — либо путём интеграции в функции таблиц, либо путём полного удаления. [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/typst/pull/6619)
- Закладки заголовков PDF теперь содержат нумерацию заголовка [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/typst/pull/6622)

## Символы [#symbols]

- Добавлено множество новых символов и вариантов; гораздо больше, чем можно перечислить здесь. Полный список см. в [отдельном списке изменений](https://github.com/typst/codex/blob/v0.2.0/CHANGELOG.md#version-020-october-7-2025).
- Кодовые точки, имеющие представление в виде символа и в виде эмодзи, теперь имеют правильный селектор вариантов в зависимости от того, появляются ли они в `sym` или `emoji`. Тем не менее, они по-прежнему отображаются непоследовательно в Typst из-за того, как работает резервный шрифт. [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/codex/pull/114)
- Функцию [`symbol`](/docs/typst/reference/foundations/symbol) теперь можно использовать для создания символов, состоящих не из одного символа, а из одного полного кластера графем [<img src="/typst_docs_assets/icons/16-link.svg" alt="Link" width="16" height="16" />](https://github.com/typst/typst/pull/6489)
