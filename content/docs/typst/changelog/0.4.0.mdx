## Сноски [#footnotes]

- Реализована поддержка сносок
- Функция [`footnote`](/docs/typst/reference/model/footnote) вставляет сноску
- Функцию [`footnote.entry`](/docs/typst/reference/model/footnote#definitions-entry) можно использовать для настройки списка сносок
- Теперь доступен [стиль цитирования](/docs/typst/reference/model/cite#parameters-style) `"chicago-notes"`

## Документация [#documentation]

- Добавлено [руководство для пользователей LaTeX](/docs/typst/guides/for-latex-users)
- Теперь отображаются значения по умолчанию для необязательных аргументов
- Добавлены более подробные оглавления в разделе «На этой странице»
- Добавлена начальная поддержка ключевых слов для поиска: «Table of Contents» теперь найдёт функцию [outline](/docs/typst/reference/model/outline). Предложения по новым ключевым словам приветствуются!
- Исправлена проблема с ранжированием результатов поиска
- Исправлено множество других мелких проблем

## Математика [#math]

- **Ломающее изменение**: Точки выравнивания (`&`) в уравнениях теперь чередуются между выравниванием по левому и правому краю
- Добавлена поддержка записи корней с помощью Unicode: например, `$root(x+y)$` теперь можно также записать как `$√(x+y)$`
- Исправлено неравномерное вертикальное выравнивание [`attachment`](/docs/typst/reference/math/attach#functions-attach)
- Исправлены отступы у декорированных элементов (например, отступы вокруг [зачёркнутого](/docs/typst/reference/math/cancel) оператора)
- Исправлена стилизация растяжимых символов
- Добавлены [символы](/docs/typst/reference/symbols/sym) `tack.r.double`, `tack.l.double`, `dotless.i` и `dotless.j`
- Исправлены правила show для символов (например, `show sym.tack: set text(blue)`)
- Исправлено отсутствующее переименование из `ast.op` в `ast`, которое должно было быть в предыдущем выпуске

## Скрипты [#scripting]

- Добавлены области видимости функций: теперь функция может содержать связанные определения в собственной области видимости, подобно модулю. Новая функция [`assert.eq`](/docs/typst/reference/foundations/assert#definitions-eq), например, является частью области видимости функции [`assert`](/docs/typst/reference/foundations/assert). Обратите внимание, что области видимости функций в настоящее время доступны только для встроенных функций.
- Добавлены функции [`assert.eq`](/docs/typst/reference/foundations/assert#definitions-eq) и [`assert.ne`](/docs/typst/reference/foundations/assert#definitions-ne) для более простых проверок равенства и неравенства с более информативными сообщениями об ошибках
- Элементы [списков](/docs/typst/reference/model/list#definitions-item), [перечислений](/docs/typst/reference/model/enum#definitions-item) и [списков терминов](/docs/typst/reference/model/terms#definitions-item) теперь доступны в области видимости соответствующих функций
- Методы `at` для [строк](/docs/typst/reference/foundations/str#definitions-at), [массивов](/docs/typst/reference/foundations/array#definitions-at), [словарей](/docs/typst/reference/foundations/dictionary#definitions-at) и [контента](/docs/typst/reference/foundations/content#definitions-at) теперь поддерживают указание значения по умолчанию
- Добавлена поддержка передачи функции в [`replace`](/docs/typst/reference/foundations/str#definitions-replace), которая вызывается для каждого совпадения.
- Исправлены строки [замены](/docs/typst/reference/foundations/str#definitions-replace): теперь они вставляются полностью дословно вместо поддержки прежнего (непреднамеренного) магического синтаксиса с долларом для групп захвата
- Исправлена ошибка с завершающими заполнителями в шаблонах деструктуризации
- Исправлена ошибка с подчёркиванием в деструктуризации параметров
- Исправлено падение при вложенных шаблонах и при наведении на недопустимый шаблон
- Улучшены сообщения об ошибках при неудачном приведении к [целому числу](/docs/typst/reference/foundations/int) или [числу с плавающей точкой](/docs/typst/reference/foundations/float)

## Текст и вёрстка [#text-and-layout]

- Реализована сложная корректировка пунктуации CJK
- Отключён [выступ](/docs/typst/reference/text/text#parameters-overhang) для пунктуации CJK
- Добавлены базовые переводы для традиционного китайского
- Исправлено [выравнивание](/docs/typst/reference/text/raw#parameters-align) текста внутри блоков raw (центрирование блока raw, например, через figure, теперь сохраняет сам текст выровненным по левому краю)
- Добавлена поддержка передачи массива вместо функции для настройки [выравнивания](/docs/typst/reference/model/table#parameters-align) и [заливки](/docs/typst/reference/model/table#parameters-fill) ячеек таблицы по столбцам
- Исправлено автоматическое определение [`kind`](/docs/typst/reference/model/figure#parameters-kind) для figure
- Сделано настраиваемым выравнивание [номеров перечислений](/docs/typst/reference/model/enum#parameters-number-align), по умолчанию — `end`
- Теперь figure можно сделать разрывным с помощью правила show-set для блоков в figure
- Первоначальное исправление умных кавычек в языках RTL

## Экспорт [#export]

- Исправлены лигатуры при экспорте в PDF: теперь их можно копировать и искать
- Экспортированные PDF-файлы теперь встраивают профили ICC для изображений, которые их имеют
- Исправлен экспорт штрихов нулевой толщины

## Веб-приложение [#web-app]

- Проекты теперь могут содержать папки
- Добавлена загрузка перетаскиванием в панель файлов
- Файлы из панели файлов теперь можно перетаскивать в редактор, чтобы вставить их в файл Typst
- Теперь можно копировать и вставлять изображения и другие файлы с компьютера прямо в редактор
- Добавлена кнопка для повторной отправки письма с подтверждением
- Добавлена опция инвертирования цветов предпросмотра в тёмном режиме
- Добавлены подсказки на экран загрузки и в меню «Справка». Не стесняйтесь предлагать новые!
- Добавлена подсветка синтаксиса для файлов YAML
- Разрешено открывать многие кнопки в новой вкладке щелчком средней кнопкой мыши
- Разрешено больше названий проектов
- Исправлены переопределённые сочетания клавиш в режиме Vim
- Исправлено множество ошибок, связанных с загрузкой файлов, и другое

## Прочие улучшения [#miscellaneous-improvements]

- Повышена производительность счётчиков, состояния и запросов
- Улучшен инкрементальный разбор для более эффективных повторных компиляций
- Добавлена поддержка расширения `.yaml` в дополнение к `.yml` для библиографий
- CLI теперь выводит escape-коды только если вывод направлен в TTY
- Для пользователей крейта `typst`: `Document` снова является `Sync`, а `World` больше не обязан быть `'static`
