## Управление пакетами [#package-management]

- В Typst теперь есть встроенное [управление пакетами](/docs/typst/reference/scripting#packages)
- Вы можете импортировать [опубликованные](https://typst.app/universe) пакеты сообщества или создавать и использовать [локальные для системы](https://github.com/typst/packages#local-packages) пакеты
- Опубликованные пакеты также поддерживаются в веб-приложении

## Математика [#math]

- Добавлена поддержка оптических размеров вариантов глифов в математическом режиме
- Добавлен аргумент для условного включения [`limits`](/docs/typst/reference/math/attach#functions-limits) в зависимости от того, задано ли уравнение в стиле [`display`](/docs/typst/reference/math/sizes#functions-display) или [`inline`](/docs/typst/reference/math/sizes#functions-inline)
- Добавлены символы `gt.eq.slant` и `lt.eq.slant`
- Повышен приоритет факториалов в математическом режиме (теперь `$1/n!$` работает корректно)
- Улучшены [подчёркивания](/docs/typst/reference/math/underover#functions-underline) и [надчёркивания](/docs/typst/reference/math/underover#functions-overline) в математическом режиме
- Исправлено использование функции [`limits`](/docs/typst/reference/math/attach#functions-limits) в правилах show
- Исправлены ошибки с переносами строк в уравнениях

## Текст и вёрстка [#text-and-layout]

- Добавлена поддержка чередующихся [полей](/docs/typst/reference/layout/page#parameters-margin) страницы с ключами `inside` и `outside`
- Добавлена поддержка указания [`binding`](/docs/typst/reference/layout/page#parameters-binding) страницы
- Добавлен аргумент [`to`](/docs/typst/reference/layout/pagebreak#parameters-to) функции pagebreak для перехода к следующей чётной или нечётной странице
- Добавлена базовая интернационализация для ещё нескольких языков (TR, SQ, TL)
- Исправлена ошибка с пропадающей строкой таблицы при разрыве страницы
- Исправлена ошибка с [подчёркиваниями](/docs/typst/reference/text/underline)
- Исправлена ошибка с лишними линиями таблицы
- Исправлены типографские кавычки после переносов строк
- Исправлено падение, связанное с вёрсткой текста

## Интерфейс командной строки [#command-line-interface]

- **Обратно несовместимое изменение:** Добавлено требование, чтобы каталог `--root`/`TYPST_ROOT` содержал входной файл, поскольку он обозначает корень _проекта_. Существующие конфигурации, использующие `TYPST_ROOT` для эмуляции управления пакетами, должны перейти на [локальные пакеты](https://github.com/typst/packages#local-packages)
- **Обратно несовместимое изменение:** Теперь запрещён доступ к файлам за пределами корня проекта
- Добавлена поддержка локальных пакетов и загрузки пакетов по требованию
- Теперь отслеживаются все соответствующие файлы, в пределах корня и всех пакетов
- Теперь отображается время компиляции

## Прочие улучшения [#miscellaneous-improvements]

- Добавлен [`outline.entry`](/docs/typst/reference/model/outline#definitions-entry) для настройки элементов оглавления с помощью правил show
- Добавлены некоторые подсказки для сообщений об ошибках
- Добавлены некоторые недостающие синтаксисы для подсветки [`raw`](/docs/typst/reference/text/raw)
- Улучшен рендеринг повёрнутых изображений при экспорте в PNG и в веб-приложении
- [Сноски](/docs/typst/reference/model/footnote) сделаны переиспользуемыми и доступными для ссылок
- Исправлена ошибка с цитатами и библиографиями в [`locate`](/docs/typst/reference/introspection/locate)
- Исправлена несогласованность времён в документации

## Разработка [#development]

- Добавлено [руководство по участию](https://github.com/typst/typst/blob/main/CONTRIBUTING.md)
- Переработан интерфейс `World` для поддержки управления пакетами и упрощения его реализации _(Обратно несовместимое изменение для разработчиков реализаций)_
