## Основные изменения [#highlights]

- Добавлена поддержка многоколоночного плавающего [размещения](/docs/typst/reference/layout/place#parameters-scope) и [иллюстраций](/docs/typst/reference/model/figure#parameters-scope)
- Добавлена поддержка автоматической [нумерации строк](/docs/typst/reference/model/par#definitions-line) (часто используется в научных статьях)
- Механизм вёрстки Typst теперь многопоточный. Типичное ускорение составляет 2–3 раза для больших документов. Многопоточность работает на границах разрывов страниц, поэтому для её включения необходимы явные разрывы страниц.
- Выравнивание абзацев оптимизировано с помощью нового двухпроходного алгоритма. Ускорение больше для коротких абзацев и достигает 6 раз.
- Значительно уменьшены размеры PDF-файлов благодаря улучшенному подмножеству шрифтов (спасибо [@LaurenzV](https://github.com/LaurenzV))
- Эмодзи теперь корректно экспортируются в PDF
- Добавлена начальная поддержка PDF/A. На данный момент поддерживается только профиль PDF/A-2b, но в будущем планируется больше.
- Добавлены различные параметры для настройки окружения CLI (шрифты, пути к пакетам и т. д.)
- Правила show для текста теперь срабатывают на нескольких текстовых элементах
- Блочные формулы теперь могут по желанию разрываться на несколько страниц
- Исправлена ошибка, из-за которой некоторые шрифты неправильно печатались на профессиональных принтерах
- Исправлена давняя ошибка, из-за которой заголовки могли оставаться в одиночестве внизу страницы

## Вёрстка [#layout]

- Добавлена поддержка многоколоночного плавающего размещения и иллюстраций через [`place.scope`](/docs/typst/reference/layout/place#parameters-scope) и [`figure.scope`](/docs/typst/reference/model/figure#parameters-scope). В двухколоночных документах теперь следует предпочитать `set page(columns: 2)` вместо `show: column.with(2)` (см. [Руководство по настройке страницы](/docs/typst/guides/page-setup#columns)).
- Добавлена поддержка автоматической [нумерации строк](/docs/typst/reference/model/par#definitions-line) (часто используется в научных статьях)
- Добавлено свойство [`par.spacing`](/docs/typst/reference/model/par#parameters-spacing) для настройки интервала между абзацами. Теперь его следует использовать вместо `show par: set block(spacing: ..)` **(Обратно несовместимое изменение)**
- Блочные элементы, такие как списки, сетки и стеки, теперь отображаются как блоки и, следовательно, подвержены влиянию всех свойств блока (например, `stroke`), а не только `spacing` **(Обратно несовместимое изменение)**
- Добавлено свойство [`block.sticky`](/docs/typst/reference/layout/block#parameters-sticky), которое предотвращает разрыв страницы после блока
- Добавлена функция [`place.flush`](/docs/typst/reference/layout/place#definitions-flush), которая принудительно размещает все плавающие иллюстрации перед любым последующим содержимым
- Добавлена функция [`skew`](/docs/typst/reference/layout/skew)
- Добавлена опция `auto` для [`page.header`](/docs/typst/reference/layout/page#parameters-header) и [`page.footer`](/docs/typst/reference/layout/page#parameters-footer), которая приводит к автоматическому колонтитулу на основе нумерации (который ранее был недоступен после изменения)
- Добавлены параметры `gap` и `justify` в функцию [`repeat`](/docs/typst/reference/layout/repeat)
- Добавлены параметры `width` и `height` в функцию [`measure`](/docs/typst/reference/layout/measure) для определения пространства, в котором следует измерять содержимое. Особенно полезно в сочетании с [`layout`](/docs/typst/reference/layout/layout).
- Высота `block`, `image`, `rect`, `square`, `ellipse` или `circle` теперь может быть указана в [дробных единицах](/docs/typst/reference/layout/fraction)
- Функция [`scale`](/docs/typst/reference/layout/scale) теперь поддерживает абсолютные длины для `x`, `y`, `factor`. Таким образом, элемент неизвестного размера может быть масштабирован до фиксированного размера.
- Значения `block.above` и `block.below` теперь можно получить в контекстных выражениях.
- Повышена точность преобразования между абсолютными единицами (pt, mm, cm, in)
- Исправлена ошибка, из-за которой заголовки могли оставаться в одиночестве внизу страницы
- Исправлено появление сносок внутри разрывных блоков на странице, где заканчивается разрывный блок, вместо страницы, где находится маркер сноски
- Исправлена нумерация вложенных сносок и сносок в плавающих элементах
- Исправлено появление пустых страниц, когда выражение [context](/docs/typst/reference/context) охватывает целые страницы
- Исправлено поведение `set block(spacing: x)`, отличавшееся от `set block(above: x, below: x)`
- Исправлено поведение [`rotate`](/docs/typst/reference/layout/rotate) и [`scale`](/docs/typst/reference/layout/scale) с `reflow: true`
- Исправлено взаимодействие `align(horizon)` и `v(1fr)`
- Исправлены различные ошибки, из-за которых плавающее размещение давало перекрывающиеся результаты
- Исправлена ошибка, из-за которой предотвращение висячих/одиноких строк без необходимости перемещало текст в следующую колонку
- Исправлено, что [слабый интервал](/docs/typst/reference/layout/h#parameters-weak) не обрезался в начале и конце строк в абзаце (только в начале и конце абзацев)
- Исправлено взаимодействие слабого разрыва страницы и [`pagebreak.to`](/docs/typst/reference/layout/pagebreak#parameters-to)
- Исправлен вывод компиляции одиночного слабого разрыва страницы
- Исправлено падение при [отступе](/docs/typst/reference/layout/pad) в `100%`

## Текст [#text]

- Настроена расстановка переносов: по умолчанию она менее агрессивна, а переносы вблизи краёв слов теперь избегаются более строго **(Может привести к более крупным перекомпоновкам вёрстки)**
- Новый шрифт по умолчанию: Libertinus Serif. Это поддерживаемый преемник старого шрифта по умолчанию Linux Libertine. **(Может привести к небольшим перекомпоновкам)**
- Установка шрифта на недоступное семейство теперь приводит к предупреждению
- Реализован новый алгоритм умных кавычек, исправляющий различные ошибки, из-за которых умные кавычки были не такими уж умными
- Добавлен параметр [`text.costs`](/docs/typst/reference/text/text#parameters-costs) для настройки различных параметров, влияющих на выбор механизма вёрстки при вёрстке текста
- Добавлен режим подсветки `typm` для математики в [блоках raw](/docs/typst/reference/text/raw#parameters-lang)
- Добавлена базовая интернационализация для галисийского, каталанского, латинского, исландского, иврита
- Реализовано дублирование переносов для чешского, хорватского, нижнелужицкого, польского, португальского, словацкого и испанского.
- Функция [`smallcaps`](/docs/typst/reference/text/smallcaps) теперь является элементной функцией и, следовательно, может использоваться в правилах show(-set).
- Параметр [`raw.theme`](/docs/typst/reference/text/raw#parameters-theme) теперь можно установить в `none`, чтобы отключить подсветку даже при наличии языкового тега, и в `auto`, чтобы сбросить к значению по умолчанию
- Теперь можно одновременно включить несколько [стилистических наборов](/docs/typst/reference/text/text#parameters-stylistic-set)
- Исправлен китайский перевод «Equation»
- Исправлено, что перенос мог происходить вне слов
- Исправлена некорректная вёрстка двунаправленного текста в граничных случаях
- Исправлена вёрстка абзацев с явными завершающими пробелами
- Исправлены ошибки, связанные с пустыми абзацами, созданными через `#""`
- Исправлены случайные завершающие пробелы для разрывов строк, непосредственно предшествующих встроенной формуле
- Исправлено, что [`text.historical-ligatures`](/docs/typst/reference/text/text#parameters-historical-ligatures) не работал корректно
- Исправлено случайное повторение тайских символов вокруг разрывов строк в некоторых обстоятельствах
- Исправлены [умные кавычки](/docs/typst/reference/text/smartquote) для швейцарского французского
- Новые исключения метаданных шрифтов для Archivo, Kaiti SC и Kaiti TC
- Встроенные шрифты New Computer Modern обновлены до версии 6.0

## Математика [#math]

- Блочные формулы теперь могут разрываться на несколько страниц, если это включено через `show math.equation: set block(breakable: true)`.
- Размеры матриц и векторов теперь более согласованы для различного содержимого ячеек
- Добавлена функция [`stretch`](/docs/typst/reference/math/stretch) для ручного или автоматического растягивания символов, таких как стрелки или скобки, по горизонтали или вертикали
- Улучшена вёрстка индексов у выражений в скобках, а также под- и надчёркнутых выражений
- Улучшена вёрстка вложенных индексов, возникающих из кода вроде `#let a0 = $a_0$; $a0^1$`
- Улучшена вёрстка штрихов вблизи надстрочных индексов
- Улучшена вёрстка дробей
- Typst теперь использует специфичную для математики информацию о кернинге, зависящем от высоты, в некоторых шрифтах для лучшей вёрстки индексов
- Функции `floor` и `ceil` в математике теперь являются вызываемыми символами, так что `$ floor(x) = lr(floor.l x floor.r) $`
- Параметры [`mat.delim`](/docs/typst/reference/math/mat#parameters-delim), [`vec.delim`](/docs/typst/reference/math/vec#parameters-delim) и [`cases.delim`](/docs/typst/reference/math/cases#parameters-delim) теперь допускают любой символ, который Unicode считает разделителем или «ограждением» (например, |). Запись `delim: "||"` больше _не_ поддерживается и должна быть заменена на `delim: bar.double` **(Незначительное обратно несовместимое изменение)**
- Добавлены параметры [`vec.align`](/docs/typst/reference/math/vec#parameters-align) и [`mat.align`](/docs/typst/reference/math/mat#parameters-align)
- Добавлены [`underparen`](/docs/typst/reference/math/underover#functions-underparen), [`overparen`](/docs/typst/reference/math/underover#functions-overparen), [`undershell`](/docs/typst/reference/math/underover#functions-undershell) и [`overshell`](/docs/typst/reference/math/underover#functions-overshell)
- Добавлено сокращение `~` для `tilde.op` в математическом режиме **(Незначительное обратно несовместимое изменение)**
- Исправлено выравнивание базовой линии номеров формул
- Исправлено позиционирование угловых скобок (⌜, ⌝, ⌞, ⌟)
- Исправлена базовая линия больших корней
- Исправлены множественные незначительные ошибки вёрстки индексов
- Исправлено, что точки выравнивания могли влиять на высоту строки в математике
- Исправлено, что пробелы могли появляться между текстом и невидимыми элементами, такими как [`metadata`](/docs/typst/reference/introspection/metadata), в математике
- Исправлено падение при рекурсивных правилах show в математике
- Исправлено, что [`lr.size`](/docs/typst/reference/math/lr#functions-lr-size) в некоторых случаях не влиял на символы, заключённые в [`mid`](/docs/typst/reference/math/lr#functions-mid)
- Исправлено разрешение единиц em в под- и надстрочных индексах
- Исправлена ограничивающая рамка встроенных формул, когда [край текста](/docs/typst/reference/text/text#parameters-top-edge) установлен в `"bounds"`

## Интроспекция [#introspection]

- Реализована новая система, с помощью которой Typst отслеживает, где элементы оказываются на страницах. Это может привести к тонко отличающемуся поведению при интроспекции. **(Обратно несовместимое изменение)**
- Исправлены различные ошибки с неправильным поведением счётчиков в сложных ситуациях вёрстки благодаря новой, более принципиальной реализации
- Обновления счётчиков теперь могут происходить до первой, между и после последней страницы, когда они изолированы слабыми разрывами страниц. Это позволяет, например, обновлять счётчик перед колонтитулом и фоном первой страницы.
- Исправлен логический порядок интроспекций внутри сносок и иллюстраций
- Исправлен некорректный [`here().position()`](/docs/typst/reference/introspection/here), когда [`place`](/docs/typst/reference/layout/place) использовался в контекстном выражении
- Исправлены разрешённые позиции элементов (в частности, заголовков), чьё правило show выдаёт невидимый элемент (например, обновление состояния) перед разрывом страницы
- Исправлено поведение шага счётчика на более глубоком уровне, чем его текущее состояние
- Исправлено, что форматирование цитирования не работало в заголовках таблиц и некоторых других местах
- Отображение счётчика сносок теперь учитывает стиль нумерации сносок

## Модель [#model]

- Правила set документа больше не обязаны находиться в самом начале документа. Единственное ограничение — они не должны встречаться внутри контейнеров вёрстки.
- Свойство `spacing` для [списков](/docs/typst/reference/model/list#parameters-spacing), [перечислений](/docs/typst/reference/model/enum#parameters-spacing) и [списков терминов](/docs/typst/reference/model/terms#parameters-spacing) теперь также учитывается для плотных списков
- Плотные списки теперь прикрепляются (с более плотным интервалом) только к предшествующим абзацам, а не к произвольным блокам
- Элемент [`quote`](/docs/typst/reference/model/quote) теперь является локализуемым (может использоваться в запросах)
- Заголовок библиографии теперь использует `depth` вместо `level`, так что его уровень по-прежнему можно настроить через правило show-set
- Добавлена поддержка дополнительных форматов [нумерации](/docs/typst/reference/model/numbering): деванагари, восточноарабские, бенгальские и числа в кружках
- Добавлен параметр [`hanging-indent`](/docs/typst/reference/model/heading#parameters-hanging-indent) в функцию заголовка для настройки внешнего вида многострочных заголовков и улучшен внешний вид многострочных заголовков по умолчанию
- Улучшена обработка двунаправленного текста в элементе оглавления
- Исправлено, что правила set документа игнорировались в остальном пустом документе
- Исправлено, что правила set документа нельзя было использовать в контекстных выражениях
- Исправлено плохое взаимодействие между `set document` и `set page`
- Исправлено `show figure: set align(..)`. Поскольку выравнивание иллюстраций по умолчанию теперь является правилом show-set, оно больше не отменяется через `show figure: it => it.body`. **(Незначительное обратно несовместимое изменение)**
- Исправлена нумерация ссылок на сноски
- Исправлен интервал после заголовка библиографии

## Библиография [#bibliography]

- Поле `publisher` в YAML Hayagriva теперь может принимать словарь с ключом `location`. Ключ `location` верхнего уровня теперь в первую очередь предназначен для мест проведения событий и местоположений элементов.
- Теперь допускаются несколько диапазонов страниц с префиксами и суффиксами
- Добавлены типы редакторов `director` и универсальный редактор в разбор BibLaTeX
- Добавлена поддержка устранения неоднозначности для буквенно-цифрового стиля цитирования
- Год 0 теперь будет отображаться как 1BC
- Исправления сортировки записей библиографии
- Исправлено склонение меток диапазонов страниц
- Исправлена сортировка цитат по их номеру
- Исправлено, как сворачиваются диапазоны номеров цитат
- Исправлено, когда используется краткая форма названия
- Исправлен разбор несбалансированных знаков доллара в поле `url` BibLaTeX
- Обновлены встроенные стили цитирования

## Визуализация [#visualization]

- Добавлен параметр `fill-rule` в функции `path` и [`polygon`](/docs/typst/reference/visualize/polygon#parameters-fill-rule)
- Исправлено смешивание цветов и градиенты для [цветов Luma](/docs/typst/reference/visualize/color#definitions-luma)
- Исправлено преобразование из цветов Luma в цвета CMYK
- Исправлены смещённые градиентные обводки при экспорте в PNG
- Исправлено непреднамеренное обрезание некоторых SVG
- SVG с внешними объектами теперь выдают предупреждение, так как они, вероятно, не будут корректно отображаться в Typst

## Синтаксис [#syntax]

- Добавлена поддержка вложенных импортов, таких как `import "file.typ": module.item`
- Добавлена поддержка импортов в скобках, таких как `import "file.typ": (a, b, c)`. С ними список импорта может разрываться на несколько строк.
- Исправлен граничный случай при разборе синтаксиса ссылок
- Исправлен граничный случай при разборе маркеров заголовков, списков, перечислений и терминов, непосредственно за которыми следуют комментарии
- Исправлено редкое падение при разборе выражений в скобках

## Скрипты [#scripting]

- Добавлен новый тип чисел с фиксированной точкой [`decimal`](/docs/typst/reference/foundations/decimal) для высокоточной арифметики над числами по основанию 10, как требуется в финансах
- Добавлен модуль `std` для доступа к определениям стандартной библиотеки, даже когда переменная с тем же именем затеняет/перезаписывает его
- Добавлены методы [`array.to-dict`](/docs/typst/reference/foundations/array#definitions-to-dict), [`array.reduce`](/docs/typst/reference/foundations/array#definitions-reduce), [`array.windows`](/docs/typst/reference/foundations/array#definitions-windows)
- Добавлен аргумент `exact` в [`array.zip`](/docs/typst/reference/foundations/array#definitions-zip)
- Добавлен метод [`arguments.at`](/docs/typst/reference/foundations/arguments#definitions-at)
- Добавлены [`int.from-bytes`](/docs/typst/reference/foundations/int#definitions-from-bytes), [`int.to-bytes`](/docs/typst/reference/foundations/int#definitions-to-bytes), [`float.from-bytes`](/docs/typst/reference/foundations/float#definitions-from-bytes) и [`float.to-bytes`](/docs/typst/reference/foundations/float#definitions-to-bytes)
- Добавлена надлежащая поддержка отрицательных значений параметра `digits` в [`calc.round`](/docs/typst/reference/foundations/calc#functions-round) (поведение существовало и раньше, но было тонко нарушено)
- Преобразования из [`int`](/docs/typst/reference/foundations/int) в [`float`](/docs/typst/reference/foundations/float) теперь будут выдавать ошибку вместо насыщения, если число с плавающей точкой слишком велико **(Незначительное обратно несовместимое изменение)**
- Добавлены [`float.nan`](/docs/typst/reference/foundations/float#definitions-nan) и [`float.inf`](/docs/typst/reference/foundations/float#definitions-inf), удалён `calc.nan` **(Незначительное обратно несовместимое изменение)**
- Некоторые символы теперь в целом вызываемы как функции, а не только специально в математике. Примеры — акценты или [`floor`](/docs/typst/reference/math/lr#functions-floor) и [`ceil`](/docs/typst/reference/math/lr#functions-ceil).
- Улучшено [`repr`](/docs/typst/reference/foundations/repr) относительных значений, последовательностей, бесконечностей, NaN, `type(none)` и `type(auto)`
- Исправлено падение при циклическом импорте целых пакетов (а не только файлов) друг другом
- Исправлен тип возвращаемого значения [`calc.round`](/docs/typst/reference/foundations/calc#functions-round) для целых чисел, когда для `digits` указано ненулевое значение

- Строка `"` в правиле show для текста теперь соответствует умным кавычкам
- Исправлена давняя ошибка стилизации, из-за которой колонтитул неправильно наследовал стили от одинокого элемента на странице (например, заголовка)
- Исправлено, что `set page` не работал непосредственно после обновления счётчика/состояния
- Поля страницы, настроенные через явный вызов `page(..)[..]`, теперь можно корректно получить в контекстных выражениях

## Экспорт [#export]

- Значительно уменьшены размеры PDF-файлов благодаря улучшенному подмножеству шрифтов
- Эмодзи теперь корректно экспортируются в PDF
- Добавлена начальная поддержка PDF/A. На данный момент поддерживается только стандарт PDF/A-2b, но в будущем планируется больше. Включается через `--pdf-standard a-2b` в CLI и через интерфейс в File \> Export as \> PDF в веб-приложении.
- Установка [`page.fill`](/docs/typst/reference/layout/page#parameters-fill) в `none` теперь приводит к прозрачным страницам вместо белых в PNG и SVG. Новое значение по умолчанию `auto` означает прозрачность для PDF и белый цвет для PNG и SVG.
- Улучшено копирование и вставка текста из PDF в сложных сценариях
- Экспортируемые SVG теперь содержат атрибут `data-typst-label` на группах, полученных из помеченных [боксов](/docs/typst/reference/layout/box) и [блоков](/docs/typst/reference/layout/block)
- Исправлена ошибка, из-за которой некоторые шрифты неправильно печатались на профессиональных принтерах
- Исправлена ошибка, из-за которой прозрачность могла перетекать из одного объекта PDF в другой
- Исправлена ошибка с градиентами CMYK в PDF
- Исправлены различные ошибки с экспортом градиентов Oklab в PDF
- Исправлены падения, связанные с отрисовкой глифов без контура
- Два небольших исправления для соответствия стандарту PDF

## Производительность [#performance]

- Механизм вёрстки Typst теперь многопоточный. Типичное ускорение составляет 2–3 раза для больших документов. Многопоточность работает на границах разрывов страниц, поэтому для её включения необходимы явные разрывы страниц.
- Выравнивание абзацев оптимизировано с помощью нового двухпроходного алгоритма. Ускорение больше для коротких абзацев и составляет от 1 до 6 раз.

- Добавлены полезные ссылки в вывод справки
- CLI теперь приветствует пользователей, которые впервые вызывают просто `typst`

- Входные и выходные пути теперь допускают значения, отличные от UTF-8
- Время теперь форматируется более согласованно во всём CLI
- Исправлена ошибка, связанная с флагом `--open`
- Исправлено, что дополнение путей для `typst` не работало в zsh
