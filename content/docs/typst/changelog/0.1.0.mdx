## Ломающие изменения [#breaking-changes]

- При использовании CLI теперь необходимо применять подкоманды:
  - `typst compile file.typ` или `typst c file.typ` для создания PDF
  - `typst watch file.typ` или `typst w file.typ` для компиляции и отслеживания изменений
  - `typst fonts` для вывода списка всех шрифтов
- Ручные счётчики теперь начинаются с нуля. Подробнее см. раздел «How to step» [здесь](/docs/typst/reference/introspection/counter)
- Стили [библиографии](/docs/typst/reference/model/bibliography#parameters-style) `"author-date"` и `"author-title"` были переименованы в `"chicago-author-date"` и `"chicago-author-title"`

## Улучшения иллюстраций [#figure-improvements]

- Иллюстрации теперь автоматически определяют своё содержимое и адаптируют поведение. Например, иллюстрации, содержащие таблицы, автоматически получают префикс «Table X» и имеют отдельный счётчик
- Дополнение иллюстрации (например, «Figure» или «Table») теперь можно настроить
- Кроме того, иллюстрации теперь можно полностью настроить, поскольку правило show предоставляет доступ к автоматически определённым виду, дополнению и счётчику

## Улучшения библиографии [#bibliography-improvements]

- Функция [`bibliography`](/docs/typst/reference/model/bibliography) теперь также принимает несколько путей к библиографии (в виде массива)
- Разбор файлов BibLaTeX стал более снисходительным (принимает нечисловые edition, pages, volumes, dates и комментарии в стиле Jabref; исправлен разбор сокращений)
- Метки и ссылки теперь могут содержать `:` и `.`, кроме позиции в конце
- Исправлен порядок в библиографии APA

## Дополнения к рисованию [#drawing-additions]

- Добавлена функция [`polygon`](/docs/typst/reference/visualize/polygon) для рисования многоугольников
- Добавлена поддержка обрезки в [блоках-контейнерах](/docs/typst/reference/layout/box#parameters-clip) и [блоках](/docs/typst/reference/layout/block#parameters-clip)

## Интерфейс командной строки [#command-line-interface]

- Теперь возвращает ненулевой код состояния при наличии ошибки
- Теперь отслеживает корневой каталог вместо текущего
- Теперь по умолчанию размещает PDF-файл рядом с входным файлом
- Теперь принимает больше видов входных файлов (например, `/dev/stdin`)
- Добавлен флаг `--open` для непосредственного открытия PDF

## Прочие улучшения [#miscellaneous-improvements]

- Добавлена функция [`yaml`](/docs/typst/reference/data-loading/yaml) для загрузки данных из файлов YAML
- Добавлена базовая интернационализация для ещё нескольких языков (IT, RU, ZH, FR, PT)
- Добавлена поддержка нумерации для иврита
- Добавлена поддержка [целых чисел](/docs/typst/reference/foundations/int) с основанием 2, 8 и 16
- Добавлены символы двойной скобки и оператора Лапласа
- Функция [`link`](/docs/typst/reference/model/link) теперь принимает [метки](/docs/typst/reference/foundations/label)
- Синтаксис ссылок теперь допускает больше символов
- Улучшено выравнивание японского и китайского текста
- Функции вычислений ведут себя более согласованно в отношении невещественных результатов
- Заменены устаревшие угловые скобки
- Максимальная глубина вызова функций уменьшена с 256 до 64
- Исправлено неприменение [`first-line-indent`](/docs/typst/reference/model/par#parameters-first-line-indent), когда абзац начинается со стилизованного текста
- Исправлен лишний интервал в унарных операторах в формулах
- Исправлен интервал между блоками, например, в `block(above: 1cm, below: 1cm, ..)`
- Исправлено оформление текстовых операторов в математике
- Исправлен некорректный разбор языкового тега в блоке raw с одной обратной кавычкой
- Исправлены ошибки при отображении счётчиков и состояния
- Исправлено падение, связанное со счётчиком страниц
- Исправлено падение при вызове функции [`symbol`](/docs/typst/reference/foundations/symbol) без аргументов
- Исправлено падение при генерации библиографии
- Исправлён доступ к метке некоторых элементов содержимого
- Исправлен номер строки в сообщении об ошибке при разборе CSV
- Исправлено некорректное автодополнение после некоторых элементов разметки
