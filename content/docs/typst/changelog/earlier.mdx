## 28 марта 2023 г. [#march-28-2023]

- **Критические изменения:**
  - Перечисления теперь требуют пробел после маркера, то есть `1.ok` теперь нужно писать как `1. ok`
  - Изменён стиль по умолчанию для [списков терминов](/docs/typst/reference/model/terms): больше не включает двоеточие и имеет немного больший отступ
- Интерфейс командной строки
  - Добавлен аргумент `--font-path` для CLI
  - Встроены шрифты по умолчанию в бинарник CLI
  - Исправлена сборка CLI, если `git` не установлен
- Прочие улучшения
  - Добавлена поддержка отключения разделителей [матриц](/docs/typst/reference/math/mat) и [векторов](/docs/typst/reference/math/vec). Обычно с помощью `#set math.mat(delim: none)` или разово с помощью `$mat(delim: #none, 1, 2; 3, 4)$`.
  - Добавлен аргумент [`separator`](/docs/typst/reference/model/terms#parameters-separator) для списков терминов
  - Добавлена функция [`round`](/docs/typst/reference/math/lr#functions-round) для уравнений
  - Нумерации теперь допускают нули. Чтобы сбросить счётчик, можно написать `#counter(..).update(0)`
  - Добавлена документация для методов `page()` и `position()` типа [`location`](/docs/typst/reference/introspection/location)
  - Добавлены символы для двойного, тройного и четверного точечного акцента
  - Добавлены типографские кавычки для норвежского букмола
  - Добавлен Nix flake
  - Исправлен порядок библиографии в стиле IEEE
  - Исправлен разбор десятичных дробей в математике: `$1.2/3.4$`
  - Исправлен разбор несбалансированных разделителей в дробях: `$1/(2 (x)$`
  - Исправлен неожиданный разбор чисел как перечислений, например, в `1.2`
  - Исправлено сочетание заливки страницы и колонтитула
  - Исправлено падение компилятора, если [`repeat`](/docs/typst/reference/layout/repeat) используется на странице с автоматической шириной
  - Исправлены [матрицы](/docs/typst/reference/math/mat) с явным разделителем
  - Исправлено свойство [`indent`](/docs/typst/reference/model/terms#parameters-indent) списков терминов
  - Множество исправлений в документации
  - На ссылки в библиографиях теперь влияет стилизация ссылок
  - Исправлено наведение на комментарии в веб-приложении

## 21 марта 2023 г. [#march-21-2023]

- Управление ссылками и библиографией
  - [Библиографии](/docs/typst/reference/model/bibliography) и [цитирования](/docs/typst/reference/model/cite) (в настоящее время поддерживаются стили APA, Chicago Author Date, IEEE и MLA)
  - Теперь можно [ссылаться](/docs/typst/reference/model/ref) на разделы, рисунки, формулы и работы из библиографии с помощью `@label`
  - Элемент можно сделать доступным для ссылок с помощью метки:
    - `= Introduction <intro>`
    - `$ A = pi r^2 $ <area>`
- Система интроспекции для взаимодействия между различными частями документа
  - Функция [`counter`](/docs/typst/reference/introspection/counter)
    - Доступ и изменение счётчиков для страниц, заголовков, рисунков и уравнений
    - Определение и использование собственных счётчиков
    - Путешествие во времени: узнайте, каким было или будет значение счётчика в другой точке документа (например, при построении списка рисунков можно определить значение счётчика рисунков для любого заданного рисунка).
    - Счётчики считают в порядке вёрстки, а не в порядке кода
  - Функция [`state`](/docs/typst/reference/introspection/state)
    - Управление произвольным состоянием по всему документу
    - Путешествие во времени: узнайте значение вашего состояния в любой позиции документа
    - Состояние изменяется в порядке вёрстки, а не в порядке кода
  - Функция [`query`](/docs/typst/reference/introspection/query)
    - Поиск всех вхождений элемента или метки — как во всём документе, так и до/после некоторой позиции
    - Ссылки на элементы, определение их положения на страницах и доступ к их полям
    - Примеры использования: пользовательский список рисунков или колонтитул с текущим названием главы
  - Функция [`locate`](/docs/typst/reference/introspection/locate)
    - Определяет собственное положение в итоговой вёрстке
    - Можно получить доступ к `page` и координатам `x`, `y`
    - Может использоваться со счётчиками и состоянием для определения их значений в этой позиции
    - Может использоваться с запросами для поиска элементов до или после своей позиции
- Новая функция [`measure`](/docs/typst/reference/layout/measure)
  - Измеряет размер элементов после вёрстки
  - Используется в сочетании с новой функцией `style`, которая позволяет генерировать различное содержимое в зависимости от стилевого контекста, в который что-то вставляется (поскольку это влияет на измеряемый размер содержимого)
- Открытое представление содержимого
  - Содержимое больше не является непрозрачным
  - Содержимое можно сравнивать на равенство
  - Дерево элементов содержимого можно обходить с помощью кода
  - Его можно наблюдать во всплывающих подсказках или с помощью [`repr`](/docs/typst/reference/foundations/repr)
  - Новые [методы](/docs/typst/reference/foundations/content) для содержимого: `func`, `has`, `at` и `location`
  - Все необязательные поля элементов теперь можно задавать
  - Более единообразные имена полей (`heading.title` становится `heading.body`, `list.items` становится `list.children`, и ещё несколько изменений)
- Дальнейшие улучшения
  - Добавлена функция [`figure`](/docs/typst/reference/model/figure)
  - Добавлен параметр [`numbering`](/docs/typst/reference/math/equation#parameters-numbering) для функции equation
  - Добавлены параметры [`numbering`](/docs/typst/reference/layout/page#parameters-numbering) и [`number-align`](/docs/typst/reference/layout/page#parameters-number-align) для функции page
  - Параметры [`header`](/docs/typst/reference/layout/page#parameters-header) и [`footer`](/docs/typst/reference/layout/page#parameters-footer) функции page больше не принимают функции. Если вы хотите настроить их в зависимости от номера страницы, используйте вместо этого новый параметр [`numbering`](/docs/typst/reference/layout/page#parameters-numbering) или функцию [`counter`](/docs/typst/reference/introspection/counter).
  - Добавлены параметры [`footer-descent`](/docs/typst/reference/layout/page#parameters-footer-descent) и [`header-ascent`](/docs/typst/reference/layout/page#parameters-header-ascent)
  - Улучшено выравнивание по умолчанию в колонтитулах
  - Исправлено размещение арабских огласовок
  - Исправлены проблемы со встраиванием шрифтов в PDF
  - `math.formula` переименована в [`math.equation`](/docs/typst/reference/math/equation)
  - Семейство шрифтов теперь должно быть именованным аргументом: `#set text(font: "..")`
  - Добавлена поддержка [висячего отступа](/docs/typst/reference/model/par#parameters-hanging-indent)
  - Параметр `indent` абзаца переименован в [`first-line-indent`](/docs/typst/reference/model/par#parameters-first-line-indent)
  - Более точный [логарифм](/docs/typst/reference/foundations/calc#functions-log), когда основание равно `2` или `10`
  - Улучшены некоторые сообщения об ошибках
  - Исправлена вёрстка списка [`terms`](/docs/typst/reference/model/terms)
- Улучшения веб-приложения
  - Добавлена галерея шаблонов
  - Добавлены кнопки для вставки заголовков, уравнений, raw-блоков и ссылок
  - Переход к исходному коду чего-либо по щелчку на нём в панели предпросмотра (работает для текста, уравнений, изображений и многого другого)
  - Теперь можно загружать собственные шрифты и использовать их в своём проекте
  - Отладка при наведении и автодополнение теперь учитывают несколько файлов и работают в show-правилах
  - Всплывающие подсказки при наведении теперь автоматически сворачивают несколько подряд идущих одинаковых значений
  - Предпросмотр теперь автоматически прокручивается в нужное место при вводе
  - Ссылки теперь кликабельны в области предпросмотра
  - Панель инструментов, предпросмотр и редактор теперь можно скрыть
  - Добавлено автодополнение для языковых тегов raw-блоков
  - Добавлено автодополнение в SVG-файлах
  - Новая кнопка «Назад» вместо кнопки с четырьмя точками
  - Множество исправлений ошибок

## 15 февраля 2023 г. [#february-15-2023]

- У [Box](/docs/typst/reference/layout/box) и [block](/docs/typst/reference/layout/block) появились свойства `fill`, `stroke`, `radius` и `inset`
- Блокам теперь можно явно задавать размер; блоки с фиксированной высотой по-прежнему могут разрываться между страницами
- Блоки теперь можно настроить как [`breakable`](/docs/typst/reference/layout/block#parameters-breakable) или нет
- [Стиль нумерации](/docs/typst/reference/model/enum#parameters-numbering) теперь можно настроить для вложенных перечислений
- [Маркеры](/docs/typst/reference/model/list#parameters-marker) теперь можно настроить для вложенных списков
- Функция [`eval`](/docs/typst/reference/foundations/eval) теперь ожидает код вместо разметки и возвращает произвольное значение. Разметку по-прежнему можно вычислить, заключив строку в скобки.
- PDF-файлы, созданные Typst, теперь содержат метаданные XMP
- Рамки ссылок теперь отключены в выводе PDF
- Таблицы больше не создают маленькие пустые ячейки перед разрывом страницы
- Исправлена ошибка подсветки raw-блоков

## 12 февраля 2023 г. [#february-12-2023]

- Фигуры, изображения и преобразования (перемещение/поворот/масштабирование/повтор) теперь являются блочными. Чтобы встроить их в абзац, используйте [`box`](/docs/typst/reference/layout/box), как и для других элементов.
- В show-правиле «всё» теперь требуется двоеточие: пишите `show: it => ..` вместо `show it => ..`. Это предотвращает промежуточные состояния, которые портят весь документ.
- Нематематическое содержимое, такое как фигура или таблица в математической формуле, теперь выравнивается по центру по вертикали
- Поддержка предотвращения висячих строк и вдов внутри контейнеров
- Поддержка [RTL](/docs/typst/reference/text/text#parameters-dir) в списках, сетках и таблицах
- Поддержка явного размера `auto` для блоков и фигур
- Поддержка дробных (то есть `1fr`) ширин для блоков
- Исправлена ошибка, из-за которой столбцы перескакивали на следующую страницу
- Исправлена ошибка, из-за которой элементы списка не имели интерлиньяжа
- Исправлен относительный размер в списках, квадратах и автоматических столбцах сетки
- Исправлено относительное смещение в функции [`place`](/docs/typst/reference/layout/place)
- Исправлено отсутствие размера у линий
- Исправлена ошибка, из-за которой `set document(..)` выдавал ошибку о том, что находится после содержимого
- Исправлен разбор операции `not in`
- Исправлены всплывающие подсказки в математике
- Исправлена ошибка, из-за которой show-правило заголовка могло не содержать разрыв страницы при наличии оглавления
- Добавлено свойство [`baseline`](/docs/typst/reference/layout/box#parameters-baseline) для [`box`](/docs/typst/reference/layout/box)
- Добавлены операторы [`tg`](/docs/typst/reference/math/op) и [`ctg`](/docs/typst/reference/math/op) в математике
- Добавлена настройка разделителя для функции [`cases`](/docs/typst/reference/math/cases)
- Круглые скобки теперь включаются при принятии автодополнения функции

## 30 января 2023 г. [#january-30-2023]

[Перейти к анонсу в блоге.](https://typst.app/blog/2023/january-update)

- Новый синтаксис выражений в разметке/математике
  - Блоки больше нельзя напрямую встраивать в разметку
  - Как и другие выражения, они теперь требуют ведущего хеша
  - С хешем доступно больше выражений, включая литералы (`#"string"`), а также доступ к полям и вызов методов без пробела: `#emoji.face`
- Новый синтаксис импорта
  - `#import "module.typ"` создаёт привязку с именем `module`
  - `#import "module.typ": a, b` или `#import "module.typ": *` для импорта элементов
  - `#import emoji: face, turtle` для импорта из уже привязанного модуля
- Новая обработка символов
  - Удалена символьная нотация
  - Символы теперь находятся в модулях: `sym`, `emoji` и `math`
  - Модуль math также реэкспортирует весь `sym`
  - Изменяются через доступ к полям, по-прежнему независимо от порядка
  - Неизвестные модификаторы больше не допускаются
  - Поддержка пользовательских определений символов с помощью функции `symbol`
  - Символы теперь перечислены в документации
- Новый модуль `math`
  - Содержит все функции, связанные с математикой
  - Переменные и вызовы функций непосредственно в математике (без хеша) обращаются к этому модулю вместо глобальной области видимости, но также могут обращаться к локальным переменным
  - Может явно использоваться в коде, например `#set math.vec(delim: "[")`
- Сопоставление разделителей в математике
  - Любой открывающий разделитель сопоставляется с любым закрывающим
  - При сопоставлении они автоматически масштабируются
  - Чтобы предотвратить масштабирование, экранируйте их
  - Чтобы принудительно сопоставить два разделителя, используйте функцию `lr`
  - Между сопоставленными разделителями могут возникать переносы строк
  - Разделители также могут быть несбалансированными
  - Вы также можете использовать функцию `lr`, чтобы вручную масштабировать скобки (или только одну скобку) до определённого размера
- Многострочная математика с выравниванием
  - Символ `\` вставляет перенос строки
  - Символ `&` определяет точку выравнивания
  - Точки выравнивания также работают для нижних фигурных скобок, векторов, случаев и матриц
  - Поддерживается несколько точек выравнивания
- Более функциональные вызовы математических функций
  - Вызовы функций непосредственно в математике теперь могут принимать выражения кода с хешем
  - Они теперь также могут принимать именованные аргументы
  - Внутри вызовов математических функций точки с запятой превращают предшествующие аргументы в массивы для поддержки матриц: `$mat(1, 2; 3, 4)$`
- Произвольное содержимое в математике
  - Текст, изображения и другое произвольное содержимое теперь можно встраивать в математику
  - Математика теперь также поддерживает резервные шрифты для поддержки, например, CJK и эмодзи
- Дополнительные математические возможности
  - Новые текстовые операторы: функция `op`, `lim`, `max` и др.
  - Новая функция матриц: `mat`
  - Новые корни n-й степени с помощью функции `root`: `$root(3, x)$`
  - Новые нижние и верхние фигурные скобки, квадратные скобки и линии
  - Новые функции `abs` и `norm`
  - Новые сокращения: `[|`, `|]` и `||`
  - Новая функция `attach`, переопределяемые присоединения с помощью `script` и `limit`
  - Ручные интервалы в математике с помощью `h`, `thin`, `med`, `thick` и `quad`
  - Символы и другое содержимое теперь можно использовать как функцию, например `$zeta(x)$`
  - Добавлен шрифт Fira Math, удалён шрифт Noto Sans Math
  - Поддержка альтернативных математических шрифтов через `#show math.formula: set text("Fira Math")`
- Дополнительные улучшения библиотеки
  - Новый модуль `calc`, `abs`, `min`, `max`, `even`, `odd` и `mod` перемещены туда
