## Управление библиографией [#bibliography-management]

- Добавлена поддержка объединения цитирований (например, `[1]-[3]` вместо `[1], [2], [3]`), если это запрошено стилем CSL
- Исправлена ошибка, из-за которой после группы цитирований появлялся лишний пробел
- Исправлены правила show для ссылок в библиографии
- Исправлены правила show-set для цитирований
- Исправлены связанные с библиографией сбои, происходившие на некоторых системах
- Исправлено название семейства стилей GB/T 7714 с 7114 на 7714
- Исправлено отсутствующее название в некоторых стилях библиографии
- Исправлена печать томов в некоторых стилях
- Исправлен порядок разделителей для авторов в некоторых стилях (например, APA)
- Исправлено поведение буквенно-цифрового стиля
- Исправлено несколько ошибок в стиле GB/T 7714
- Исправлено экранирование в значениях Hayagriva
- Исправлены сбои при пустых датах в файлах Hayagriva
- Исправлена ошибка с отступами вокруг математических блоков
- Исправлено форматирование заголовков в стиле title case после дословного текста и апострофов
- Диапазоны страниц в файлах `.bib` теперь могут быть произвольными строками
- Многострочные значения в файлах `.bib` теперь разбираются корректно
- Ключи записей в файлах `.bib` теперь допускают больше символов
- Исправлено сообщение об ошибке для пустых дат в файлах `.bib`
- Добавлена поддержка годов длиной не 4 без ведущих нулей в файлах `.bib`
- Теперь учитывается больше команд LaTeX (например, для кавычек) в файлах `.bib`

## Визуализация [#visualization]

- Добавлена поддержка [паттернов](/docs/typst/reference/visualize/tiling) в качестве заливок и обводок
- Параметр `alpha` функции [`components`](/docs/typst/reference/visualize/color#definitions-components) для цветов теперь является именованным параметром **(Обратно несовместимое изменение)**
- Добавлена поддержка цветового пространства [Oklch](/docs/typst/reference/visualize/color#definitions-oklch)
- Улучшены преобразования между цветами в разных цветовых пространствах
- Сняты ограничения на компонент chroma в [Oklab](/docs/typst/reference/visualize/color#definitions-oklab)
- Исправлено [отсечение](/docs/typst/reference/layout/block#parameters-clip) на блоках и боксах без обводки
- Исправлена ошибка с [градиентами](/docs/typst/reference/visualize/gradient) в математике
- Исправлена ошибка с поворотом градиента на тексте
- Исправлена ошибка с цветами градиента в PDF
- Исправлена относительная база соотношений chroma в Oklab
- Исправлено отрицание цвета в Oklab

## Текст и вёрстка [#text-and-layout]

- Текст CJK теперь можно выделять с помощью синтаксиса `*` и `_`, даже если между символами нет пробелов
- Добавлена базовая интернационализация для греческого и эстонского языков
- Улучшен разделитель [подписи к рисунку](/docs/typst/reference/model/figure#definitions-caption-separator) по умолчанию для китайского, французского и русского языков
- Изменено [дополнение к рисунку](/docs/typst/reference/model/figure#parameters-supplement) по умолчанию для русского языка на краткую форму
- Исправлен [интервал между CJK и латиницей](/docs/typst/reference/text/text#parameters-cjk-latin-spacing) перед переносами строк и в вызовах [`locate`](/docs/typst/reference/introspection/locate)
- Исправлен перенос строк в конце ссылок

## Математика [#math]

- Добавлена функция [`mid`](/docs/typst/reference/math/lr#functions-mid) для масштабирования разделителя до высоты окружающей группы [`lr`](/docs/typst/reference/math/lr#functions-lr)
- Функция [`op`](/docs/typst/reference/math/op) теперь может принимать любое содержимое, а не только строки
- Улучшена документация по [выравниванию в математике](/docs/typst/reference/math#alignment)
- Исправлено проглатывание завершающей запятой, когда символ используется подобно функции (например, `pi(a,b,)`)

## Скрипты [#scripting]

- Любой ключ словаря, не являющийся идентификатором, теперь интерпретируется как выражение: например, `((key): value)` создаст словарь с динамическим ключом
- У типа [`stroke`](/docs/typst/reference/visualize/stroke) теперь есть конструктор, который преобразует значение в обводку или создаёт её из составных частей
- Добавлен конструктор для типа [`arguments`](/docs/typst/reference/foundations/arguments)
- Добавлены функции [`calc.div-euclid`](/docs/typst/reference/foundations/calc#functions-div-euclid) и [`calc.rem-euclid`](/docs/typst/reference/foundations/calc#functions-rem-euclid)
- Исправлено сравнение на равенство для [`arguments`](/docs/typst/reference/foundations/arguments)
- Исправлен [`repr`](/docs/typst/reference/foundations/repr) для цветов [`cmyk`](/docs/typst/reference/visualize/color#definitions-cmyk)
- Исправлены сбои с предоставляемыми элементами, такими как подписи к рисункам, элементы оглавления и элементы сносок

## Инструменты и диагностика [#tooling-and-diagnostics]

- Правила show, которые сопоставляются с собственным выводом, теперь выдают соответствующее сообщение об ошибке вместо сбоя (это первый шаг, в будущем они будут просто работать)
- Слишком глубокая или бесконечная вложенность макетов теперь выдаёт сообщения об ошибках вместо сбоев
- Добавлены подсказки для недопустимых идентификаторов
- Добавлена подсказка при попытке использовать вручную созданную сноску или элемент оглавления
- Добавлены недостающие сведения в автодополнение для типов
- Улучшено сообщение об ошибке при передаче именованного аргумента там, где ожидается позиционный
- Переход по клику теперь работает на блоках `raw`

## Экспорт [#export]

- Вывод компиляции PDF теперь снова полностью воспроизводим байт в байт, если [`date`](/docs/typst/reference/model/document#parameters-date) документа задана вручную
- Исправлен экспорт цветов в SVG
- Исправлена кодировка метаданных PDF для нескольких [авторов](/docs/typst/reference/model/document#parameters-author)

## Интерфейс командной строки [#command-line-interface]

- Исправлена серьёзная ошибка, из-за которой `typst watch` путал файлы и не подхватывал обновления
- Получение метаданных релиза в `typst update` теперь учитывает прокси
- Исправлена ошибка с флагом `--open` в Windows, когда путь содержит пробел
- Переменная окружения `TYPST_FONT_PATHS` теперь может содержать несколько путей (разделённых `;` в Windows и `:` в остальных системах)
- Встроенные шрифты New Computer Modern обновлены до версии 4.7
- Процесс отслеживания больше не останавливается, когда основной файл содержит недопустимый UTF-8

## Прочие улучшения [#miscellaneous-improvements]

- Кодирование изображений при экспорте в PDF распараллелено
- Улучшено внутреннее представление содержимого для повышения производительности
- Оптимизирована производительность интроспекции (query, counter и т.д.)
- [Название документа](/docs/typst/reference/model/document#parameters-title) теперь может быть произвольным содержимым, а не только строкой
- Параметр [`number-align`](/docs/typst/reference/model/enum#parameters-number-align) в нумерованных списках теперь также принимает вертикальные выравнивания
- Исправлены селекторы для элементов [quote](/docs/typst/reference/model/quote)
- Исправлен разбор выражения `#return` в разметке
- Исправлена ошибка, из-за которой встроенные уравнения отображались в оглавлении уравнений
- Исправлена потенциальная проблема с CRLF в блоках [`raw`](/docs/typst/reference/text/raw)
- Исправлена ошибка, из-за которой китайская нумерация не могла превысить число 255

## Разработка [#development]

- Объединены `typst` и `typst-library`, а `typst-pdf`, `typst-svg` и `typst-render` выделены в отдельные крейты
- Nix flake теперь включает ревизию git при запуске `typst --version`
