## Управление библиографией [#bibliography-management]

- Новый движок библиографии на основе [CSL](https://citationstyles.org/) (Citation Style Language). Поставляется с примерно 100 распространёнными стилями цитирования и может загружать пользовательские файлы `.csl`.
- Добавлен новый аргумент [`form`](/docs/typst/reference/model/cite#parameters-form) функции `cite` для создания различных форм цитирования (например, для создания цитаты, подходящей для включения в текст).
- Функция [`cite`](/docs/typst/reference/model/cite) теперь принимает только одну метку/ключ вместо нескольких. Соседние цитаты объединяются и форматируются в соответствии с правилами стиля цитирования автоматически. Это работает как с синтаксисом ссылок, так и с явными вызовами функции `cite`. **(Обратно несовместимое изменение)**
- Функция `cite` теперь принимает [метку](/docs/typst/reference/foundations/label) вместо строки **(Обратно несовместимое изменение)**
- Добавлен аргумент [`full`](/docs/typst/reference/model/bibliography#parameters-full) функции bibliography для вывода полной библиографии, даже если не все работы были процитированы
- Записи библиографии теперь могут содержать уравнения Typst (заключённые в `$..$`, как и в разметке); это работает как для библиографий `.yaml`, так и `.bib`
- Формат YAML hayagriva был улучшен. Подробности см. в его [списке изменений](https://github.com/typst/hayagriva/blob/main/CHANGELOG.md). **(Обратно несовместимое изменение)**
- Исправлено несколько ошибок при разборе файлов `.bib`
- Удалён аргумент `brackets` функции `cite` в пользу `form`

## Визуализация [#visualization]

- Градиенты и цвета (благодарность [@Dherse](https://github.com/Dherse))
  - Добавлена поддержка [градиентов](/docs/typst/reference/visualize/gradient) для фигур и текста
  - Поддерживаются линейные, радиальные и конические градиенты
  - Добавлена поддержка определения цветов в большем числе цветовых пространств, включая [Oklab](/docs/typst/reference/visualize/color#definitions-oklab), [Linear RGB(A)](/docs/typst/reference/visualize/color#definitions-linear-rgb), [HSL](/docs/typst/reference/visualize/color#definitions-hsl) и [HSV](/docs/typst/reference/visualize/color#definitions-hsv)
  - Добавлены функции [`saturate`](/docs/typst/reference/visualize/color#definitions-saturate), [`desaturate`](/docs/typst/reference/visualize/color#definitions-desaturate) и [`rotate`](/docs/typst/reference/visualize/color#definitions-rotate) для цветов
  - Добавлен модуль [`color.map`](/docs/typst/reference/visualize/color#definitions-map) с предопределёнными цветовыми картами, которые можно использовать с градиентами
  - Функция `kind` для цветов переименована в [`space`](/docs/typst/reference/visualize/color#definitions-space)
  - Удалены функции `to-rgba`, `to-cmyk` и `to-luma` в пользу новой функции [`components`](/docs/typst/reference/visualize/color#definitions-components)
- Улучшена отрисовка [прямоугольников](/docs/typst/reference/visualize/rect) со скруглёнными углами и переменной толщиной обводки
- Добавлена поддержка корректной обрезки [блоков](/docs/typst/reference/layout/box#parameters-clip) и [блочных элементов](/docs/typst/reference/layout/block#parameters-clip) со скруглёнными углами
- Добавлен параметр `background` функциям [`overline`](/docs/typst/reference/text/overline), [`underline`](/docs/typst/reference/text/underline) и [`strike`](/docs/typst/reference/text/strike)
- Исправлено неточное встраивание цветов в PDF
- Исправлена обработка ICC-профилей для изображений, встроенных в PDF

## Текст и вёрстка [#text-and-layout]

- Добавлена поддержка автоматической вставки правильных [пробелов](/docs/typst/reference/text/text#parameters-cjk-latin-spacing) между текстом CJK и латиницей (включено по умолчанию)
- Добавлена поддержка автоматической корректировки большего числа знаков препинания CJK
- Добавлен элемент [`quote`](/docs/typst/reference/model/quote) для вставки встроенных и блочных цитат с необязательными атрибуциями
- Добавлен элемент [`raw.line`](/docs/typst/reference/text/raw#definitions-line) для настройки отображения отдельных строк неформатированного текста, например для добавления номеров строк при сохранении правильной подсветки синтаксиса
- Добавлена поддержка настройки [отступов](/docs/typst/reference/model/table#parameters-inset) для каждой стороны в функции table
- Добавлены венгерский и румынский переводы
- Добавлена поддержка переносов для чешского языка
- Добавлена поддержка настройки пользовательских [типографских кавычек](/docs/typst/reference/text/smartquote)
- Стандартный [разделитель подписи](/docs/typst/reference/model/figure#definitions-caption-separator) теперь учитывает текущий установленный язык и регион
- Улучшены переносы строк в ссылках / URL-адресах (особенно полезно для библиографий с большим количеством URL-адресов)
- Улучшена обработка последовательных дефисов в алгоритме выравнивания
- Исправлено взаимодействие выравнивания и висячего отступа
- Исправлена ошибка с переносом коротких строк без пробелов при включённом выравнивании
- Исправлен резервный шрифт для дефиса, созданного переносом
- Исправлена обработка соединителя слов и других неразрывных символов при переносе
- Исправлено падение при переносе после пустой строки
- Исправлен перенос составных эмодзи, таких как 🏳️‍🌈
- Исправлен отсутствующий текст в некоторых SVG
- Исправлен резервный шрифт в SVG
- Исправлено поведение аргумента [`to`](/docs/typst/reference/layout/pagebreak#parameters-to) функции `pagebreak`
- Исправлен `set align(..)` для уравнений
- Исправлены отступы вокруг [размещённых](/docs/typst/reference/layout/place) элементов
- Исправлено объединение отступов [`above`](/docs/typst/reference/layout/block#parameters-above) и [`below`](/docs/typst/reference/layout/block#parameters-below), если они заданы в единицах em и размеры шрифтов различаются
- Исправлена обработка параметра `extent` функций [`underline`](/docs/typst/reference/text/underline), [`overline`](/docs/typst/reference/text/overline) и [`strike`](/docs/typst/reference/text/strike)
- Исправлено падение для [плавающих размещённых элементов](/docs/typst/reference/layout/place#parameters-float) без указанного вертикального выравнивания
- Частично исправлена ошибка с цитатами в сносках

## Математика [#math]

- Добавлен аргумент `gap` для функций [`vec`](/docs/typst/reference/math/vec#parameters-gap), [`mat`](/docs/typst/reference/math/mat#parameters-gap) и [`cases`](/docs/typst/reference/math/cases#parameters-gap)
- Добавлен аргумент `size` для функций [`abs`](/docs/typst/reference/math/lr#functions-abs), [`norm`](/docs/typst/reference/math/lr#functions-norm), [`floor`](/docs/typst/reference/math/lr#functions-floor), [`ceil`](/docs/typst/reference/math/lr#functions-ceil) и [`round`](/docs/typst/reference/math/lr#functions-round)
- Добавлен параметр [`reverse`](/docs/typst/reference/math/cases#parameters-reverse) функции cases
- Добавлена поддержка мультиномиальных коэффициентов функции [`binom`](/docs/typst/reference/math/binom)
- Удалён аргумент `rotation` функции [`cancel`](/docs/typst/reference/math/cancel) в пользу нового и более гибкого аргумента `angle` **(Обратно несовместимое изменение)**
- Добавлена константа `wide`, которая вставляет удвоенный отступ `quad`
- Добавлены [операторы](/docs/typst/reference/math/op) `csch` и `sech`
- `↼`, `⇀`, `↔` и `⟷` теперь можно использовать как [акценты](/docs/typst/reference/math/accent)
- Добавлены [символы](/docs/typst/reference/symbols/sym) `integral.dash`, `integral.dash.double` и `integral.slash`
- Добавлена поддержка указания отрицательных индексов для линий [дополнения](/docs/typst/reference/math/mat#parameters-augment) для позиционирования линии с конца
- Исправлен цвет по умолчанию для линий [дополнения](/docs/typst/reference/math/mat#parameters-augment) матрицы
- Исправлено присоединение штрихов к встроенным выражениям
- Математическое содержимое теперь учитывает настройку текстовой [базовой линии](/docs/typst/reference/text/text#parameters-baseline)

## Производительность [#performance]

- Исправлена ошибка, связанная с правилами show в шаблонах, которая фактически отключала инкрементальную компиляцию в затронутых документах
- Микрооптимизирован код в нескольких горячих путях, что даёт существенный прирост производительности, в частности при инкрементальной компиляции
- Улучшен инкрементальный разбор, что влияет на весь конвейер инкрементальной компиляции
- Добавлена поддержка инкрементального разбора в CLI
- Добавлена поддержка инкрементального кодирования SVG при экспорте в PDF, что значительно повышает производительность экспорта для документов с большим количеством SVG

## Инструменты и диагностика [#tooling-and-diagnostics]

- Улучшено автодополнение для переменных, находящихся в области видимости
- Добавлено автодополнение для импортов пакетов
- Добавлено автодополнение для [меток](/docs/typst/reference/foundations/label)
- Добавлена подсказка, показывающая, какие переменные захватывает функция (при наведении на знак равенства или стрелку функции)
- Диагностические сообщения теперь дедуплицируются
- Улучшена диагностика при попытке применить унарные `+` или `-` к типам, которые поддерживают только бинарные `+` и `-`
- Сообщения об ошибках теперь указывают, какая метка или ключ цитирования отсутствует в документе или его библиографии
- Исправлена ошибка, при которой ошибки разбора аргументов функции затенялись ошибками выполнения функции (например, при попытке вызвать [`array.sorted`](/docs/typst/reference/foundations/array#definitions-sorted) и передаче ключевой функции как позиционного аргумента вместо именованного).

## Экспорт [#export]

- Добавлена поддержка настройки [`date`](/docs/typst/reference/model/document#parameters-date) создания документа. Если `date` установлено в `auto` (по умолчанию), дата создания PDF будет установлена в текущую дату и время.
- Добавлена поддержка настройки [`keywords`](/docs/typst/reference/model/document#parameters-keywords) документа
- Сгенерированные PDF теперь содержат идентификаторы PDF-документов
- Метаданные инструмента создания PDF теперь включают версию Typst

## Веб-приложение [#web-app]

- Добавлен выбор версии для привязки проекта к более старой версии компилятора (с поддержкой Typst 0.6.0+)
- Исправлены рассинхронизации между редактором и компилятором и улучшена общая стабильность
- Приложение теперь продолжает подсвечивать документ при вводе во время компиляции документа

## Интерфейс командной строки [#command-line-interface]

- Добавлена поддержка обнаружения шрифтов через fontconfig
- Теперь очищает экран вместо сброса терминала
- Теперь автоматически выбирает правильное расширение файла для выбранного формата вывода
- Теперь перегенерирует изображения только для изменённых страниц при использовании `typst watch` с экспортом в PNG или SVG

## Прочие улучшения [#miscellaneous-improvements]

- Добавлен тип [`version`](/docs/typst/reference/foundations/version) и константа [`sys.version`](/docs/typst/reference/foundations/sys#constants-version), указывающая текущую версию компилятора. Может использоваться для корректной поддержки нескольких версий.
- Символ U+2212 MINUS SIGN теперь используется при отображении числового значения, в [`repr`](/docs/typst/reference/foundations/repr) любого числового значения и для замены обычного дефиса в текстовом режиме перед цифрой. Это улучшает, в частности, отображение отрицательных целочисленных значений в математическом режиме.
- Добавлена поддержка указания значения по умолчанию вместо ошибки для функции `remove` в [массиве](/docs/typst/reference/foundations/array#definitions-remove) и [словаре](/docs/typst/reference/foundations/dictionary#definitions-remove)
- Упрощены примеры в руководстве по настройке страницы
- В документации слово «hashtag» заменено на слово «hash» там, где это уместно
- Добавлена поддержка [`array.zip`](/docs/typst/reference/foundations/array#definitions-zip) без дополнительных аргументов
- Исправлено падение, когда плагин пытался прочитать память за пределами допустимого диапазона
- Исправлены падения при обработке бесконечных [длин](/docs/typst/reference/layout/length)
- Исправлены ошибки интроспекции (в основном библиографии) из-за слабого разрыва страницы ближе к концу документа

## Разработка [#development]

- `typst::ide` вынесен в отдельный крейт `typst_ide`
- Удалено несколько оставшихся ограничений `'static` на `&dyn World`
- Удалена ненужная зависимость, что уменьшает размер бинарного файла
- Исправлена компиляция `typst` самого по себе (без `typst-library`)
- Исправлены предупреждения с Nix flake при использовании `lib.getExe`
