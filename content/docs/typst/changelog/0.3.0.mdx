## Ломающие изменения [#breaking-changes]

- Переименованы некоторые символы: то, что раньше было `dot.op`, теперь просто `dot`, а базовый символ точки — `dot.basic`. То же самое относится к `ast` и `tilde`.
- `mod` переименован в [`rem`](/docs/typst/reference/foundations/calc#functions-rem), чтобы точнее отражать поведение. В качестве переходного периода он останется доступен как `mod` до следующего обновления.
- Одиночный символ подчёркивания больше не является допустимым идентификатором, теперь его можно использовать только в шаблонах.
- Из [`query`](/docs/typst/reference/introspection/query) удалены аргументы `before` и `after`. Теперь это реализуется через гибкие комбинаторные методы [селекторов](/docs/typst/reference/foundations/selector).
- Добавлена поддержка [присоединений](/docs/typst/reference/math/attach#functions-attach) (нижних и верхних индексов), которые стоят перед базовым символом. Аргументы `top` и `bottom` переименованы в `t` и `b`.

## Новые возможности [#new-features]

- Добавлена поддержка более сложных [обводок](/docs/typst/reference/visualize/stroke) (настраиваемые окончания, соединения и шаблоны штрихов)
- Добавлена функция [`cancel`](/docs/typst/reference/math/cancel) для уравнений
- Добавлена поддержка [деструктуризации](/docs/typst/reference/scripting#bindings) в списках аргументов и присваиваниях
- В функцию изображения добавлен аргумент текста [`alt`](/docs/typst/reference/visualize/image#parameters-alt)
- Добавлена функция [`toml`](/docs/typst/reference/data-loading/toml) для загрузки данных из файла TOML
- Для массивов добавлены методы [`zip`](/docs/typst/reference/foundations/array#definitions-zip), [`sum`](/docs/typst/reference/foundations/array#definitions-sum) и [`product`](/docs/typst/reference/foundations/array#definitions-product)
- Добавлены функции [вычислений](/docs/typst/reference/foundations/calc) `fact`, `perm`, `binom`, `gcd`, `lcm`, `atan2`, `quo`, `trunc` и `fract`

## Улучшения [#improvements]

- Текст в SVG теперь отображается корректно
- Typst теперь создаёт структуру заголовков в PDF
- [Ссылки](/docs/typst/reference/model/ref) теперь предоставляют элемент, на который они ссылаются, в качестве поля в правилах show
- Уточнён алгоритм переноса строк для лучшего выравнивания китайского текста
- Местоположения теперь являются допустимым видом селектора
- Добавлено несколько символов для алгебры
- Добавлена поддержка испанских типографских кавычек
- Добавлена функция [`selector`](/docs/typst/reference/foundations/selector), превращающая значение, похожее на селектор, в селектор, для которого можно вызывать комбинаторные методы
- Улучшены некоторые сообщения об ошибках
- Заголовки оглавления и библиографии теперь можно стилизовать с помощью правил show-set
- Операции над числами теперь выдают ошибку вместо переполнения

## Исправления ошибок [#bug-fixes]

- Исправлен неверный перенос строки перед знаками препинания, следующими за встроенными уравнениями, цитатами и другими элементами
- Исправлена ошибка с [приёмниками аргументов](/docs/typst/reference/foundations/arguments)
- Исправлены обводки нулевой толщины
- Исправлены скрытие и правила show в математике
- Исправлено выравнивание в матрицах
- Исправлены некоторые ошибки выравнивания в уравнениях
- Исправлено выравнивание ячеек сетки
- Исправлено выравнивание маркеров списка и маркеров перечисления при наличии глобальных настроек выравнивания
- Исправлено замыкание контуров
- Исправлено падение компилятора при ссылках на рисунки
- Одиночный завершающий перенос строки теперь игнорируется в математике, как и в тексте

## Интерфейс командной строки [#command-line-interface]

- Путь к шрифтам и корень компиляции теперь можно задать с помощью переменных окружения `TYPST_FONT_PATHS` и `TYPST_ROOT`
- Вывод `typst fonts` теперь включает встроенные шрифты

## Разработка [#development]

- Добавлена инструментация для отладки и оптимизации
- Добавлен флаг `--update` и переменная окружения `UPDATE_EXPECT` для обновления эталонных изображений для тестов
- Теперь можно запустить конкретный подтест с помощью `--subtest`
- Тесты теперь выполняются в несколько потоков
