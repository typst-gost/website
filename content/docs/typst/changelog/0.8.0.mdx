## Скрипты [#scripting]

- Плагины (спасибо [@astrale-sharp](https://github.com/astrale-sharp) и [@arnaudgolfouse](https://github.com/arnaudgolfouse))
  - Typst теперь может загружать [плагины](/docs/typst/reference/foundations/plugin), скомпилированные в WebAssembly
  - Таким образом, в качестве плагина можно загрузить всё, что компилируется в WebAssembly
  - Эти плагины полностью изолированы (нет доступа к файловой системе или сети)
  - Плагины можно поставлять в составе [пакетов](/docs/typst/reference/scripting#packages)
  - Плагины работают точно так же и в веб-приложении
- Типы теперь являются полноценными значениями **(Обратно несовместимое изменение)**
  - [Тип](/docs/typst/reference/foundations/type) теперь сам по себе является значением
  - Некоторые типы можно вызывать как функции (те, у которых есть конструктор), например [`int`](/docs/typst/reference/foundations/int) и [`str`](/docs/typst/reference/foundations/str)
  - Проверки типов теперь имеют вид `type(10) == int` вместо старого `type(10) == "integer"`. Совместимость со старым способом сохранится на некоторое время, чтобы дать авторам пакетов время на обновление, но в какой-то момент она будет удалена.
  - Методы теперь являются синтаксическим сахаром для вызова функции, привязанной к типу, то есть `"hello".len()` эквивалентно `str.len("hello")`
- Добавлена поддержка переименования при [`import`](/docs/typst/reference/scripting#modules) с помощью `as`
- Добавлен тип [`duration`](/docs/typst/reference/foundations/duration)
- Добавлена поддержка кодирования и декодирования [CBOR](/docs/typst/reference/data-loading/cbor)
- Добавлены функции кодирования и декодирования из байтов и в байты для форматов данных: `json.decode`, [`json.encode`](/docs/typst/reference/data-loading/json#definitions-encode) и аналогичные функции для других форматов
- Добавлена функция [`array.intersperse`](/docs/typst/reference/foundations/array#definitions-intersperse)
- Добавлена функция [`str.rev`](/docs/typst/reference/foundations/str#definitions-rev)
- Добавлена константа [`calc.tau`](/docs/typst/reference/foundations/calc#constants-tau)
- [Байты](/docs/typst/reference/foundations/bytes) теперь можно объединять и складывать
- Функция [`array.zip`](/docs/typst/reference/foundations/array#definitions-zip) теперь является вариативной
- Исправлена ошибка в [`eval`](/docs/typst/reference/foundations/eval), когда `mode` был установлен в `"math"`
- Исправлена ошибка в функции [`ends-with`](/docs/typst/reference/foundations/str#definitions-ends-with) для строк
- Исправлена ошибка с деструктуризацией в сочетании с break, continue и return
- Исправлены типы аргументов [гиперболических функций](/docs/typst/reference/foundations/calc#functions-cosh), они больше не допускают углы **(Обратно несовместимое изменение)**
- Переименованы некоторые методы цвета: `rgba` стал `to-rgba`, `cmyk` стал `to-cmyk`, а `luma` стал `to-luma` **(Обратно несовместимое изменение)**

## Экспорт [#export]

- Добавлен экспорт в SVG (спасибо [@Enter-tainer](https://github.com/Enter-tainer))
- Исправлены ошибки со встраиванием шрифтов в PDF
- Добавлена поддержка меток страниц, отражающих стиль [нумерации страниц](/docs/typst/reference/layout/page#parameters-numbering) в PDF

## Текст и вёрстка [#text-and-layout]

- Добавлена функция [`highlight`](/docs/typst/reference/text/highlight) для выделения текста цветом фона
- Добавлена функция [`polygon.regular`](/docs/typst/reference/visualize/polygon#definitions-regular) для рисования правильного многоугольника
- Добавлена поддержка табуляции в элементах [`raw`](/docs/typst/reference/text/raw) вместе с параметром [`tab-width`](/docs/typst/reference/text/raw#parameters-tab-size)
- Механизм вёрстки теперь пытается предотвращать «висячие строки» (последние строки, состоящие всего из одного слова)
- Добавлены финские переводы
- Добавлена поддержка переносов для польского языка
- Улучшена обработка идущих подряд «умных» кавычек разных видов
- Исправлено вертикальное выравнивание для аргумента [`number-align`](/docs/typst/reference/layout/page#parameters-number-align) в функции page **(Обратно несовместимое изменение)**
- Исправлены слабые разрывы страниц после обновлений счётчиков
- Исправлен отсутствующий текст в SVG, когда шрифт текста установлен в «New Computer Modern»
- Исправлены переводы для китайского языка
- Исправлено падение при пустом тексте в правиле show
- Исправлены ведущие пробелы при разрыве строки после числа и запятой
- Исправлено размещение плавающих элементов в колонках и других контейнерах
- Исправлен расчёт размера блока, содержащего всего один box

## Математика [#math]

- Добавлена поддержка [расширенных матриц](/docs/typst/reference/math/mat#parameters-augment)
- Удалена поддержка автоматического сопоставления скобок, таких как `|` и `||`, поскольку было слишком много ложных срабатываний. Вместо этого можно использовать функции [`abs`](/docs/typst/reference/math/lr#functions-abs) или [`norm`](/docs/typst/reference/math/lr#functions-norm) либо явный вызов [`lr`](/docs/typst/reference/math/lr#functions-lr). **(Обратно несовместимое изменение)**
- Исправлен интервал после числа с десятичной точкой в математике
- Исправлена ошибка со штрихами в нижнем индексе
- Исправлен слабый интервал
- Исправлено падение, когда текст внутри математики содержит перевод строки

## Инструменты и диагностика [#tooling-and-diagnostics]

- Добавлены подсказки при попытке вызвать функцию, хранящуюся в словаре, без дополнительных скобок
- Исправлена подсказка при ссылке на уравнение без нумерации
- Добавлены дополнительные сведения в некоторые диагностические сообщения (например, при сбое декодирования SVG)

## Интерфейс командной строки [#command-line-interface]

- Добавлена команда `typst update` для самообновления CLI (спасибо [@jimvdl](https://github.com/jimvdl))
- Добавлен индикатор прогресса загрузки для пакетов и обновлений
- Добавлен аргумент `--format` для явного указания выходного формата
- CLI теперь учитывает конфигурацию прокси через переменные окружения и имеет новую опцию `--cert` для установки пользовательского сертификата CA
- Исправлено падение, когда поле отсутствовало и в `typst query` передавался `--one`

## Прочие улучшения [#miscellaneous-improvements]

- Добавлено [руководство по настройке страницы](/docs/typst/guides/page-setup)
- Добавлена функция [`figure.caption`](/docs/typst/reference/model/figure#definitions-caption), которую можно использовать для более простой настройки рисунков (**Обратно несовместимое изменение**, поскольку `it.caption` теперь отображает полную подпись с дополнением в правилах show для рисунков и ручных оглавлениях)
- Аргумент `caption-pos` перенесён в функцию `figure.caption` и переименован в `position` **(Обратно несовместимое изменение)**
- Добавлен аргумент [`separator`](/docs/typst/reference/model/figure#definitions-caption-separator) в функцию `figure.caption`
- Добавлена поддержка комбинации and/or и before/after для [селекторов](/docs/typst/reference/foundations/selector)
- Пакеты теперь могут указывать [минимальную версию компилятора](https://github.com/typst/packages#package-format), необходимую для их работы
- Исправлена ошибка парсера, из-за которой вызовы методов могли переноситься на отдельную строку для выражений `#let` в разметке **(Обратно несовместимое изменение)**
- Исправлены ошибки в преобразовании регистра предложений и заголовков для библиографий
- Исправлены дополнения для алфавитно-цифрового стиля библиографии и стиля «автор — название»
- Исправлена ошибка на единицу в стиле библиографии APA
